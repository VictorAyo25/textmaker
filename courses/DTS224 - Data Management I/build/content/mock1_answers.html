AnswerQuestion Three

(a) Normalization organises attributes into well-structured relations, removing redundancy and anomalies using functional dependencies. Full: depends on the whole composite key. Partial: depends on part of the key. Transitive: depends on the key only through a non-key attribute.

(b) The key is (orderNo, productNo). custNo, custName, orderDate depend on orderNo alone (partial); custName depends on custNo (transitive).

Customer(custNo, custName)                   PK custNo
OrderHead(orderNo, orderDate, custNo)        PK orderNo   FK custNo -> Customer
OrderLine(orderNo, productNo, qty, unitPrice)
   PK (orderNo, productNo)   FK orderNo -> OrderHead
AnswerQuestion Four

(a)(i) Total specialization: every supertype instance must be in some subtype; partial: it need not be. (ii) Supertype: the general type holding common attributes; subtype: a specialised subgroup with its own extra attributes, inheriting the supertype's.

(b) Each subtype becomes a relation sharing the supertype's key:

VEHICLE(vehID, make, price)         PK vehID
CAR(vehID, numDoors)                PK vehID   FK vehID -> VEHICLE
TRUCK(vehID, capacity)              PK vehID   FK vehID -> VEHICLE

(c) A DBMS is the software that defines, creates, maintains, and controls access to a database (MySQL, Oracle). DDL defines structure (CREATE, ALTER, DROP); DML changes data (INSERT, UPDATE, DELETE, SELECT).

AnswerQuestion Five

(a) Super key: any attribute set that identifies a row uniquely. Candidate key: a minimal super key. Primary key: the chosen candidate key, never null. Foreign key: an attribute matching a primary key elsewhere.

(i)   CREATE TABLE Dept (
        deptNo CHAR(4) PRIMARY KEY, dName VARCHAR(20), city VARCHAR(20) );
      CREATE TABLE Emp (
        empNo CHAR(5) PRIMARY KEY, name VARCHAR(30),
        salary DECIMAL(9,2), deptNo CHAR(4),
        FOREIGN KEY (deptNo) REFERENCES Dept(deptNo) );
(ii)  INSERT INTO Emp VALUES ('E001','Ada Obi',60000,'D01');
(iii) UPDATE Emp SET salary = salary * 1.05;
(iv)  CREATE VIEW lagosStaff AS
        SELECT empNo, name, deptNo FROM Emp
        WHERE deptNo IN (SELECT deptNo FROM Dept WHERE city = 'Lagos');
(v)   SELECT * FROM Emp WHERE salary > 50000 ORDER BY salary DESC;
(vi)  SELECT deptNo, COUNT(*) FROM Emp GROUP BY deptNo;
