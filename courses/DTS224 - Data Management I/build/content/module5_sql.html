Module Five · Unit 2

Structured Query Language (SQL)

The language you actually type. SQL both defines the tables (DDL) and works with the data in them (DML). The exam gives you a schema and a list of English requests; your job is to write the statement for each. Every keyword below is introduced before it is used.

By the end of this unit you can: create, alter, and drop tables with keys and constraints; insert, update, and delete rows; and write a SELECT for any request using WHERE, ORDER BY, GROUP BY, the aggregate functions, LIKE, IN, BETWEEN, joins, subqueries, and views.

2.1 DDL: defining the tables

Must memoriseCREATE, ALTER, DROP
CREATE TABLE Branch (
  branchNo  CHAR(4)     PRIMARY KEY,
  city      VARCHAR(20) NOT NULL );

ALTER TABLE Staff DROP COLUMN DOB;          -- remove a column
ALTER TABLE Staff ADD prefRooms INT;        -- add a column
DROP TABLE Branch;                          -- remove the whole table

PRIMARY KEY enforces entity integrity; FOREIGN KEY ... REFERENCES enforces referential integrity; NOT NULL, UNIQUE, DEFAULT, and CHECK are the other constraints.

2.2 DML: changing the data

Must memoriseINSERT, UPDATE, DELETE
INSERT INTO Emp VALUES (101, 'Azi Esther', 40, 15000);
UPDATE  Emp SET Salary = Salary * 1.10;          -- every row: 10% rise
DELETE  FROM Dept WHERE Dname = 'Toy';           -- only matching rows

An UPDATE or DELETE with no WHERE touches every row. Text values are quoted; numbers are not.

2.3 SELECT: asking questions

Must memoriseThe clauses, in order
SELECT   columns (or * for all, or COUNT/SUM/AVG/MIN/MAX)
FROM     table(s)
WHERE    row condition   (=, <, >, AND, OR, LIKE, IN, BETWEEN, IS NULL)
GROUP BY column          (one result row per group)
HAVING   group condition
ORDER BY column [ASC|DESC];

LIKE '%London%' matches any text containing London; IN ('a','b') matches a list; BETWEEN 200 AND 300 is an inclusive range; COUNT(*) counts rows. A join combines tables on a matching column; a subquery is a SELECT inside another; a view is a stored SELECT (CREATE VIEW).

DTS224 25/26, Q1c, as printed.

Exam questionPQ 25/26 Q1c

BRANCH(branch_no, street, city, postcode); STAFF(staff_no, fName, lName, position, sex, DOB, salary, branch_no); PROPERTYFORRENT(property_no, street, city, postcode, type, rooms, rent, staff_no, branch_no). Write SQL: (i) staff earning over 100000, highest first; (ii) staff count per branch; (iii) average salary per branch; (iv) properties with more than 3 rooms and rent above 80000; (v) property number, type, rent, and the responsible staff member's full name; (vi) branches with no staff.

Answer
(i)   SELECT * FROM STAFF WHERE salary > 100000 ORDER BY salary DESC;

(ii)  SELECT branch_no, COUNT(*) AS total FROM STAFF GROUP BY branch_no;

(iii) SELECT branch_no, AVG(salary) AS avg_salary FROM STAFF GROUP BY branch_no;

(iv)  SELECT * FROM PROPERTYFORRENT WHERE rooms > 3 AND rent > 80000;

(v)   SELECT p.property_no, p.type, p.rent, s.fName, s.lName
      FROM   PROPERTYFORRENT p JOIN STAFF s ON p.staff_no = s.staff_no;

(vi)  SELECT branch_no FROM BRANCH
      WHERE  branch_no NOT IN (SELECT branch_no FROM STAFF);

(vi) is the anti-join: the branches whose number never appears in STAFF. This is the one most people miss.

Exam questionPQ 23/24 Q1b

Emp(Eid, Ename, Age, Salary); Works(Eid, Did, per_time); Dept(Did, Dname, Budget, managerId). Write SQL to: (i) create the relations; (ii) add a 40-year-old Azi Esther, Eid 101, salary 15000; (iii) give every employee a 10% rise; (iv) delete the Toy department; (v) set the Account department budget to 8 million; (vi) remove the Dept relation; (vii) list Emp with Eid first.

Answer
(i)   CREATE TABLE Emp (
        Eid INT PRIMARY KEY, Ename VARCHAR(30),
        Age INT, Salary DECIMAL(10,2) );
      CREATE TABLE Dept (
        Did INT PRIMARY KEY, Dname VARCHAR(20),
        Budget DECIMAL(12,2), managerId INT );
      CREATE TABLE Works (
        Eid INT, Did INT, per_time INT,
        PRIMARY KEY (Eid, Did),
        FOREIGN KEY (Eid) REFERENCES Emp(Eid),
        FOREIGN KEY (Did) REFERENCES Dept(Did) );

(ii)  INSERT INTO Emp VALUES (101, 'Azi Esther', 40, 15000);
(iii) UPDATE Emp SET Salary = Salary * 1.10;
(iv)  DELETE FROM Dept WHERE Dname = 'Toy';
(v)   UPDATE Dept SET Budget = 8000000 WHERE Dname = 'Account';
(vi)  DROP TABLE Dept;
(vii) SELECT Eid, Ename, Age, Salary FROM Emp;

(vii) column order in the result is chosen by naming the columns in the SELECT; changing the stored order would mean recreating the table.

Hotel(hotelNo, hotelName, city); Room(roomNo, hotelNo, type, price); Booking(hotelNo, guestNo, dateFrom, dateTo, roomNo); Guest(guestNo, guestName, guestAddress).

-- how many hotels
SELECT COUNT(*) FROM Hotel;
-- full details of all hotels in London
SELECT * FROM Hotel WHERE city = 'London';
-- number of rooms in each hotel
SELECT hotelNo, COUNT(*) AS rooms FROM Room GROUP BY hotelNo;
-- guests in London, alphabetically by name (pattern match)
SELECT guestName, guestAddress FROM Guest
WHERE  guestAddress LIKE '%London%' ORDER BY guestName;
-- double or family rooms below 40 per night, cheapest first
SELECT * FROM Room WHERE type IN ('double','family') AND price < 40
ORDER BY price;
-- bookings with no dateTo
SELECT * FROM Booking WHERE dateTo IS NULL;

TrapNULL and COUNT

To find rows with a missing value you must write IS NULL, never = NULL (nothing equals NULL, not even NULL). And COUNT(column) skips NULLs in that column, while COUNT(*) counts every row: choose the one the question means.

RecallCover the answers

1. Which clause filters rows? Which filters groups?

2. Write the condition for "address contains Glasgow".

3. How do you count rows per branch?

4. What enforces referential integrity in a CREATE TABLE?

5. How do you find bookings with no end date?

Answers

1. WHERE filters rows; HAVING filters groups. 2. address LIKE '%Glasgow%'. 3. SELECT branch, COUNT(*) FROM ... GROUP BY branch. 4. A FOREIGN KEY ... REFERENCES clause. 5. WHERE dateTo IS NULL.
