Before you start

How to use this manual

This is not a book to read. It is a book to be tested by. Reading feels productive and teaches almost nothing; retrieval is what sticks. So on nearly every page you will be asked a question before you are given an answer. Cover the answer, attempt it aloud or on paper, and only then look.

The whole of TMC221 is five lecture decks. This manual carries every idea, name, number, definition and acronym in those decks, and then it tests each one in the exact styles the real test uses. Nothing from the slides is left out, and nothing is tested as a vague essay: every fact is drilled as a specific, checkable question.

The exam, exactly as it comes

The test is a computer-based quiz. Each question is tagged with the lecture it comes from and is marked out of 1. There are five question styles, and this manual drills all five:

StyleWhat you doWatch for
Single MCQChoose one of four options.Two options are close; one is exactly right.
Multiple response"Select all that apply", usually two correct.Miss one and you may lose the mark.
MatchingPair each item with its label via a dropdown.Labels are near-synonyms; know the precise term.
True / FalseJudge one statement.False statements are deliberately true-sounding.
ClozeComplete a scenario with several dropdown blanks.Each blank is its own mark; finish them all.
Must Memorisethe golden rule of this test
This test does not reward opinions or general life advice. It rewards the exact wording and the precise distinction from the slides: an activity is not a Key Result, fear is replaced not managed, a niche is a launch pad not a limitation, a vision is not simply a bigger dream. When two answers feel right, the exam wants the one that matches the slide.
Memory hook: they test the slide, not your good sense. Answer the slide.

How to work through this manual

  1. Read each Teach box once, then cover it and say it back.
  2. Do every drill honestly, answer first, check second. A drill you read the answer to is a drill wasted.
  3. Learn every gold box cold, hook and all.
  4. Study the Traps: the exam is built from exactly those wrong answers.
  5. When the modules are done, sit the fully worked real test, then the three mock exams under time.
  6. Finish on the Master Cram Sheet the night before.
