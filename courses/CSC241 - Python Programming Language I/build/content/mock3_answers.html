Question One

AnswerQ1 (a) the or operator

or is a boolean operator that joins two conditions and is true when at least one of them is true. It is false only when both are false, the mirror of and.

>>> age = 15
>>> age < 13 or age > 65
False
>>> age < 18 or age > 65
True

Like and, it short-circuits: if the left is already true, Python does not bother looking at the right, because the answer is settled.

Question Two

AnswerQ2 (a) condition-controlled loop

A condition-controlled loop runs an unknown number of times, repeating as long as a condition stays true and stopping when it turns false. In Python it is the while loop. You use it when you do not know in advance how many passes are needed, such as reading until a sentinel.

total = 0
while total < 100:
    total += int(input("Add: "))

It contrasts with a count-controlled for loop, which runs a known, fixed number of times.

AnswerQ2 (b) control structures
  • Sequence: statements run in order, top to bottom. x = 1; y = 2; print(x + y)
  • Selection: a choice with if/elif/else. if age >= 18: print("Adult")
  • Repetition: a block many times, with for or while. while n > 0: n -= 1

Question Three

AnswerQ3 (a) five benefits

Reuse; readability; maintenance; decomposition into small testable pieces; and abstraction, using a function by what it does rather than how. A sixth if needed: collaboration, since a team can split the functions between them.

AnswerQ3 (b) functions, parameter vs argument

A function is a named block of code that runs when called. Functions matter for reuse, readability, maintenance and decomposition.

A parameter is the name in the definition; an argument is the actual value you pass when you call. In def greet(name), name is the parameter; in greet("Ada"), "Ada" is the argument. Parameter is the empty slot, argument is what you drop into it.

AnswerQ3 (c) the list trace
  • [0] * 3 repeats the list, so a is [0, 0, 0].
  • b.append([4, 5]) adds the list [4, 5] as a single item, so b is [1, 2, 3, [4, 5]].
  • len(b) is 4: three numbers and one inner list, which counts as one.
a = [0, 0, 0]
b = [1, 2, 3, [4, 5]]
len(b) = 4

The trap is expecting append to spread [4, 5] into two items. It does not: it appends the list whole. That is why len(b) is 4, not 5. To spread, you would use b += [4, 5] or b.extend([4, 5]).

Question Four

AnswerQ4 (a) lists are mutable

Mutable means a list can be changed in place after it is made: you can reassign an item, add one, or remove one, and it is still the same list.

>>> nums = [10, 20, 30]
>>> nums[0] = 99
>>> nums
[99, 20, 30]

The reason it matters: a string is immutable and refuses s[0] = "x" with a TypeError, while a list allows it. So a list is the structure you reach for when the data must change as the program runs.

AnswerQ4 (b) the half function

(i) result = half(10). (ii) half(10) returns 10 / 2, and / always gives a float, so:

result = 5.0

Note 5.0, not 5: true division / returns a float even when the result is whole. That decimal point is worth a mark.

AnswerQ6 (c) the cylinder tank
tank.py
import math

def volume(r, h):
    return math.pi * r ** 2 * h

radius = float(input("Radius: "))
height = float(input("Height: "))

v = volume(radius, height)
print(f"Volume: {v:.2f}")
if v > 1000:
    print("Large tank")
else:
    print("Small tank")

For radius 7 and height 10:

Volume: 1539.38
Large tank

math.pi * 7 ** 2 * 10 is math.pi * 49 * 10 = 1539.38. The ** 2 binds before the multiplications, so the radius is squared first, no brackets needed. 1539.38 exceeds 1000, so it is a large tank.
