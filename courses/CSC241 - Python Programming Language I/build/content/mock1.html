Question One17.5 marks

(a) Explain the differences among the three main types of control structures in Python. Give one example of each. [3.5mks]

(b) The following code is intended to print all odd numbers from 1 to 9, skipping the number 5. Identify and correct the error(s): [3.5mks]

n = 1
while n <= 9:
    if n % 2 != 0:
        if n == 5:
            continue
        print(n)
    n += 1

for i in range(1, 6):

(d) You are writing the ticketing system for a cinema. The price depends on the customer's age. Your program should use decision making structures to implement the logic. [3.5mks]

Program requirements:

  1. Prompt the user to enter an integer for the age.
  2. Check that the age is positive.
  3. If the age is under 13, print "Child - N500".
  4. Else if the age is under 18, print "Teen - N800".
  5. Else if the age is 60 or over, print "Senior - N600".
  6. Else, print "Adult - N1200".
  7. If the age is not positive, print "Please enter a valid age".

(e) Develop a new ticketing system as an extension of the one you did in (d) above. This updated version should allow the user to enter multiple ages in one input, separated by spaces. [3.5mks]

Program requirements:

  1. Prompt the user to enter multiple ages separated by spaces.
  2. Split the input and convert each item to an integer.
  3. For each age entered, check it is positive, apply the pricing logic, and display the category.
  4. After all ages, display the total number of tickets priced.

(d) You have been asked to build a results tool for a department. The program should define a function grade(score) that returns "A" for 70 and above, "B" for 60 to 69, "C" for 50 to 59, and "F" below 50. Student: Ada | Score: 72 | Grade: A

...

Program requirements:

  1. Define grade(score) returning the letter as described.
  2. In the main program, use a loop to collect each student's name and score.
  3. For each student, call the function and determine the grade.
  4. Display the result in a clean, formatted output.

(e) Develop a new results tool as an extension of (d). This version should allow any number of students (not just three), all in one session. [3.5mks]

Program requirements:

  1. Define grade(score) as before.
  2. Use a loop to repeatedly accept student names and scores.
  3. Stop the loop when the user enters 'done' as the name.
  4. For each student, call the function and display the grade.
  5. After the loop, display summary statistics: how many students, and how many passed. A pass is 50 and above.
