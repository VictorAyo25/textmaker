(d) You are writing the billing program for an electricity company. The charge depends on the number of units consumed. Your program should use decision making structures to implement the logic. [3.5mks]

Program requirements:

  1. Prompt the user to enter an integer for the units consumed.
  2. Check that the reading is positive.
  3. If the units are under 50, the band is "Lifeline" at N10 per unit.
  4. Else if the units are under 200, the band is "Domestic" at N20 per unit.
  5. Else, the band is "Commercial" at N30 per unit.
  6. Print the band and the bill, which is the units times the rate.
  7. If the reading is not positive, print "Please enter a valid reading".

(e) Develop a new billing program as an extension of the one you did in (d) above. This updated version should allow the user to enter several meter readings in one input, separated by spaces. [3.5mks]

Program requirements:

  1. Prompt the user to enter all the readings separated by spaces.
  2. Split the input and convert each item to an integer.
  3. For each reading, check it is positive, apply the banding, and display the band and the bill.
  4. After all readings, display how many were billed and the total of all the bills.
