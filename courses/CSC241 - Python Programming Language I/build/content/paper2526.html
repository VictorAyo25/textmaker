AnswerQ1 (a) the and operator, 2.5 marks

and is a boolean operator. It joins two conditions and is true only when both are true. If either side is false, the whole thing is false.

LeftRightleft and right
TrueTrueTrue

FalseTrueFalse
FalseFalseFalse

The example the marker wants is a range check:

AnswerQ1 (d) BMI, 3.5 marks

elif bmi < 30:

The elif ladder needs no upper bound on each rung: by the time you reach elif bmi < 25, the first if has already ruled out everything below 18.5, so < 25 alone means the 18.5 to 25 band. That is the whole economy of elif.

What is a count-controlled loop in Python? [3.5 mark]

Break it downBefore you write anything
What is actually asked

A definition. One clear sentence plus a short example is the whole answer.

What the marks say

Where it is taught

Module Three, Unit 2 (Loops).

AnswerQ2 (a) count-controlled loop, 3.5 marks

A count-controlled loop runs a known, fixed number of times, once per item in a sequence. In Python it is the for loop with range. You use it when you know how many passes you need before the loop starts.

for i in range(5):
    print(i)

It contrasts with a condition-controlled loop (while), which runs an unknown number of times, until a condition turns false. Count-controlled: "do this five times". Condition-controlled: "do this until the user types done".

As printed2025/2026 paper, Question Two (b)

Explain the differences among the main types of control structures in Python. Give one example of each. [4.5 marks]

Break it downBefore you write anything
What is actually asked

"Differences among" means compare them against each other, not define each in isolation. Then one example each.

What I should name

Sequence, selection and repetition. Naming only if and for misses a third of the answer.

What the marks say

Where it is taught

Module Three, Units 1 and 2.

AnswerQ2 (b) control structures, 4.5 marks

There are three kinds of control structure, and the answer names all three with an example each:

  • Sequence: statements run top to bottom, in order. The default. a = 2; b = 3; print(a + b)
  • Selection: a choice, with if/elif/else. if score >= 50: print("Pass")
  • Repetition: doing something many times, with for or while. for i in range(3): print(i)

The difference is what decides the flow: sequence has no decision, selection runs a block or skips it once, repetition runs a block again and again.

AnswerQ2 (d) the control-structures program, 6.5 marks

Six tasks in one program. Take them in order: a password loop, a validated score, a grade, a multiplication table, then a running sum. Each is a control structure from Module Three.

system.py
# i. password loop
while True:
    pw = input("Password: ")
    if pw == "admin123":
        print("Access Granted")
        break
    print("Access Denied")

# ii and iii. read a score and validate it
score = int(input("Score: "))
if score < 0 or score > 100:
    print("Error: score must be between 0 and 100")
else:
    # iv. grade it
    if score >= 70:
        print("Grade A")
    elif score >= 60:
        print("Grade B")
    elif score >= 50:
        print("Grade C")
    elif score >= 45:
        print("Grade D")
    else:
        print("Grade F")

# v. multiplication table 1 to 12
num = int(input("Number: "))
for i in range(1, 13):
    print(f"{num} x {i} = {num * i}")

# vi. sum until 0
total = 0
count = 0
while True:
    n = int(input("Number (0 to stop): "))
    if n == 0:
        break
    total += n
    count += 1
print("Sum:", total)
print("Count:", count)

The grade ladder is the same elif economy as the BMI: each rung needs only its lower bound, because the rungs above have already been ruled out. The order matters: put >= 45 before >= 70 and every score would grade D. Ranges must be tested high to low.

The two while True loops are the two loop patterns from Module Three, Unit Two: one broken by a right password, one by a sentinel of 0.

AnswerQ4 (a) strings are immutable

Immutable means a string cannot be changed after it is made. Trying to change one character is an error:

>>> s = "cat"
>>> s[0] = "b"
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'str' object does not support item assignment

The reason: every method that "changes" a string, like upper() or replace(), actually returns a new string and leaves the original untouched. To "edit" a string you build a new one and reassign it: s = s.replace("c", "b"). A list, by contrast, is mutable and does allow list[0] = "b".

AnswerQ4 (c) the SQLite program, 10.5 marks

The biggest single part on the paper, and it walks through the whole of Module Five, Unit One plus the new WHERE, UPDATE, DELETE and summary functions. Take the seven requirements in order.

school.py
import sqlite3

conn = sqlite3.connect("school.db")
cursor = conn.cursor()

# i. create the table if it is not there
cursor.execute("""CREATE TABLE IF NOT EXISTS student
                  (StudentID INTEGER PRIMARY KEY, StudentName TEXT,
                   Class TEXT, Score REAL)""")

# ii. insert the given records
records = [(101, "David James", "SS1", 78),
           (102, "Mary Johnson", "SS2", 85),
           (103, "Peter Okoro", "SS1", 67),
           (104, "Grace Bello", "SS3", 92),
           (105, "Esther Ade", "SS2", 74)]
cursor.executemany("INSERT INTO student VALUES (?, ?, ?, ?)", records)
conn.commit()

# iii. all records
print("All students:")
cursor.execute("SELECT * FROM student")
for row in cursor.fetchall():
    print(row)

# iv. SS2 only
print("SS2 students:")
cursor.execute("SELECT * FROM student WHERE Class = ?", ("SS2",))
for row in cursor.fetchall():
    print(row)

# v. statistics in one query
cursor.execute("SELECT COUNT(*), MAX(Score), AVG(Score) FROM student")
total, highest, average = cursor.fetchone()
print("Total:", total, " Highest:", highest, " Average:", average)

# vi. update Peter's score
cursor.execute("UPDATE student SET Score = ? WHERE StudentName = ?",
               (75, "Peter Okoro"))
conn.commit()

# vii. delete student 105
cursor.execute("DELETE FROM student WHERE StudentID = ?", (105,))
conn.commit()

conn.close()

AnswerQ5 (c) reading vs appending, 2 marks

Reading ("r") takes data out of a file and changes nothing. Appending ("a") adds new data to the end, keeping what is already there. Reading needs the file to exist; appending creates it if it does not. In short: one looks, the other adds without erasing.

AnswerQ5 (d) the CA records file, 7.5 marks

Write the first records with "w", add more with "a" so the first are kept, then read the whole file and just the first five. The same file name throughout, as the question insists.

ca_records.py
filename = "23CG012345_CSC241.txt"

# i. first 10 records, "w" starts the file fresh
with open(filename, "w") as f:
    for i in range(10):
        name = input("Name: ")
        matric = input("Matric No: ")
        dept = input("Department: ")
        score = input("Score: ")
        f.write(f"Name: {name}, Matric No: {matric}, "
                f"Department: {dept}, Score: {score}\n")

# ii. 5 more, "a" keeps the first ten
with open(filename, "a") as f:
    for i in range(5):
        name = input("Name: ")
        matric = input("Matric No: ")
        dept = input("Department: ")
        score = input("Score: ")
        f.write(f"Name: {name}, Matric No: {matric}, "
                f"Department: {dept}, Score: {score}\n")

# iii. read and show all
print("All records:")
with open(filename, "r") as f:
    for line in f:
        print(line.strip())

# iv. read and show the first five
print("First five:")
with open(filename, "r") as f:
    for i, line in enumerate(f):
        if i >= 5:
            break
        print(line.strip())

The marks live in the modes: "w" once at the start, then "a" so the append does not wipe the ten already written. If both used "w", the second open would erase the first ten before adding five, and you would end with five records, not fifteen. Reading the first five uses enumerate and break to stop early, from Module Three.

def display_achievement_summary(user_name, actual_total, target_total):
    print(f"--- Progress Report for {user_name} ---")
    print("Total Steps:", actual_total)
    if actual_total >= target_total:

    else:
        print("Milestone Not Achieved.")

name = input("Enter your name: ")
days = int(input("Enter the number of days to track: "))
goal = int(input("Enter your daily step goal: "))

total_steps = 0

    total_steps += steps

target = goal * days
display_achievement_summary(name, total_steps, target)

AnswerQ6 (c) value-returning functions and math.pi, 7 marks

Three value-returning functions, each handing a value back, and math.pi for the area of the circle. This is the modular style the question demands.

flooring.py
import math

def get_data():
    radius = float(input("Enter room radius (meters): "))
    price = float(input("Enter flooring price per square meter: "))
    labor = float(input("Enter labor fee: "))
    return radius, price, labor

def calculate_area(radius):
    return math.pi * radius ** 2

def calculate_total(area, material_price, labor_fee):
    return area * material_price + labor_fee

radius, price, labor = get_data()
area = calculate_area(radius)
total_cost = calculate_total(area, price, labor)

print("--- Project Estimate ---")
print(f"Total Calculated Cost: {total_cost:.2f}")
if total_cost > 10000:
    print("Status: Requires Senior Management Approval.")
else:
    print("Status: Approval not required.")
