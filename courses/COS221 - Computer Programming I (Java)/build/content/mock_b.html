  1. State the five outputs for this code. You may show your workings, but make the answer bold.
  2. Retain everything else, but change the For loop to a While loop and the While loops to For loops.
public class AutomorphicChecker {    public static void main(String[] args) {        int[] numbers = {5, 6, 7, 25, 76};        for (int idx = 0; idx < numbers.length; idx++) {            int n = numbers[idx], digits = 0, temp = n;            while (temp > 0) { digits++; temp /= 10; }            int power = 1;            for (int p = 0; p < digits; p++) power *= 10;            int tail = (n * n) % power;            System.out.println(n + " -> " + (tail == n ? public class PrimeClassifier {    public static void main(String[] args) {        int primeCount = 0, compositeCount = 0, neitherCount = 0;        for (int num = 1; num <= 30; num++) {            int divisors = 0;            for (int d = 1; d <= num; d++) {                if (num % d == 0) divisors++;            }            if (divisors == 2) primeCount++;            else if (divisors > 2) compositeCount++;            else neitherCount++;        }        System.out.println("Prime: " + primeCount + ", Composite: " + compositeCount            + ", Neither: " + neitherCount);    }}

Q5 A · Courier pricing12 MARKS

A courier needs a program (using JOptionPane only, for all input and output) that prices parcels across up to three delivery zones and produces a sales summary. Implement the following four methods.

  1. create a method that takes in a zone number. Use a switch statement to return a base rate for Zone 1, Zone 2 or Zone 3 (pick any three distinct rates and state them clearly). If the zone number is not 1, 2 or 3, throw an IllegalArgumentException;
  2. create a method that takes in a tier and a parcel weight in kg. Use nested if-else statements (not a switch, and not independent/separate if checks) to return a surcharge percentage:
    • Gold, over 20 kg, 5%
    • Gold, 20 kg or under, 0%
    • Silver, over 20 kg, 15%
    • Silver, 20 kg or under, 10%
    • Bronze (any weight), 25%
    • any tier string that is not "Gold" or "Silver" must be treated as "Bronze"

    The nesting must reflect that the weight is only checked within each tier branch, not as a separate top-level check.

  3. create a method that takes in a base rate total and a surcharge percentage and applies the surcharge to the base total. If the surcharged amount is above 500.0, the method should return 500.0 instead (a price ceiling);
  4. main()
    • ask the user for the number of parcels N (a positive integer);
    • loop exactly N times. In each iteration, ask for that parcel's number of zones crossed (an integer from 1 to 3, inclusive), its tier, and its weight in kg. For each zone from 1 up to that parcel's zone count, call the method from part (i) and add the result to that parcel's running base total (a running total that starts at 0 for each new parcel). Then call the method from part (ii) to get the surcharge percentage, and the method from part (iii) to get that parcel's final price;
    • accumulate: (a) total revenue across all parcels, and (b) a running count of how many parcels were Gold, Silver and Bronze;
  5. after the loop, show one summary dialog with the total revenue and the three tier counts.

Section C, Question Six

Q6 A · Digit pattern12 MARKS

Design and implement a program, using JOptionPane only for input and output, that classifies a single user-supplied positive integer N according to its digit pattern.

Definition. A number is monotone if its digits never decrease from left to right. For example, 1237 and 1119 are monotone; 4821 is not. The digit product is every digit multiplied together, so the digit product of 1237 is 42.

Constraints. The entire task must be implemented inside main() only, using loops and nested/chained if-else and/or switch logic. No arrays and no user-defined helper methods are permitted; everything must be inline.

  1. using a loop built only on the % and / operators (no converting N to a String or an array), compute, in the same loop:
    • the digit product of N, and
    • the largest digit of N;
  2. determine, in that same loop, whether N is monotone;
  3. inline in main() (not a separate method), determine whether the digit product from step 1 is itself a prime number. Use a loop that tests divisibility only up to the square root of the digit product;
  4. using nested/chained conditional logic, classify N into exactly one of the following, checked strictly in this priority order:
    • "MONOTONE-PRIME-PRODUCT": N is monotone AND its digit product is prime
    • "MONOTONE": N is monotone but its digit product is not prime
    • "ZERO-PRODUCT": N is not monotone but contains a digit 0
    • "STANDARD": in every other case
  5. display N, its digit product, its largest digit, and its final classification in a single JOptionPane message dialog.
Q6 B · Library fines13 MARKS

A library needs a program, using JOptionPane only for input and output, to process a batch of overdue books returned on the same day and calculate the total fines owed. The program must use clear separation of concerns: each task below must be its own method. No collection classes (for example ArrayList) are allowed anywhere.

  1. prompt for the number of overdue books, V. Then, using a loop, fill two parallel arrays of length V:
    • the number of days each book is late (an integer per book). A value of 0 or below is invalid; use a nested control statement to keep re-prompting until a valid value is entered;
    • the member type for each book (a String per book, either "Student" or "Public");
  2. create a method that takes in one book's days late and member type, and computes that book's fine using nested if-else logic (the rules below must be nested together, not checked as separate independent conditions):
    • Student: the first 3 days are free; each additional day costs 20.00; capped at a maximum of 200.00;
    • Public: no free period; the first 5 days cost a flat 150.00; each day beyond 5 costs 40.00; capped at a maximum of 500.00;
    • any member type that is not exactly "Student" must be treated as "Public";
  3. create a method that takes in the array of days late, loops over it and tallies the books into three bands: SHORT (1 to 3 days), MEDIUM (4 to 10 days), EXTENDED (more than 10 days). Return these three counts without using any collection class;
  4. in main():
    • call the method from part (ii) for every book across both parallel arrays to accumulate the batch's total fines;
    • call the method from part (iii) once;
    • display one final JOptionPane showing the total fines and the three band counts.
