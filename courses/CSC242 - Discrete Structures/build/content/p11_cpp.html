The Same Tools in C++

The older papers set their programs in C++, so here are the same seven tools in that language: the skeleton, printing and reading, the types this course needs, arithmetic, conditions, both kinds of loop, arrays through vector, functions, and the bit operations. If you have read section 11.1 you have met every idea already and this section only changes the spelling; answer in whichever language you will write in the hall.

By the end of this section you will be able to write and read a complete C++ program and set it beside its Python twin: the skeleton, printing and reading, the types, arithmetic including integer division and remainder, conditions, both kinds of loop, vector, functions with a return value, and the bit operations that turn a subset into a number.

The skeleton

Must memoriseThe shape every program has

Write this out from memory once, and you have the first mark of any programming question before you have thought about the problem.

The smallest complete program
// A comment. Everything after two slashes is ignored by the compiler.
#include <iostream>         // brings cout and cin into the program
using namespace std;      // lets us write cout, not std::cout

int main() {                // execution starts here
    cout << "Hello" << endl;
    return 0;                // 0 means "finished normally"
}
Where #include <iostream> pulls in the input and output facilities. Without it the compiler has never heard of cout and the program does not build. using namespace std; saves writing std:: in front of every library name. Real projects avoid it; exam answers use it, and so does this book. int main() is the entry point. Every program has exactly one, and the machine begins there. { } braces enclose a block: a group of statements treated as one. cout is the output stream, read "see out", and it sends what follows to the screen. << is the insertion operator. Read it as an arrow pointing at cout: the value flows into the stream. It can be chained, so one line may print several things. endl ends the line and is short for "end line". ; ends a statement. It is not optional and it is the single most common thing candidates leave out. return 0; hands 0 back to whatever started the program, meaning success.

Memory hook: include, namespace, main, return. Four lines, always the same, before any thinking happens.

Values and variables

Must memoriseThe types this course needs

C++ makes you say what kind of value a name holds. Five types cover every examined question.

Where int n = 24; reads: make a whole-number box called n and put 24 in it. The type comes first, then the name, then the value. = is assignment, not equality. It puts the right side into the left. The test for equality is ==, with two signs, and confusing the two is the classic C++ error. string needs its own line, #include <string>, at the top. '1' and "1" are different things: single quotes make one character, double quotes make text. A bit string is built from the first and printed as the second.

Why long long matters here. An int runs out at about two thousand million. The password count of section 5.1 is 2684483063360, which is far past that, and storing it in an int silently gives a wrong answer rather than an error. If a count can be large, say long long.

Reading input, and making choices

Teachcin, if and else

cin is the input stream, and >> is the extraction operator: the arrow points away from cin and into the variable you name.

Reading a number and testing it
int n;
cout << "Enter an integer: ";   // always prompt; a bare cursor is not a program
cin >> n;                        // wait for the user, then store it in n

if (n % 2 == 0) {
    cout << n << " is even" << endl;
} else {
    cout << n << " is odd" << endl;
}

The condition goes in round brackets and the branch in braces. The else part is optional. Note that the test is ==: a single = would assign 0 to the remainder rather than compare with it, and the compiler will let you.

Dynamic input is what "dynamically" means in an exam question. The 2023/2024 paper asks for a program that "dynamically takes these sets as input"; that is a request for cin, not for the three sets typed into the source as constants. A program with the answer already written into it has not been asked for.

Loops

Must memorisefor and while

Two loops, and the choice between them is mechanical.

A for loop: use it when you know how many times
for (int i = 0; i < n; i++) {
    cout << i << " ";
}
A while loop: use it when you stop on a condition
while (low <= high) {
    // keep going until the range is empty
}
Where int i = 0 is the start, run once before the first pass. i < n is the condition, tested before every pass; the loop ends the first time it is false. i++ is the step, run after every pass, and it means "add one to i". i is the loop variable, and counting from 0 rather than 1 is the C++ convention. A loop over n items runs i = 0, 1, ..., n − 1, which is n passes. while takes only the condition, so anything that makes it eventually false has to happen inside the body. If nothing does, the program never stops.

Memory hook: for counts, while waits. A known number of passes is a for; a search that ends when it finds something is a while.

The off-by-one to expect. i < n gives n passes; i <= n gives n + 1 and reads past the end of an n-element array. This is the same one-fewer-than-you-think that section 9.3 met in an = a + (n − 1)d.

Many values at once

Must memorisevector, a list that knows its own length
Declaring, filling and reading a vector
#include <vector>                // needed at the top of the file

int n = 3;
vector<int> s(n);                 // three ints, all 0 to begin with

for (int i = 0; i < n; i++) cin >> s[i];   // fill it from the keyboard
cout << s[0] << " and there are " << s.size() << " of them";
Where vector<int> means "a list of int". The type in the angle brackets is what it holds, so vector<string> is a list of text. s(n) creates it with n slots. The size may be a variable, which is exactly what "dynamically" needs and what a plain fixed-size array cannot do. s[i] is the slot at position i, counting from 0. So a three-element vector has slots s[0], s[1], s[2], and s[3] does not exist. s.size() is how many slots there are. The dot means "of this object", and the brackets are there because it is a function call.

Position 0 is not a quirk to work around. It is the reason bits[m - 1] appears in the bit-string program: element m of the universe {1, ..., 10} lives at slot m − 1. Write that subtraction down deliberately rather than discovering it by being one out.

Functions

Must memoriseWriting a function and calling it

A function is a named piece of program that takes values in and hands one value back. It is the section 4.1 idea of a function, made executable.

Definition, then use
// returns the larger of two whole numbers
int larger(int a, int b) {
    if (a > b) return a;
    return b;
}

int main() {
    cout << larger(3, 9);          // prints 9
    return 0;
}
Where int larger(...) the leading int is the return type: the kind of value handed back. A function that hands nothing back is declared void. (int a, int b) are the parameters: names for the values passed in, each with its own type. These are the domain of section 4.1. return a; hands a value back and stops the function immediately. Everything after it in that path is not run. larger(3, 9) is the call. The whole expression stands for the value returned, so it can be printed, stored or used in arithmetic. const vector<int>& s, which appears in the programs below, is a parameter that receives the list without copying it, and const promises the function will not change it. Say that in one line if a marker asks; nothing else about references is examined.

A function must appear before the line that calls it, or the compiler has not met it yet. Defining every helper above main avoids the question entirely, and every program in the next section does that.

Bits, and why a subset is a number

TeachThe two operators the power set needs

Section 2.3 encoded a subset as a bit string: one bit per element of the universe, 1 when the element is in. C++ can hold that string of bits as a single whole number and test one bit at a time, which turns "list every subset" into "count from 0 upwards".

WrittenReadDoes
1 << ione shifted left by ia number with a single 1 bit, at position i
mask & (1 << i)mask AND thatnon-zero exactly when bit i of mask is 1
Where << here is the shift operator, not the printing one. Which meaning applies is decided by what sits on its left: a stream means print, a number means shift. Both spellings are the same two characters and this is a genuine wart of the language. & with one ampersand is bitwise and: it lines the two numbers up bit by bit and keeps a 1 only where both have one. Two ampersands, &&, is the logical and of Part One; the two are not interchangeable. mask is the number whose bits name a subset: bit i is 1 when element i is in. position i counts from 0 at the right-hand end, so 1 << 0 is 1, 1 << 1 is 2, 1 << 2 is 4.

Read the right-hand column downwards and compare it with the sample output printed on the 2024/2025 paper. They are in the same order, because counting 0 to 7 is the enumeration the examiner printed. That is not a coincidence to be grateful for; it is the reason the power set of an n-element set has 2n members, which section 2.1 proved by a different route.

Answers

1. #include <iostream>, using namespace std;, int main() {, and return 0; }.
2. = assigns the right side into the left; == tests whether the two are equal.
3. 3 and 1. Division between whole numbers discards the fraction, and % gives what was discarded.
4. A for loop when the number of passes is known in advance; a while loop when you stop on a condition.
5. s[0], and the last is s[n - 1].
6. Whether bit i of mask is 1, that is whether element i is in the subset that mask encodes.
7. Because element m of the universe {1, ..., 10} sits at slot m − 1, since slots count from 0.
