Propositions and Truth Tables

Everything in this part is built from one idea: a sentence that is definitely true or definitely false, and nothing in between.

By the end of this section you will be able to say whether a sentence is a proposition, write an English sentence in symbols, build a truth table for any compound proposition however tangled, and name a proposition as a tautology, a contradiction or a contingency.

What a proposition is

TeachThe starting point

A proposition is a declarative sentence that is either true or false, but not both.

Three phrases in that definition are doing work. Declarative means it declares something, so it is not a question or a command. Either true or false means it has a definite truth value, even if nobody present knows which. Not both means it cannot be true in one breath and false in the next.

Must memoriseDefinition

A proposition is a declarative sentence that is either true or false, but not both.

Propositions are written with letters, usually p, q, r, s. A letter standing for a proposition is a propositional variable. The two truth values are written T for true and F for false.

Memory hook: if you can sensibly answer "is that true?", it is a proposition. You cannot answer that about a question or an order.

The connectives

TeachBuilding bigger statements

Single propositions are not very interesting. We join them with connectives to make compound propositions, and the whole of this part is the study of how the truth of the pieces fixes the truth of the whole.

Each connective is defined by a truth table: a table listing every possible combination of truth values for the pieces, with the resulting value for the whole. A truth table is not an explanation of a connective, it is the connective. There is nothing more to know about "and" in logic than the four rows of its table.

TrapThe row that costs marks every year

Look at row 3 of p → q: p is false, q is true, and the implication is true. Now row 4: both false, and it is true again.

Students reject this because it feels wrong. "If I pass, I will celebrate" seems to say nothing about what happens when I fail. Exactly: it says nothing, and a promise that says nothing about a case has not been broken in that case. An implication is a promise, and a promise is false only when it is broken, which needs p true and q false.

p → q is false in exactly one case: p true, q false. Learn that as a single fact and the other three rows follow.

TeachWhy "or" needs care

English uses "or" in two ways. "Tea or coffee?" usually means one or the other but not both. "Applicants must have a degree or five years of experience" means at least one, and having both is fine.

Logic splits these. Disjunction (∨) is the inclusive one: true when at least one part is true, including when both are. Exclusive or (⊕) is the other: true when exactly one is true. Compare the rows where p and q are both true: ∨ gives T, ⊕ gives F. That single row is the whole difference.

Building a table for a compound proposition

TeachThe method, once, properly

Any compound proposition, however tangled, is handled the same way.

Step 1. Count the letters. With n distinct propositional variables the table has 2n rows: 2 letters give 4 rows, 3 give 8, 4 give 16.

Step 2. Fill the letter columns mechanically. Under the first letter write T for the top half of the rows and F for the bottom half; under the next, alternate in blocks half that size; keep halving. Done this way you cannot miss a combination or write one twice.

Step 3. Work outward from the innermost bracket. Give every intermediate expression its own column. Do not jump to the final answer in one step: you cannot check a step you did not write down, and the marks are for the working.

Step 4. Read the final column. All T is a tautology, all F a contradiction, a mixture a contingency.

Must memoriseThree names for a final column

A compound proposition is a

tautology if it is true for every assignment of truth values, that is, the final column is all T;
contradiction if it is false for every assignment, all F;
contingency if it is neither, true for some assignments and false for others.

Memory hook: a tautology tells you nothing because it is always true, a contradiction is always false, and a contingency depends, which is what "contingent" means in ordinary English.

Taking the rows one at a time, remembering that → is false only for T then F, and ↔ is true only when its two sides match:

Row 1: q is T and ¬p is F, so q → ¬p is F. p ↔ q with both T is T. F against T gives F.
Row 2: q is F, so q → ¬p is T whatever follows it. p ↔ q with T and F is F. T against F gives F.
Row 3: q is T and ¬p is T, so T. p ↔ q with F and T is F. T against F gives F.
Row 4: q is F so the implication is T. p ↔ q with both F is T. T against T gives T.

Three F rows and one T row, so this is a contingency. It is true exactly when p and q are both false.

Answers

1. When p is true and q is false, and in no other.
2. 25 = 32.
3. When both are true: ∨ gives T, ⊕ gives F.
4. No. Its truth depends on x, so it has no truth value until x is fixed. It is a predicate, and Section 1.4 shows how to turn it into a proposition.
