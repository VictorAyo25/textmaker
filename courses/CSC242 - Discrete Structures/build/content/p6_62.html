The Types of Undirected Graph

This is the single most repeated question in the whole set. It has appeared on three of the five papers we hold, worth 12, 12 and 9 marks, and it is always phrased the same way.

By the end of this section you will be able to name and draw every standard type of undirected graph, count the edges of a complete graph, decide which type a given drawing is, and answer the types question and the communication-links questions in full.

The types

Must memoriseThe families by what edges are allowed

The first three types are told apart by one question: what kinds of edge does the graph permit?

TypeLoops?Parallel edges?In one line
Simple graphnonoat most one edge between any two vertices, and none from a vertex to itself
Multigraphnoyesa simple graph that also allows repeated edges between the same pair
Pseudographyesyesanything goes: the most general undirected graph
Where loop is an edge from a vertex to itself, defined in section 6.1. parallel edges are two or more edges joining the same pair, also from 6.1. the nesting matters: every simple graph is a multigraph, and every multigraph is a pseudograph. The families contain one another, they do not exclude one another.

Memory hook: simple, multi, pseudo. Simple forbids both, multi allows repeats, pseudo allows repeats and self-loops. Say them in that order and the permissions only ever grow.

Memory hook: K for complete, C for cycle, P for path, W for wheel, N for null. The subscript is always the number of vertices, except in Km,n where it is the two side sizes.

Must memoriseEdges of a complete graph

The complete graph on n vertices, Kn, has

C(n, 2) = n(n − 1) / 2 edges,

and every vertex has degree n − 1.

Where n is the number of vertices. C(n, 2) is the combination count of section 5.2: an edge is an unordered pair of distinct vertices, and order does not matter because an edge from a to b is the same edge as one from b to a. n − 1 is the degree because each vertex is joined to every other vertex, that is, to all but itself.

The values you will need:

n234567
edges of Kn136101521

Memory hook: every pair, counted once. The "counted once" is the divide by 2, and forgetting it is the standard error: n(n − 1) counts each edge from both ends.

Worked examplePQ 20/21 Q1(a) · PQ 21/22 Q1(c) · PQ 23/24 Q4(a)

How to lay the answer out. One short paragraph per type, each with a small sketch beside it. Open with a single framing sentence, then work down the list. The framing sentence is worth writing because it shows the list is organised rather than remembered:

"An undirected graph is one whose edges have no direction. The types divide first by which edges are permitted, and then by the shape the edges make."

Group 1: told apart by what edges are allowed

  1. Simple graph. No loops and no parallel edges, so at most one edge between any two vertices. Example: a triangle on a, b, c.
  2. Multigraph. Parallel edges are allowed, loops are not. Example: two towns joined by two separate roads.
  3. Pseudograph. Both loops and parallel edges are allowed; the most general undirected graph. Example: a network where a router also has a cable looping back to itself for testing.

Group 2: told apart by shape

  1. Null or empty graph Nn. Vertices but no edges; every vertex is isolated. Example: three computers with no cables between them.
  2. Trivial graph K1. One vertex, no edges. The smallest graph there is, and a special case of the null graph.
  3. Complete graph Kn. Simple, with every pair of distinct vertices joined. It has n(n − 1)/2 edges and every vertex has degree n − 1. Example: K4, four vertices and six edges.
  4. Regular graph. Every vertex has the same degree; k-regular if that degree is k. Example: a cycle is 2-regular, and Kn is (n − 1)-regular.
  5. Cycle graph Cn. The vertices form one closed ring. Example: C5, a pentagon.
  6. Path graph Pn. The vertices in a line, the ring left open. Its two end vertices are pendant.
  7. Wheel graph Wn. A cycle plus a hub joined to every vertex on it. Example: a bicycle wheel, rim and spokes.
  8. Bipartite graph. The vertices split into two sets with every edge running between the sets and none inside either. Example: students on one side, courses on the other, an edge for each enrolment. If every cross pair is joined it is complete bipartite, Km,n.
  9. Connected and disconnected graphs. Connected means a route exists between every pair of vertices. A disconnected graph falls into separate components. Example: the figure in section 6.1 is disconnected, because vertex 4 is joined to nothing.
  10. Weighted graph. Each edge carries a number such as a distance or a cost. Example: the five-city map of section 6.8, whose edges are labelled with mileages.
  11. Subgraph. A graph formed from some of the vertices and some of the edges of another. Example: a triangle inside K4.

Close with one sentence on the nesting, which few candidates write and which shows real understanding: every simple graph is a multigraph, and every multigraph is a pseudograph, so the three families contain one another rather than exclude one another. The shape-based types cut across all three.

Now redo it: which type is a single square with its two diagonals drawn in? Four vertices, every pair joined, no loops or repeats: it is the complete graph K4, and it is also 3-regular.

Counting the possible links

As printed2020/2021 · Q1(b)

(b) Assuming you are required to set up a simple communication link between CSIS, CST Lab, CLR, CUCRID and Senate Building, how many of such simple communication links are possible? Support your answer with a diagrammatical illustration. (6½marks)

As printed2021/2022 · Q2(b)

(b) Assuming CU has contracted you to help set up simple communication links between the SENATE Building, CUCRID, CLR & CSIS NOC. How many of such simple communication links are possible? Support your answer with a diagrammatical illustration. (7½marks)

Note on the paper
These two look identical and are not. Count the buildings. The 2020/2021 version names five (CSIS, CST Lab, CLR, CUCRID, Senate Building) and the 2021/2022 version names four (SENATE Building, CUCRID, CLR, CSIS NOC). Five gives 10 links and four gives 6. Copying the answer across from one paper to the other is the fastest way to lose 6.5 marks, and it is exactly what a candidate who has memorised "the answer is 10" will do.
Break it down
Given
A list of named buildings, and the word simple, which is doing real work: no building links to itself, and no pair is linked twice.
Asked
How many such links are possible, plus a diagrammatical illustration.
Marks say
6.5 and 7.5, which is far more than one combination is worth. The marks are in the modelling and the drawing: say that buildings are vertices and links are edges, name the complete graph, give the formula, then draw it with every edge shown.
Teaches
This section, 6.2, using C(n, 2) from section 5.2.
Trap
Answering n(n − 1) instead of n(n − 1)/2. A link between CLR and CUCRID is the same link as one between CUCRID and CLR, so each pair must be counted once.
Worked examplePQ 20/21 Q1(b) · PQ 21/22 Q2(b)
Given
Five buildings in the 2020/2021 version, four in the 2021/2022 version. Links are simple: no self-links, no repeats.
Find
The number of possible links, and a diagram.
Formula
Links = C(n, 2) = n(n − 1)/2, the edge count of the complete graph Kn.

Step 1. Model it. Let each building be a vertex and each possible communication link an edge. "How many links are possible" asks for the case where every pair is joined, which is the complete graph Kn.

Step 2. Count for five buildings (2020/2021).

links = C(5, 2) = 5 × 4 / 2 = 20 / 2 = 10

List them once to show the count is right: CSIS to each of the other four is 4 links; CST Lab to the three not yet used is 3; CLR to the two remaining is 2; CUCRID to Senate is 1. Then 4 + 3 + 2 + 1 = 10, and no pair is repeated because each building only reaches forward down the list.

Step 3. Count for four buildings (2021/2022).

links = C(4, 2) = 4 × 3 / 2 = 12 / 2 = 6

By the same listing, 3 + 2 + 1 = 6.

The sentence that ties it together: "Since every pair of buildings may be linked and a link has no direction, the possible links are the edges of the complete graph on the buildings, so there are n(n − 1)/2 of them."

Now redo it: with six buildings, how many links? C(6, 2) = 6 × 5 / 2 = 15.
