Equivalence Relations and Partitions

Three properties together make the most useful relation in mathematics: one that behaves like equality without being equality.

By the end of this section you will be able to define an equivalence relation, test one in the order that finds a failure fastest, and explain the partition it creates.

The definition

Must memoriseEquivalence relation

A relation R on a set A is an equivalence relation when it is all three of:

reflexive: (a, a) ∈ R for every a
symmetric: (a, b) ∈ R forces (b, a) ∈ R
transitive: (a, b) and (b, c) in R force (a, c) ∈ R

All three, with no exceptions. Failing any one means it is not an equivalence relation, however close it looks.

Memory hook: Reflexive, Symmetric, Transitive: RST. Say it out loud before every answer, and check them in that order.

TeachWhat it is for

An equivalence relation is "sameness in some respect". Ordinary equality is the strictest example, but most useful ones are looser.

"Has the same remainder when divided by 3" is an equivalence relation on the integers. So is "was born in the same year", "has the same absolute value", and "computes the same output". None of these is equality, yet each lets you treat different things as interchangeable for a purpose.

That is why it matters in computing: two states of a machine that behave identically can be merged, two expressions that always evaluate the same can be swapped, and a cache can return one answer for many requests. Every one of those is an equivalence relation being exploited.

Testing in the fastest order

TeachCheck reflexive first, always

Reflexivity is the cheapest to test and the most commonly broken. It needs one glance at the diagonal, and a single missing loop settles the whole question.

So the efficient order is:

1. Reflexive? Scan the diagonal. If one loop is missing, stop: the answer is no, and you have your counterexample.
2. Symmetric? Compare each pair with its reverse. One unmatched pair settles it.
3. Transitive? The expensive one, so do it last, and only if the first two passed.

Under exam time this ordering routinely saves several minutes on a four-mark question.

Worked examplePQ 25/26 Q2(c)
Given
R = {(1,1), (2,2), (3,3), (4,4), (1,2), (2,3)}, on the set A = {1, 2, 3, 4} implied by the elements appearing.
Find
Whether R is reflexive, with justification.
Rule
R is reflexive when (a, a) ∈ R for every a in A.

Step 1. Fix the set. The elements mentioned are 1, 2, 3 and 4, so A = {1, 2, 3, 4}.

Step 2. Check each element for its loop.

ais (a, a) in R?
1yes, (1,1) is listed
2yes, (2,2) is listed
3yes, (3,3) is listed
4yes, (4,4) is listed

Step 3. Verdict and justification.

Yes, R is reflexive. Every element of A = {1, 2, 3, 4} is related to itself, because all four pairs (1,1), (2,2), (3,3) and (4,4) are present in R. The remaining pairs (1,2) and (2,3) do not affect reflexivity, which depends only on the loops.

Worth one extra line, and it is free: R is not symmetric, since (1,2) is in R but (2,1) is not, and it is not transitive, since (1,2) and (2,3) are in R but (1,3) is not. So R is reflexive but not an equivalence relation. In context that says every user can view their own profile, but viewing is not mutual and does not chain.

Now redo it: what single pair would you add to make R symmetric? And what would you then need for transitivity?

Given
A = {1,2,3,4}, R = {(1,1),(2,2),(3,3),(4,4),(1,3),(3,1),(2,4),(4,2)}.
Find
Whether R is reflexive, symmetric and transitive, hence whether it is an equivalence relation.
Rule
All three properties must hold. Test in the order reflexive, symmetric, transitive.

1. Reflexive

The diagonal reads 1, 1, 1, 1. All four pairs (1,1), (2,2), (3,3), (4,4) are present, so every element relates to itself. R is reflexive.

2. Symmetric

Take each non-loop pair and look for its reverse.

pair in Rreverse neededpresent?
(1,3)(3,1)yes
(3,1)(1,3)yes
(2,4)(4,2)yes
(4,2)(2,4)yes

The loops are their own reverses, so they hold automatically. The matrix is its own mirror image across the diagonal. R is symmetric.

3. Transitive

Every two-step path must have its one-step shortcut. Ignoring paths where one step is a loop, since those give back a pair already present, the genuine two-step paths are:

first stepsecond stepshortcut neededpresent?
(1,3)(3,1)(1,1)yes
(3,1)(1,3)(3,3)yes
(2,4)(4,2)(2,2)yes
(4,2)(2,4)(4,4)yes

There is no path from the {1,3} side to the {2,4} side, because no pair joins them, so no further check is needed. R is transitive.

Conclusion

R is reflexive, symmetric and transitive, so R IS an equivalence relation on A.

The detail that earns the last mark. An equivalence relation cuts its set into groups, and this one is easy to see. Element 1 is related to 1 and 3; element 2 is related to 2 and 4. So A splits into

{1, 3} and {2, 4}

Those are the equivalence classes. Every element lies in exactly one, none is empty, and together they make up all of A. Here the relation is "has the same parity", since 1 and 3 are odd while 2 and 4 are even, which is why it behaves so neatly.

Now redo it: remove (2,4) and (4,2) from R and re-test. It stays an equivalence relation, but the classes become {1,3}, {2}, {4}.

Equivalence classes and partitions

Must memoriseClasses and partitions

Given an equivalence relation R on A, the equivalence class of a, written [a], is the set of everything related to a:

[a] = {x ∈ A | (a, x) ∈ R}

A partition of A is a collection of non-empty subsets that are pairwise disjoint and whose union is all of A. Every element is in exactly one piece.

The fundamental fact: the equivalence classes of an equivalence relation always form a partition of A, and conversely every partition defines an equivalence relation ("lies in the same piece").

Memory hook: an equivalence relation and a partition are the same information written two ways. Sorting things into boxes and declaring things equivalent are one act.

TeachThe picture
