AnswerMock Two Q1 · 17.5 marks

a. Five definitions with an example each (5 marks)

One mark each, so one clean sentence and one example each. Do not write three sentences on the first and run out of time.

Proposition. A declarative sentence that is either true or false, but not both. Example: "7 is a prime number", which is true. Non-example, worth adding if you have room: "Close the door", which is a command and has no truth value.

Tautology. A compound proposition that is true in every row of its truth table, whatever its components. Example: p ∨ ¬p.

Contradiction. A compound proposition that is false in every row. Example: p ∧ ¬p.

Contingency. A compound proposition that is neither a tautology nor a contradiction, so it is true in some rows and false in others. Example: p ∧ q, which is true only when both hold.

Logical equivalence. Two propositions are logically equivalent when they have the same truth value in every row, written P ≡ Q. Example: p → q is equivalent to ¬p ∨ q.

c. Converse, inverse, contrapositive (4.5 marks)

Let p be "the number is divisible by 6" and q be "the number is divisible by 3", so the statement is p → q.

NameFormIn wordsTrue?
Originalp → qif divisible by 6 then divisible by 3True
Converseq → pif divisible by 3 then divisible by 6False
Inverse¬p → ¬qif not divisible by 6 then not divisible by 3False
Contrapositive¬q → ¬pif not divisible by 3 then not divisible by 6True

The counter-example, which is what the marks are for. Take 9. It is divisible by 3 but not by 6, so it makes the converse false; and it is not divisible by 6 yet is divisible by 3, so the same number makes the inverse false. One number kills both, and that is no accident: the converse and the inverse are contrapositives of each other, so they always stand or fall together.

The original and the contrapositive are true for the same reason, being equivalent: 6 = 2 × 3, so any multiple of 6 is a multiple of 3.

d. Symbolising and testing the argument (4 marks)

Let p be "it rains" and q be "the match is cancelled".

Premise 1: p → q
Premise 2: ¬q
Conclusion: ∴ ¬p

The argument is valid, and the rule is modus tollens. It is valid because there is no way for both premises to be true and the conclusion false: if p were true, the first premise would force q, which the second premise denies.

The trap this question is set to catch is the fallacy that looks almost the same. From p → q and ¬p one may not conclude ¬q; that is the fallacy of denying the hypothesis, and here it would say that if it did not rain the match went ahead, which the premises do not support. The match may have been cancelled for some other reason.

AnswerMock Two Q2 · 17.5 marks

a. Five set operations (5 marks)

A ∪ B = {1, 2, 3, 4, 5, 6, 8, 10}
A ∩ B = {2, 4}
A′ = {1, 3, 5, 7, 9}
A − B = {6, 8, 10}
A △ B = (A − B) ∪ (B − A) = {6, 8, 10} ∪ {1, 3, 5} = {1, 3, 5, 6, 8, 10}

Check the last one by counting. |A △ B| = |A| + |B| − 2|A ∩ B| = 5 + 5 − 4 = 6, and six members are listed. The 2 in that formula is the whole content of the symmetric difference: the shared members are removed once for each set.

The complement needs the universal set, which is why the question supplies U. A complement written without saying what it is taken inside is meaningless, and 7 and 9 appearing in A′ while belonging to neither A nor B is the visible sign that U is doing work.

b. Proving (A ∪ B)′ = A′ ∩ B′ (4 marks)

Two sets are equal when each is contained in the other, so the proof has two halves. Take x arbitrary.

First half. Suppose x ∈ (A ∪ B)′. Then x ∉ A ∪ B, so x is in neither A nor B. Hence x ∈ A′ and x ∈ B′, so x ∈ A′ ∩ B′. This gives (A ∪ B)′ ⊆ A′ ∩ B′.

Second half. Suppose x ∈ A′ ∩ B′. Then x ∉ A and x ∉ B, so x is in neither, so x ∉ A ∪ B, so x ∈ (A ∪ B)′. This gives A′ ∩ B′ ⊆ (A ∪ B)′.

Both inclusions hold, so the sets are equal. Write that closing line: the two halves are the work, and the conclusion is the mark.

Why "arbitrary" matters. The element x was never assumed to be anything in particular, so the argument covers every element at once. Choosing a specific x, or verifying the law on one example as Q1(b) of Mock One did, illustrates the law but does not prove it.

c. f(x) = 3x − 5 is a bijection (5 marks)

Injective. Suppose f(x1) = f(x2). Then

3x1 − 5 = 3x2 − 5, so 3x1 = 3x2, so x1 = x2

so no two different inputs share an output.

Surjective. Let y be any real number and put x = (y + 5)/3, which is a real number because 3 is not zero. Then

f(x) = 3 · (y + 5)/3 − 5 = (y + 5) − 5 = y

so every y in the codomain is reached.

Being both, f is a bijection, and a bijection is exactly the condition under which an inverse function exists. Making x the subject of y = 3x − 5 gives

f−1(x) = (x + 5) / 3

Check both ways round, since an inverse must undo the function from either side: f(f−1(x)) = 3(x + 5)/3 − 5 = x, and f−1(f(x)) = ((3x − 5) + 5)/3 = x.

d. Composing g(x) = x² and h(x) = x + 3 (3.5 marks)

Read g ∘ h as "g after h": the right-hand function is applied first. That is the single most common slip in this topic.

(g ∘ h)(x) = g(h(x)) = g(x + 3) = (x + 3)2
(h ∘ g)(x) = h(g(x)) = h(x2) = x2 + 3

At x = 2:

(g ∘ h)(2) = (2 + 3)2 = 52 = 25
(h ∘ g)(2) = 22 + 3 = 4 + 3 = 7

So g and h do not commute: 25 and 7 differ, and one counter-example is enough to settle a claim made for all x. Composition of functions is not commutative in general, and this is the standard demonstration of it.

The extra line worth writing if there is time. The two compositions agree exactly when (x + 3)2 = x2 + 3, that is x2 + 6x + 9 = x2 + 3, that is 6x = −6, so they agree at the single point x = −1 and nowhere else. Agreeing at a point is not commuting.

AnswerMock Two Q3 · 17.5 marks

a. The five properties, with examples (6 marks)

Throughout, R is a relation on a set A. Each definition is worth about a mark and each example about a fifth of one, so state the definitions precisely and keep the examples tiny.

PropertyDefinitionExample on {1, 2}
Reflexive(a, a) ∈ R for every a ∈ A{(1,1), (2,2), (1,2)}
Irreflexive(a, a) ∉ R for every a ∈ A{(1,2), (2,1)}
Symmetricwhenever (a, b) ∈ R, also (b, a) ∈ R{(1,2), (2,1)}
Antisymmetricif (a, b) and (b, a) are both in R then a = b{(1,1), (1,2)}
Transitivewhenever (a, b) and (b, c) are in R, also (a, c){(1,2), (2,2), (1,1)}

Reflexive and irreflexive are not opposites. A relation can be neither: {(1,1)} on {1, 2} has a loop at 1 and none at 2, so it fails both definitions. "Not reflexive" means some loop is missing; "irreflexive" means every loop is missing. Losing this mark is losing it to a quantifier, not to a relation.

b. Divisibility on {1, 2, 3, 4, 6, 12} (6 marks)

The pairs, listed by first element so that none is missed. Read each row as "this divides these".

That is 18 ordered pairs in all. Note that 1 relates to everything and 12 is related to by everything, which is the shape of a divisibility order on a set of divisors.

Reflexive. Every n divides itself, since n = 1 × n, so all six loops are present. Yes.

Antisymmetric. Suppose a divides b and b divides a, with a and b positive. Then a ≤ b and b ≤ a, so a = b. Yes.

Transitive. If a divides b, say b = a·s, and b divides c, say c = b·t, then c = a·(s·t), so a divides c. Yes.

Reflexive, antisymmetric and transitive, so it is a partial order.

Why it is not a total order. A total order requires every two elements to be comparable. Here 2 and 3 are not: 2 does not divide 3 and 3 does not divide 2, so neither (2, 3) nor (3, 2) is in the relation. One such pair is enough, though 4 and 6 are another, as are 3 and 4.

c. Reading a matrix (3 marks)

Number the rows and columns 1, 2, 3, and put 1 in position (i, j) when (i, j) is in R:

123
1010
2011
3100

Reflexive? The test in the matrix is that the main diagonal is all 1's. Here the diagonal reads 0, 1, 0, so R is not reflexive: the missing loops are at 1 and at 3.

Symmetric? The test is that the matrix equals its own transpose, that is, it is a mirror image about the main diagonal. Here the (1, 2) entry is 1 while the (2, 1) entry is 0, so R is not symmetric.

This is why the matrix representation is worth learning. Both questions are answered by looking rather than by searching a list of pairs, and the same two glances work for a relation with a hundred pairs.

d. Symmetric and antisymmetric at once (2.5 marks)

Take R = {(1,1), (2,2)} on {1, 2, 3}, or indeed any relation made only of loops, including the empty relation.

Symmetric, because the only pairs in R are (1,1) and (2,2), and each has its own reverse already in R.

Antisymmetric, because the definition only bites when (a, b) and (b, a) are both in R, and here that happens only with a = b, which is exactly what the definition then demands.

Why there is no contradiction. The two properties conflict only over a pair (a, b) with a ≠ b: symmetry would insist that (b, a) be present, and antisymmetry would forbid it. A relation containing no such pair is answerable to neither demand, so it satisfies both definitions vacuously. The two properties are not opposites, and a relation is both exactly when it is a set of loops.

AnswerMock Two Q4 · 17.5 marks

a. Eight vertices, each of degree 3 (3 marks)

By the handshaking theorem the degrees sum to twice the number of edges:

8 × 3 = 2|E|, so 24 = 2|E| and |E| = 12

Such a graph does exist. The sum of the degrees, 24, is even, which is necessary; and a concrete example settles it beyond doubt: the eight corners of a cube, each joined by an edge to the three corners next to it, is a simple graph with 8 vertices, all of degree 3, and 12 edges, one for each edge of the cube.

Name a graph rather than argue. "The degree sum is even so it exists" is not a proof, because an even degree sum is necessary but not sufficient. Exhibiting one graph is a complete answer, and it is shorter.

b. Faces by Euler's formula (2.5 marks)

For a connected planar simple graph drawn without crossings, v − e + f = 2. With v = 10 and e = 15,

f = 2 − v + e = 2 − 10 + 15 = 7

The check against the bound. For a simple connected planar graph with v ≥ 3,

e ≤ 3v − 6 = 3 × 10 − 6 = 24

and 15 ≤ 24, so nothing here contradicts planarity. Say what the check does and does not prove. Failing the bound would prove the graph is not planar; passing it proves nothing on its own, since K3,3 passes the same bound and is not planar. The question grants planarity, so Euler's formula may be used; the bound is only being confirmed as consistent.

c. The three traversals of the tree (6 marks)

Each traversal visits the root, the left subtree and the right subtree in a fixed order, and the name says where the root goes: pre means first, in means between, post means last.

TraversalOrderResult
Preorderroot, left, right× + a b − c d
Inorderleft, root, righta + b × c − d
Postorderleft, right, roota b + c d − ×

Working the preorder through, since the marks are for the method: visit the root ×; then the left subtree, whose root is +, then its left child a, then its right child b; then the right subtree, whose root is −, then c, then d. That gives × + a b − c d.

The expression the tree represents is read off the inorder traversal, with the brackets that the tree shape implies and the flat string does not:

(a + b) × (c − d)

Say why the brackets are needed. The inorder string a + b × c − d, read with the usual precedence, would mean a + (b × c) − d, which is a different calculation. Inorder alone loses the structure; preorder and postorder do not, which is why machines use them.

d. The handshaking theorem, applied (3 marks)

The theorem. In any undirected graph, the sum of the degrees of all the vertices equals twice the number of edges:

∑ deg(v) = 2|E|

because each edge has two ends and so contributes exactly 1 to the degree of each of its two endpoints.

The application. Suppose a graph had five vertices, each of degree 3. Then

∑ deg(v) = 5 × 3 = 15

But 2|E| is even for every graph, being twice a whole number, and 15 is odd. No number of edges can satisfy 2|E| = 15, so no such graph exists.

This is the corollary in disguise: the number of odd-degree vertices in any graph is even, and five vertices of degree 3 would be five odd-degree vertices.

e. Walks of length 2 in K4 (3 marks)

K4 joins every pair of its four vertices, so its adjacency matrix has 0 down the diagonal and 1 everywhere else:

v1v2v3v4
v10111
v21011
v31101
v41110

The number of walks of length 2 from v1 to v2 is the (1, 2) entry of A2, which is row 1 of A multiplied into column 2 of A:

(0 × 1) + (1 × 0) + (1 × 1) + (1 × 1) = 0 + 0 + 1 + 1 = 2

Naming them confirms it: the two walks are v1 to v3 to v2, and v1 to v4 to v2. The first two products vanish precisely because a walk cannot step from v1 to itself or from v2 to itself: there are no loops in K4.

AnswerMock Two Q5 · 17.5 marks

a. Six statistics from ten marks (7 marks)

Sort first. The median and the range both need the sorted list, and sorting takes one line:

38, 45, 45, 45, 47, 52, 55, 61, 62, 70

Mean. The ten marks total

45 + 52 + 38 + 61 + 45 + 70 + 55 + 45 + 62 + 47 = 520, so the mean is 520 / 10 = 52

Median. Ten values is an even count, so the median is the mean of the 5th and 6th of the sorted list:

(47 + 52) / 2 = 99 / 2 = 49.5

Mode. 45 occurs three times and no other value occurs more than once, so the mode is 45.

Range. 70 − 38 = 32

The two standard deviations. Both start from the same column of squared deviations about the mean 52.

x45523861457055456247

(x − 52)²490196814932494910025

the squared deviations total 882
population variance σ2 = 882 / 10 = 88.2, so σ = √88.2 = 9.39 to two decimals

The deviations must sum to zero, and they do: −7 + 0 − 14 + 9 − 7 + 18 + 3 − 7 + 10 − 5 = 0. That one line catches an arithmetic slip in the mean before it poisons every figure below it.

Which divisor, and say why. Divide by n when the ten marks are the whole group you are describing, and by n − 1 when they are a sample from a larger group whose spread you are estimating. The sample figure is always the larger of the two, here 9.90 against 9.39, because the divisor is smaller.

b. Two rolls of a fair die (5 marks)

The sample space is the 6 × 6 = 36 ordered pairs, all equally likely. Ordered, because the first and second rolls are distinguishable, and (3, 5) is not the same outcome as (5, 3).

(i) The sum is 8. The favourable pairs are (2,6), (3,5), (4,4), (5,3) and (6,2), which is 5 of them:

P(sum = 8) = 5 / 36

(ii) At least one six. "At least one" calls for the complement. No six at all leaves 5 faces for each roll:

P(no six) = 25 / 36, so P(at least one six) = 1 − 25/36 = 11 / 36

Counting them directly gives the same 11 and shows where 6 + 6 = 12 goes wrong: the six pairs with a six first and the six with a six second share the single pair (6, 6), so the answer is 6 + 6 − 1 = 11, which is inclusion and exclusion again.

(iii) The sum is 8 given a first roll of 3. Conditioning on the first roll shrinks the sample space to the 6 pairs beginning with 3, and exactly one of them, (3, 5), sums to 8:

P(sum = 8 | first = 3) = 1 / 6

Note the two rolls are independent and yet the conditional probability, 1/6, differs from the unconditional 5/36. There is no contradiction: independence is between the two rolls, whereas the event "the sum is 8" is not an event about one roll at all.

c. Which machine made the defective item (5.5 marks)

Name the events before writing a single fraction. Let A, B and C be the events that the item came from that machine, and let D be the event that it is defective. The question gives

P(A) = 0.50, P(B) = 0.30, P(C) = 0.20
P(D | A) = 0.03, P(D | B) = 0.04, P(D | C) = 0.05

Step 1, the total probability of a defect. The three machines cover the whole output and no item comes from two of them, so

P(D) = P(A)P(D|A) + P(B)P(D|B) + P(C)P(D|C)
= 0.50 × 0.03 + 0.30 × 0.04 + 0.20 × 0.05
= 0.015 + 0.012 + 0.010 = 0.037

Step 2, Bayes' theorem turns the conditioning round:

P(A | D) = P(A)P(D|A) / P(D) = 0.015 / 0.037 = 15 / 37, about 0.405

Read the answer back. Machine A makes half the output but only about 40.5% of the defects, because it is the most reliable of the three. The three posteriors are 15/37, 12/37 and 10/37, and they add to 1, which is the check to write.

The mistake this question is set to catch is answering 0.03. That is P(D | A), the chance that an item from A is defective, and the question asks the reverse, P(A | D). Bayes' theorem exists precisely because those two are different numbers.

AnswerMock Two Q6 · 17.5 marks

a. The sum of the first n odd numbers (4 marks)

P(n): 1 + 3 + 5 + … + (2n − 1) = n2

Basis. At n = 1 the left side is the single term 2 × 1 − 1 = 1 and the right side is 12 = 1. P(1) holds.

Hypothesis. Assume P(k), that 1 + 3 + … + (2k − 1) = k2.

Step. The next odd number is 2(k + 1) − 1 = 2k + 1. Adding it to both sides,

1 + 3 + … + (2k − 1) + (2k + 1) = k2 + 2k + 1 = (k + 1)2

which is exactly P(k + 1). So P(k) implies P(k + 1), and by the principle of mathematical induction P(n) holds for every positive integer n.

The one line that is easy to drop is the identification of the next term. Writing "+ (2k + 1)" without saying it came from 2(k + 1) − 1 leaves the reader to check that the series really does continue that way, and it is a mark.

b. The arithmetic progression (5 marks)

In an arithmetic progression the nth term is an = a + (n − 1)d. The two facts given become two equations:

a + 3d = 13   (the 4th term)
a + 9d = 31   (the 10th term)

Subtracting the first from the second removes a in one step:

6d = 18, so d = 3, and then a = 13 − 9 = 4

The sum of the first 20 terms.

Sn = n/2 · [2a + (n − 1)d]
S20 = 20/2 · [2 × 4 + 19 × 3] = 10 × [8 + 57] = 10 × 65 = 650

Check the two given terms against a and d: the 4th term is 4 + 3 × 3 = 13 and the 10th is 4 + 9 × 3 = 31. Both match, so the sum rests on solid ground.

Watch the index convention. The 4th term uses (n − 1) = 3, not 4. Using a + 4d here is the single commonest error in this question, and it gives d = 3 with a = 1, which then fails the check above.

c. Solving an = 4an−1 − 4an−2 (4.5 marks)

r2 = 4r − 4, that is r2 − 4r + 4 = 0
(r − 2)2 = 0, so r = 2, a repeated root

A repeated root changes the shape of the solution. With a single root r of multiplicity two the general solution is

an = (A + Bn) · rn = (A + Bn) · 2n

and not A·2n + B·2n, which collapses to a single constant times 2n and cannot meet two independent starting conditions.

Fitting the two given terms.

n = 0: (A + 0) × 1 = 1, so A = 1
n = 1: (1 + B) × 2 = 6, so 1 + B = 3 and B = 2

an = (1 + 2n) · 2n

Check against the recurrence. It gives a2 = 4 × 6 − 4 × 1 = 20, and the formula gives (1 + 4) × 4 = 20. They agree.

d. The program for the sum of an AP (4 marks)

The closed form of part (b) is one line of arithmetic. The loop beneath it is not required by the question, but it costs three lines and turns the program into its own check, which is worth writing when a program is being marked on paper.

apsum.cpp
// Mock Two Question Six (d): the sum of the first n terms of an AP.
#include <iostream>
using namespace std;

int main() {
    int a, d, n;
    cout << "Enter a, d and n: ";          // i. prompt for all three
    cin >> a >> d >> n;

    int sum = n * (2 * a + (n - 1) * d) / 2;  // ii. the closed form
    cout << "S_" << n << " = " << sum << endl;

    int running = 0;                       // iii. the same sum, term by term
    for (int k = 0; k < n; k++) {
        running += a + k * d;                // iv. the (k+1)th term
    }
    cout << "term by term: " << running << endl;
    return 0;
}
What it printed for a = 4, d = 3, n = 20
Enter a, d and n: S_20 = 650
term by term: 650

So the program prints 650, which is the answer part (b) reached by hand. Two routes to one number is the strongest check a short program can carry.

The subtlety worth a sentence on paper. In n * (2 * a + (n - 1) * d) / 2 the multiplication happens before the division, so the product 20 × 65 = 1300 is formed first and then halved. Writing n / 2 * (...) instead would divide 20 by 2 correctly here but would silently discard a half whenever n is odd, because integer division throws away the remainder. Divide last.
