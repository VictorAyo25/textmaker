Part Three · 3.1

Relations and Their Representations

A relation records which things are connected to which. There are four ways to write one down, and the exam uses all four.

By the end of this section you will be able to define a relation on a set, list the pairs of a relation given by a rule, and move freely between the set of pairs, the matrix, the arrow diagram and the directed graph.

Not in the course text
The official 161-page text never defines a relation as a set of ordered pairs, never mentions reflexive, symmetric, antisymmetric or transitive, and never mentions partial or total orders. Every paper we hold examines them: 2024/2025 gives 7.5 marks to it, 2023/2024 gives 10, 2025/2026 gives 6. Everything you need is taught here from zero.

What a relation is

TeachBuilt straight out of Part Two

Section 2.3 ended with the Cartesian product A × B, the set of every ordered pair with a first entry from A and a second from B. That is the set of all connections that could exist.

A relation is simply a choice of which of them actually do. It is any subset of A × B.

If A = {John, Mary} and B = {CSC701, CSC702}, the product has four pairs. The relation "is enrolled in" might be {(John, CSC701), (Mary, CSC702)}: a subset, recording the two enrolments that exist.

That is the whole definition. Everything in this part is a consequence.

Must memoriseDefinition

A relation from A to B is a subset of A × B.

A relation on A is a subset of A × A, that is, a relation from a set to itself. Almost every exam question is of this kind.

We write a R b to mean (a, b) ∈ R, read "a is related to b".

A relation on a set of n elements is a subset of A × A, which has n² pairs, so there are 2n² different relations on it.

Memory hook: the Cartesian product lists every possible arrow; a relation is the set of arrows you actually drew.

TrapThe order in the pair is the direction of the arrow

(a, b) ∈ R means a is related to b, not b to a. In the relation "is the parent of", (Ada, Ben) says Ada is Ben's parent, and (Ben, Ada) would say the reverse.

Every property in section 3.2 is a statement about which direction the pairs run, so getting the convention backwards inverts every answer. Fix it now: first entry acts on second entry.

The four representations

TeachOne relation, four pictures

Take A = {1, 2, 3, 4} and R = {(1,1), (1,2), (2,1), (2,2), (3,4)}. Here is the same relation written four ways. Learn to convert between them instantly, because different exam questions hand you different forms.

Must memoriseThe relation matrix

For a relation R on A = {a1, ..., an}, the relation matrix (also called the logical matrix) M has

Mij = 1 if (ai, aj) ∈ R, and 0 otherwise.

i the row, indexing the first entry of the pair. j the column, indexing the second. Mij the entry in row i, column j.

Every property of a relation becomes a visible pattern in this matrix, which is what makes 3.2 easy rather than fiddly.

Memory hook: row acts on column. Row i, column j means "does ai relate to aj". Same order as the pair.

Listing a relation given by a rule

As printed2023/2024 · Q3(d)(i)

(i) Which ordered pairs are in the relation R = {(a, b) | a divides b}? (2 marks)

Note on the paper
The set is given earlier in the same question as A = {1, 2, 3, 4}, so the relation is on that set. "a divides b" means b is a whole multiple of a, so 2 divides 4 but 4 does not divide 2, so the pairs run one way only. That is the point of choosing divisibility, as section 3.2 will show.
Break it down
Given
A = {1, 2, 3, 4} and the rule "a divides b".
Asked
Which ordered pairs are in the relation. So list them, in braces, as a set of pairs.
Marks say
2 marks for a list. Work through it systematically rather than by inspiration.
Teaches
This section, 3.1.
Trap
Forgetting that every number divides itself, so (1,1), (2,2), (3,3), (4,4) are all in. And forgetting that 1 divides everything.

Note on the paper
The domain here is the integers, not a small finite set, so these relations are infinite. You cannot list them, only sample them, which is exactly why part (i) asks for five pairs each rather than all of them. Part (ii) is answered in section 3.2, once the properties are defined.

Check each one before writing it. For R5, (1,0) works because 1 = 0 + 1. For R6, (0,3) works because 0 + 3 = 3, and the rule says "≤ 3", so equality is allowed. That boundary case is the one people get wrong.

Recall and check

1. Complete the definition: a relation on A is a subset of ____.

2. In the matrix of R, what does a 1 in row 3, column 2 mean?

3. How many relations are there on a set with 3 elements?

4. Is (2,4) in the relation "a divides b"? Is (4,2)?

Answers

1. A × A.
2. That (a3, a2) ∈ R, so the third element relates to the second.
3. 23² = 2⁹ = 512.
4. (2,4) yes, since 4 = 2 × 2. (4,2) no, since 2 is not a whole multiple of 4.
