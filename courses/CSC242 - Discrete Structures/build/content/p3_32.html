The Five Properties of a Relation

Reflexive, symmetric, antisymmetric, transitive and irreflexive. Three of the five papers we hold ask you to classify a list of relations against these, so this is the highest-value page in Part Three.

By the end of this section you will be able to state each property precisely, test any relation against all five quickly and reliably, spot each one in a matrix at a glance, and produce the counterexample that proves a property fails.

The five definitions

Must memoriseThe five properties

Throughout, R is a relation on a set A.

PropertyDefinitionIn plain words
Reflexive(a, a) ∈ R for every a ∈ Aeverything relates to itself, with no exceptions
Irreflexive(a, a) ∉ R for every a ∈ Anothing relates to itself
Symmetricwhenever (a, b) ∈ R, also (b, a) ∈ Revery arrow has a matching return arrow
Antisymmetricwhenever (a, b) ∈ R and (b, a) ∈ R, then a = bno two different elements point both ways
Transitivewhenever (a, b) ∈ R and (b, c) ∈ R, also (a, c) ∈ Rany two-step path has a one-step shortcut

Memory hook: reflexive looks in a mirror, symmetric goes both ways, antisymmetric forbids both ways unless it is the same thing twice, transitive takes shortcuts.

TrapAntisymmetric is NOT the opposite of symmetric

This is the mistake that costs the most marks in this whole part.

A relation can be both symmetric and antisymmetric. Take R = {(1,1), (2,2)} on {1, 2, 3}. Every arrow has its return arrow, since each is its own return, so it is symmetric. And no two different elements point both ways, so it is antisymmetric too.

A relation can also be neither. Take R = {(1,2), (2,1), (2,3)}. It fails symmetry, because (2,3) has no (3,2). It fails antisymmetry, because (1,2) and (2,1) are both in with 1 ≠ 2.

The four combinations all occur. So test the two properties separately and never infer one from the other.

TrapReflexive needs EVERY element

R = {(1,1), (2,2), (3,3)} on A = {1, 2, 3, 4} is not reflexive, because (4,4) is missing. Three out of four is a fail.

This is exactly the trap in 2025/2026 Q2(c), and it is why "determine whether R is reflexive" is worth two marks rather than one: the mark is for naming the missing pair, not for the verdict.

Also note that not reflexive and irreflexive are different. R = {(1,1), (2,3)} on {1,2,3} is not reflexive (2 and 3 lack loops) and not irreflexive either (1 has one). Most relations are neither.

Seeing the properties in the matrix

TeachThe fastest reliable method

Write the matrix and every property becomes something you can see. This is far quicker than checking pairs one at a time, and much harder to get wrong.

PropertyWhat to look atPasses when
Reflexivethe main diagonalevery diagonal entry is 1
Irreflexivethe main diagonalevery diagonal entry is 0
Symmetricthe matrix versus its mirror image in the diagonalMij = Mji everywhere
Antisymmetriceach off-diagonal pair of positionsnever both Mij and Mji equal to 1 when i ≠ j
Transitiveevery two-step pathMij = Mjk = 1 forces Mik = 1
Must memoriseHow to disprove each property

Every one of these properties is a "for all" statement, so a single counterexample disproves it, and quoting that counterexample is what earns the mark. Never write "R is not transitive" alone.

To show R is not ...Produce
reflexiveone element a with (a, a) ∉ R
symmetricone pair (a, b) ∈ R with (b, a) ∉ R
antisymmetrica pair (a, b) and (b, a) both in R with a ≠ b
transitive(a, b) and (b, c) in R with (a, c) ∉ R

Memory hook: one bad case kills a "for all". Find it, write it, move on.

Why R3 is transitive. a R3 b means |a| = |b|, since a = b or a = −b is exactly the statement that they have the same absolute value. So if |a| = |b| and |b| = |c| then |a| = |c|.
