Part Two · 2.1

Sets, Membership and the Nine Types

The 2025/2026 paper asks you to discuss nine types of set with an example of each. Here they are, with the vocabulary that surrounds them.

By the end of this section you will be able to define a set, state its cardinality, name and give an example of each of the nine standard types, and use the subset symbols correctly.

The definition and the vocabulary

Must memoriseSet, element, cardinality

A set is a well-defined collection of distinct objects. The objects are its elements or members.

Well-defined is doing real work: for any object it must be unambiguous whether it belongs. "The set of tall students" is not a set until "tall" is pinned down. "The set of students over 1.8 m" is.

The number of elements in a set A is its cardinality, written n(A) or |A|. So if A = {2, 4, 6} then n(A) = 3.

Memory hook: distinct and well-defined. Repeats do not count twice, and "maybe" is not an answer to whether something is in.

Two more you should be able to name if pressed, since some books count them among the nine: a proper subset (A ⊂ B, a subset that is not the whole of B) and the power set (the set of all subsets, covered in 2.3).

Memory hook: group them in threes. By size: empty, singleton, finite/infinite. By comparison: equal, equivalent, subset. By role: universal, disjoint, power set.

TrapEqual versus equivalent

These two words are close in English and precise in mathematics, and the examiner knows it.

Equal sets have the same elements: {1, 2, 3} = {3, 2, 1}.

Equivalent sets have the same number of elements: {a, b, c} and {1, 2, 3} are equivalent but very much not equal.

Every pair of equal sets is equivalent. The reverse fails constantly.

Trap∅ is not {∅}

∅ is the empty set: it has nothing in it, so n(∅) = 0.

{∅} is a set containing one thing, and that thing happens to be the empty set. So n({∅}) = 1. It is a singleton, not an empty set.

Think of ∅ as an empty box and {∅} as a box with an empty box inside it. The second is not empty.

Also: never write {∅} meaning "the empty set", and never write "∅ = { }" with anything between the braces. Both cost marks in the power-set questions of 2.3.

Subsets

Must memorise⊆ and ⊂

A ⊆ B ("A is a subset of B") means every element of A is also an element of B. A may equal B.

A ⊂ B ("A is a proper subset of B") means A ⊆ B and A ≠ B, so B has at least one element A lacks.

Standard facts, all worth knowing on sight:

∅ ⊆ A for every set A. The empty set is a subset of everything, because it has no element that could fail to be in A.
A ⊆ A for every set A.
If A ⊆ B and B ⊆ C then A ⊆ C, so subsethood carries through a chain.
A set with n elements has 2n subsets.

Memory hook: ⊆ is to sets what ≤ is to numbers, and ⊂ is what < is. The extra line means "or equal".

Trap∈ and ⊆ are not interchangeable

Let A = {1, 2, 3}.

1 ∈ A is true. The number 1 is an element.
{1} ⊆ A is true. The set {1} is a subset.
1 ⊆ A is nonsense. The number 1 is not a set, so it cannot be a subset.
{1} ∈ A is false. The elements of A are numbers, not sets, so the set {1} is not among them.

The rule: ∈ relates an element to a set, ⊆ relates a set to a set. Check which side of the symbol each object belongs on before you write it.

Listing the members of a described set

As printed2021/2022 · Q1(a)

1. (a) List the members of the following sets. (5marks)

(i) {x | x is a real number such that x² = 1}

(ii) {x | x is a positive prime number less than 20}

(iii) {x | x is a perfect square and x < 100}

(iv) {x | x is an integer such that x² = 2}

(v) {x | x is an integer such that 2x = x}

Note on the paper
The marks are printed before the five items, on the instruction line, which is why the quote above carries them there.

Item (iii) is genuinely ambiguous and you should say so. It reads "{x | x is a perfect square and x < 100}" without saying that x is a positive integer. Read strictly, 0 qualifies, and so do non-integer squares such as 0.25, which would make the set infinite. The intended answer is the perfect squares of whole numbers below 100. State the reading you use and give the set; a stated assumption protects the mark, a silent one does not.
Break it down
Given
Five sets in set-builder notation.
Asked
List the members, that is, convert each from set-builder to roster form.
Marks say
5 marks, one per item. Each is one line. Do not explain; just list, with braces.
Teaches
This section, 2.1, and section F.1 for the notation.
Trap
Two items have fewer members than they look. Item (iv) is empty, and item (v) has exactly one member. Writing "no solution" instead of the empty set loses the mark: the answer to "list the members" is always a set.
Worked examplePQ 21/22 Q1(a)

(i) {x | x is a real number such that x² = 1}

x² = 1 gives x = 1 or x = −1, and both are real.

{1, −1}

(ii) {x | x is a positive prime number less than 20}

A prime has exactly two positive divisors, itself and 1, so 1 is not prime.

{2, 3, 5, 7, 11, 13, 17, 19}, eight members.

(iii) {x | x is a perfect square and x < 100}

Reading used: x is a whole number that is the square of a whole number. Then 0² = 0 up to 9² = 81 qualify, and 10² = 100 does not, because the condition is strictly less than 100.

{0, 1, 4, 9, 16, 25, 36, 49, 64, 81}, ten members.

If your reading excludes 0, say so and give the same set without it, which is nine members. Either is defensible; leaving the reading unstated is not.

(iv) {x | x is an integer such that x² = 2}

x² = 2 gives x = √2 or x = −√2, and neither is an integer. No integer qualifies, so the set is empty.

∅, also written { }.

Do not write { ∅ }. That is the set containing the empty set, which has one member and is not empty at all.

(v) {x | x is an integer such that 2x = x}

2x = x gives x = 0, which is an integer, so exactly one value qualifies.

{0}, a singleton set.

Note the contrast between (iv) and (v), which is almost certainly why the examiner set them next to each other: one is the empty set with no members, the other is a singleton whose single member happens to be 0. ∅ and {0} are different sets, and confusing them is the standard slip here.

Now redo it: list {x | x is an integer such that x² < 5}. The answer is {−2, −1, 0, 1, 2}, five members.

Recall and check

1. What is n({∅})?

2. Give two sets that are equivalent but not equal.

3. How many subsets does {a, b, c, d} have?

4. True or false: {2} ∈ {1, 2, 3}.

Answers

1. 1. It is a singleton whose only element is the empty set.
2. {a, b, c} and {1, 2, 3}, for instance. Same size, different elements.
3. 2⁴ = 16.
4. False. {2} is a subset, not an element: {2} ⊆ {1, 2, 3} is the true statement.
