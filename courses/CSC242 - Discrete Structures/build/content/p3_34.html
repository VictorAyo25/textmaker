Partial and Total Orders

Swap symmetry for antisymmetry and you stop describing sameness and start describing ranking. That is the difference between an equivalence relation and an order.

By the end of this section you will be able to define a partially ordered set and a totally ordered set, tell them apart by the one question that separates them, and prove which a given table is.

Not in the course text
The official text never uses the words "partially ordered", "totally ordered" or "poset". The 2025/2026 paper gives 4.5 marks to exactly this, in Q2(e).

The definitions

Must memorisePartial order

A relation R on A is a partial order when it is

reflexive: every element relates to itself
antisymmetric: (a,b) and (b,a) both in R forces a = b
transitive: (a,b) and (b,c) in R force (a,c) in R

The set together with the order, written (A, R), is a partially ordered set, or poset.

Memory hook: RAT: Reflexive, Antisymmetric, Transitive. Compare with RST for an equivalence relation. The only difference is the middle letter, and that one letter is the difference between "the same as" and "no worse than".

Must memoriseTotal order

A partial order is a total order (also called a linear order or a chain) when it also satisfies comparability:

for every a and b in A, either (a, b) ∈ R or (b, a) ∈ R.

That is, no two elements are incomparable. Every pair can be put in order.

A set with a total order is a totally ordered set, or a chain.

Memory hook: every total order is a partial order. The extra demand is that nothing sits off to the side: you can line all the elements up in a single row, which is why it is also called linear.

TeachThe one question that tells them apart

Once you know a relation is a partial order, ask one thing:

"Is there a pair I cannot compare?"

If yes, it is partial only. If no, it is total.

Examples of partial but not total:

Divisibility on {1, 2, 3, 4}: 2 and 3 are incomparable, since neither divides the other.
Subset inclusion on the subsets of {1,2}: {1} and {2} are incomparable, since neither contains the other.
"Is a prerequisite of" on university courses: two unrelated electives are incomparable.

Examples of total:

"≤" on the integers, on the reals, or on any set of numbers: any two numbers can be compared.
Alphabetical order on words: any two words have a first one.

TrapAntisymmetric does not mean "not symmetric"

Section 3.2 made this point and it returns here with marks attached. Antisymmetry forbids two different elements pointing at each other. It says nothing about loops, which are always allowed and indeed required by reflexivity.

So a partial order is full of pairs (a, a), and that is not a violation of antisymmetry. The definition already says "then a = b", which those pairs satisfy.

Worked examplePQ 25/26 Q2(e)

Part 1: the difference

Both are sets carrying a relation that is reflexive, antisymmetric and transitive, so both rank their elements consistently and neither allows two different elements to outrank each other.

They differ on comparability. In a partially ordered set there may be pairs of elements that the relation does not connect in either direction; such elements are incomparable, and the ranking has gaps. In a totally ordered set every pair is comparable, so all the elements line up in one chain with no gaps.

Consequently every total order is a partial order, but not the reverse. Divisibility on {1, 2, 3, 4} is partial only, because 2 and 3 are incomparable; the relation ≤ on numbers is total, because any two numbers can be compared.

Part 2: classifying the table

Given
S = {A, B, C} with CGPA(A) = 4.80, CGPA(B) = 4.50, CGPA(C) = 4.10.
Find
Whether (S, R) is partially or totally ordered, with proof.
Relation
Taking the natural relation x R y when CGPA(x) ≥ CGPA(y), that is, x ranks at least as high as y. This must be stated because the paper does not state it.

Writing the pairs out, since CGPA(A) > CGPA(B) > CGPA(C):

R = {(A,A), (B,B), (C,C), (A,B), (A,C), (B,C)}

1. Reflexive. Each student's CGPA is at least as high as itself, since 4.80 ≥ 4.80, 4.50 ≥ 4.50 and 4.10 ≥ 4.10. So (A,A), (B,B) and (C,C) are all in R. Reflexive.

2. Antisymmetric. Suppose x R y and y R x. Then CGPA(x) ≥ CGPA(y) and CGPA(y) ≥ CGPA(x), so CGPA(x) = CGPA(y). The three CGPAs listed are distinct, so this forces x = y. Antisymmetric.

3. Transitive. Suppose x R y and y R z. Then CGPA(x) ≥ CGPA(y) ≥ CGPA(z), so CGPA(x) ≥ CGPA(z) and x R z. Checking the only non-trivial case directly: (A,B) and (B,C) are in R, and (A,C) is in R. Transitive.

So (S, R) is a partially ordered set. Now the deciding test.

4. Comparability. Take the three pairs of distinct students:

paircomparisoncomparable?
A and B4.80 ≥ 4.50, so A R Byes
A and C4.80 ≥ 4.10, so A R Cyes
B and C4.50 ≥ 4.10, so B R Cyes

Every pair is comparable, because any two real numbers can be compared.

Conclusion. (S, R) is reflexive, antisymmetric and transitive, so it is a partially ordered set; and every pair of students is comparable, so it is in fact a totally ordered set. The students form a single chain

A > B > C   (4.80, 4.50, 4.10)

which is exactly what a class ranking is.

The remark that shows real understanding: totality here depends on the three CGPAs being distinct and on CGPA being a single number. If two students shared a CGPA, antisymmetry would fail and R would not be a partial order at all. And if students were ranked on two criteria at once, say CGPA and attendance, two students could each lead on one measure, making them incomparable and the order merely partial. That is precisely how a partial order arises in practice.

Now redo it: add student D with CGPA 4.50 and re-classify. Antisymmetry now fails, so it is no longer a partial order at all.

TeachWhere orders appear in computing

Worth a line if a question asks for relevance.

Task scheduling. "Must finish before" is a partial order on jobs; independent jobs are incomparable and can run in parallel. Sorting a partial order into a legal sequence is a topological sort.

Version control. "Is an ancestor of" is a partial order on commits; branches are incomparable commits.

Type systems. "Is a subtype of" is a partial order.

Sorting. Every sorting algorithm assumes a total order on the keys. That is why a comparison function must never report two different items as mutually less-than: it would break antisymmetry and the sort would misbehave.

Recall and check

1. Name the three properties of a partial order.

2. What one extra condition makes it a total order?

3. Give two incomparable elements under divisibility on {1,...,6}.

4. Which property differs between an equivalence relation and a partial order?

Answers

1. Reflexive, antisymmetric, transitive.
2. Comparability: for every a and b, either a R b or b R a.
3. 4 and 6, for instance: neither divides the other. Also 2 and 5, or 3 and 4.
4. The middle one. An equivalence relation is symmetric; a partial order is antisymmetric.
