Set Operations and Venn Diagrams

Five operations, each with a picture. Draw the picture and the answer is usually obvious; skip the picture and the same question becomes a guessing game.

By the end of this section you will be able to compute union, intersection, difference, symmetric difference and complement, draw and read a Venn diagram, and state De Morgan's laws for sets.

The five operations

Must memoriseThe five operations
OperationSymbolDefinitionIn words
UnionA ∪ B{x | x ∈ A or x ∈ B}everything in either, counted once
IntersectionA ∩ B{x | x ∈ A and x ∈ B}only what is in both
DifferenceA − B{x | x ∈ A and x ∉ B}in A but not in B
Symmetric differenceA △ B(A − B) ∪ (B − A)in one or the other, not in both
ComplementA′ or Ā{x | x ∈ U and x ∉ A}everything outside A

Memory hook: ∪ is a up-cup that holds everything, so it is union. ∩ points down and only what is caught in both bowls stays. The complement needs a universal set to be meaningful at all, so U must always be stated.

The pictures

TeachVenn diagrams

A Venn diagram draws each set as a circle inside a rectangle, where the rectangle is the universal set U. Overlapping circles create regions, and every element of U lives in exactly one region.

Shade the region the operation describes, and the answer becomes something you can read off rather than compute.

Worked exampleMethod
Given
U = {1, 2, 3, 4, 5, 6, 7, 8}, A = {1, 2, 3, 4}, B = {3, 4, 5, 6}.
Find
All five operations.

A ∪ B = everything in either = {1, 2, 3, 4, 5, 6}. Note 3 and 4 appear once, not twice.

A ∩ B = what is in both = {3, 4}.

A − B = in A, not in B = {1, 2}.

B − A = in B, not in A = {5, 6}. Note this differs from A − B, so the order of the two sets matters.

A △ B = (A − B) ∪ (B − A) = {1, 2} ∪ {5, 6} = {1, 2, 5, 6}. It is the union minus the intersection.

A′ = everything in U outside A = {5, 6, 7, 8}.

Check. n(A) = 4, n(B) = 4, n(A ∩ B) = 2, and n(A ∪ B) = 4 + 4 − 2 = 6, which matches the six elements listed. Always run that check; it catches a dropped element instantly.

Worked examplePQ 25/26 Q1(c)
Given
A = {11, 12, 13, 14}, B = {13, 14, 15, 16}.
Find
A ∩ B, A − B, B − A.
Rule
Intersection keeps what is in both; A − B keeps what is in A and not in B.

(i) Intersection. Go through A one element at a time and ask whether it is in B. 11: no. 12: no. 13: yes. 14: yes.

A ∩ B = {13, 14}

(ii) A − B. Elements of A that are not in B, which is the two that just failed the test.

A − B = {11, 12}

(iii) B − A. Now start from B. 13: in A, drop it. 14: in A, drop it. 15: not in A, keep. 16: not in A, keep.

B − A = {15, 16}

Check. The three answers should partition the union: {11, 12} ∪ {13, 14} ∪ {15, 16} = {11, 12, 13, 14, 15, 16}, which is A ∪ B, with 6 elements. And 4 + 4 − 2 = 6. Consistent.

Now redo it: add A △ B and A′ taking U = {10, 11, ..., 18}. Answers: {11, 12, 15, 16} and {10, 15, 16, 17, 18}.

De Morgan's laws for sets

De Morgan's laws (set form)

The claim. The complement of an intersection is the union of the complements, and the complement of a union is the intersection of the complements. Complementing flips the operation.

In symbols.
(A ∩ B)′ = A′ ∪ B′
(A ∪ B)′ = A′ ∩ B′

Conditions. A and B must be subsets of a stated universal set U, since complement is meaningless without one.

The limiting case. Take B = U. Then B′ is the empty set, and the first law reads (A ∩ U)′ = A′ ∪ ∅, which is A′ = A′: true, and empty of content. The law only says something when both sets are proper parts of U, and it says most when they overlap. The same collapse happens at A = B, where it reduces to A′ = A′ again. A worked answer that lands on one of these has almost certainly lost a term somewhere.

Why it is the same law as in logic. Membership in an intersection is a conjunction ("x is in A and x is in B") and membership in a union is a disjunction. Complement is negation. So the set law is the logic law of section 1.3, read through the definition of membership. That is exactly the proof the 2024/2025 paper asks for.

Worked examplePQ 24/25 Q3(c)

To prove: (A ∩ B)′ = A′ ∪ B′.

Two sets are equal when they have exactly the same elements, so take an arbitrary element x and show that belonging to the left is equivalent to belonging to the right, step by step.

LineStatementReason
1(A ∩ B)′ = {x | x ∉ (A ∩ B)}definition of complement
2= {x | ¬(x ∈ A ∩ B)}meaning of ∉
3= {x | ¬(x ∈ A ∧ x ∈ B)}definition of intersection
4= {x | ¬(x ∈ A) ∨ ¬(x ∈ B)}De Morgan's law for logic
5= {x | x ∉ A ∨ x ∉ B}meaning of ∉
6= {x | x ∈ A′ ∨ x ∈ B′}definition of complement
7= A′ ∪ B′definition of union

Line 4 is the only real step; everything else is unpacking a definition. That is worth saying out loud in your answer, because it shows you know where the content is.

The other law, for completeness: the same seven lines with ∩ and ∪ exchanged, and ∧ and ∨ exchanged, give (A ∪ B)′ = A′ ∩ B′.

Now redo it: write the seven lines for the second law from memory, naming the reason on each.

Must memoriseThe counting formula

For any two finite sets,

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

n(A) the number of elements in A. n(A ∪ B) the number in the union. n(A ∩ B) the number in both, subtracted because adding n(A) and n(B) counts those elements twice.

This is the two-set case of the inclusion and exclusion principle, which Part Five develops for three sets and more. It is worth 7 marks on the 2025/2026 paper by itself.

Memory hook: add both, then pay back the overlap you counted twice.

Recall and check

1. With A = {1,2,3}, B = {3,4}, find A △ B.

3. State (A ∪ B)′ in terms of A′ and B′.

3. A′ ∩ B′.
