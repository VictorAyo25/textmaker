Sequences, Series and Progressions

A sequence is an ordered list with a rule behind it. Two rules cover almost everything this course does with them: keep adding the same amount, or keep multiplying by the same amount. Getting the indexing right is where the marks actually go.

By the end of this section you will be able to define a sequence and a term, tell an arithmetic progression from a geometric one, write the general term and the sum of each, read a rule off a printed sequence, use sigma notation and the four standard sums, and state which indexing convention you are using so that an off-by-one cannot cost you.

Sequences

Must memoriseSequence, term, finite and infinite

A sequence is a function from a subset of the integers, usually {0, 1, 2, …} or {1, 2, 3, …}, to a set S. The image of the integer n is written an and is called a term of the sequence. The whole sequence is written {an}.

Where n is the index, an integer, and it says the position of the term, not its value. an is the term at position n: one number, not the whole list. The subscript is not multiplication. {an} in braces is the sequence itself, the entire ordered list. S is the set the terms are drawn from, usually the real numbers on this course.

Calling it a function is the useful part. Section 4.1 defined a function as a rule assigning exactly one output to each input; a sequence is that rule with the inputs restricted to integers. So each position has exactly one term, which is why "the third term" is a well-formed phrase.

Finite and infinite. A finite sequence has a last term and its length is the number of terms. An infinite sequence runs on without end.

SequenceKindThe rule behind it
2, 4, 6, 8, …, 20finite, length 10add 2 to the previous term
10, 6, 2, −2, …infinitesubtract 4 from the previous term
1, 1, 2, 3, 5, 8, 13, …infiniteadd the previous two terms

A progression is a sequence whose terms can be described by a formula. The third row above is the Fibonacci sequence, in which each term is the sum of the two before it; section 9.4 solves it properly.

Memory hook: the index is the seat number, the term is who is sitting in it.

Arithmetic progressions

Must memoriseArithmetic progression

An arithmetic progression is a sequence in which each term is the previous term plus a fixed amount:

a,   a + d,   a + 2d,   a + 3d,   …

The general term and the sum of the first n terms are

an = a + (n − 1)d     and     Sn = n(a + an) / 2 = n(2a + (n − 1)d) / 2

Where a is the first term, the one at position 1. d is the common difference, the fixed amount added each time; it may be negative, which makes the sequence decrease, and it is found as any term minus the one before it. n is the position of the term you want, counting the first term as position 1. an is the n-th term. Sn is the sum of the first n terms, also called the arithmetic series. (n − 1) is the number of steps taken to get from the first term to the n-th, which is one fewer than the number of terms. That subtraction is the single most common error in this topic.

Why the sum formula looks like that. Write the sum forwards and backwards under itself and add column by column. Each column gives a + an, and there are n columns, so twice the sum is n(a + an). It is the first term plus the last, times how many pairs there are. The n = 1 to 100 case of section 9.2 is exactly this trick.

Memory hook: arithmetic adds, and the n-th term has taken n minus one steps.

TrapTwo indexing conventions, one sequence

The definition above starts counting at 1, so a1 = a and an = a + (n − 1)d. The official course text writes the same progression as

a,   a + d,   a + 2d,   …,   a + nd

which counts from 0, so that its an = a + nd and its first term is a0. Neither is wrong. They describe the same list of numbers and disagree only about what to call the positions.

The danger is mixing them inside one answer, which produces an answer exactly one term out. So do two things:

  • Say which you are using, in five words: "counting the first term as a1".
  • Answer the question in the words it asked. "Find the 10th term" means the tenth number in the list, whatever you have chosen to call its index. Count the list if you are unsure; ten numbers is not many.

This is the same discipline as the Foundations convention box on whether ℕ contains 0, and for the same reason: a stated convention cannot be marked wrong.

Worked exampleMethod · the arithmetic sequence 7, 12, 17, 22
Given
The sequence 7, 12, 17, 22, …
Find
(a) the 10th term, (b) a general formula for the n-th term, and (c) the sum of the first 10 terms.
Formula
an = a + (n − 1)d and Sn = n(a + an) / 2, counting the first term as a1.

Identify it first. The differences are 12 − 7 = 5, 17 − 12 = 5, 22 − 17 = 5. Constant, so this is an arithmetic progression with a = 7 and d = 5.

(a) The 10th term

a10 = a + (10 − 1)d = 7 + 9 × 5 = 7 + 45 = 52

Check by listing, which is cheap and catches an off-by-one at once: 7, 12, 17, 22, 27, 32, 37, 42, 47, 52. Ten numbers, and the tenth is 52.

(b) The general term

an = 7 + (n − 1) × 5 = 7 + 5n − 5 = 5n + 2

Test it at both ends: n = 1 gives 7, and n = 10 gives 50 + 2 = 52. Both agree.

(c) The sum of the first 10 terms

S10 = 10 × (7 + 52) / 2 = 10 × 59 / 2 = 295

Now redo it: for 2, 4, 6, …, 20, we have a = 2, d = 2 and 10 terms, so the sum is 10 × (2 + 20) / 2 = 110.

Geometric progressions

Must memoriseGeometric progression

A geometric progression is a sequence in which each term is the previous term times a fixed amount:

a,   ar,   ar2,   ar3,   …

The general term and the sum of the first n terms are

an = arn−1     and     Sn = a(rn − 1) / (r − 1)   for r ≠ 1

Where a is the first term. r is the common ratio, the fixed multiplier, found as any term divided by the one before it. It may be a fraction, which makes the terms shrink, and it may be negative, which makes the signs alternate. n − 1 is again the number of multiplications performed to reach position n from position 1. r ≠ 1 is required because at r = 1 the formula divides by zero; that case is just n copies of a, so Sn = na.

The infinite sum. If the ratio is small enough that the terms shrink, that is if r lies strictly between −1 and 1, the infinite series has a finite total:

S = a / (1 − r)

Outside that range the terms do not shrink and the sum has no finite value.

Memory hook: arithmetic adds d, geometric times by r. To tell which one a printed sequence is: take differences, and if they are not constant, take ratios.

Worked exampleMethod · reading a rule off a sequence
Given
(a) 4, 8, 16, 32, …   (b) 1, 1/3, 1/9, 1/27, …   (c) 1, 3, 5, 7, 9, …
Find
The rule and the general term of each, plus one sum.
Formula
Differences first; if they are not constant, ratios. Then an = a + (n − 1)d or an = arn−1.

(a) 4, 8, 16, 32

Differences are 4, 8, 16: not constant. Ratios are 8 / 4 = 2, 16 / 8 = 2, 32 / 16 = 2: constant. So it is geometric with a = 4 and r = 2, and

an = 4 × 2n−1

A neater equivalent form, worth writing beside it: 4 × 2n−1 = 22 × 2n−1 = 2n+1. Check at n = 1: 22 = 4. At n = 4: 25 = 32.

The 10th term is 211 = 2048, and the sum of the first 10 terms is

S10 = 4(210 − 1) / (2 − 1) = 4 × 1023 = 4092

(b) 1, 1/3, 1/9, 1/27

The denominators are powers of 3, so the ratio is 1/3 and the first term is 1:

an = (1/3)n−1

Here the infinite sum exists, because 1/3 lies between −1 and 1:

S = a / (1 − r) = 1 / (1 − 1/3) = 1 / (2/3) = 3/2

So adding infinitely many terms gives 1.5 exactly, not something unbounded. That is worth one sentence of comment in an exam, because it is the point of the formula.

(c) 1, 3, 5, 7, 9

Differences are all 2, so it is arithmetic with a = 1, d = 2, and

an = 1 + (n − 1) × 2 = 2n − 1

which is the sequence of odd numbers, exactly the one section 9.2 summed to n2.

Worked exampleMethod · when neither differences nor ratios are constant
Given
The sequence 1, 5, 17, 53, 161, 485.
Find
The rule that generates it.
Formula
None applies directly: the two standard tests, a constant difference and a constant ratio, both fail, so the rule has to be found by comparing each term with the one before it.

Find the rule behind 1, 5, 17, 53, 161, 485.

Differences: 4, 12, 36, 108, 324. Not constant, so it is not arithmetic. Ratios: 5, 3.4, about 3.12, about 3.04, about 3.01. Not constant, so it is not geometric either. But the ratios are creeping towards 3, which is the hint.

Try "times 3 plus something".

Term3 × previousActualDifference
a23 × 1 = 352
a33 × 5 = 15172
a43 × 17 = 51532
a53 × 53 = 1591612
a63 × 161 = 4834852

The extra is 2 every time, so the rule is

an = 3an−1 + 2,   with   a1 = 1

That is a recurrence relation, a rule that defines each term from earlier ones rather than from n directly. Section 9.4 takes this exact sequence and produces a closed formula for an that needs no earlier terms at all.

The general procedure, when a sequence resists both standard shapes:

  1. Take differences. Constant means arithmetic.
  2. Take ratios. Constant means geometric.
  3. Take second differences. Constant means the terms follow a quadratic in n.
  4. Compare each term with a multiple of its predecessor. A constant leftover means a recurrence of the form an = can−1 + b.
  5. Try the sum of the previous two. That is Fibonacci.

Sigma notation and the standard sums

Must memoriseFour sums worth knowing by heart

Summation notation was introduced in Foundations; here are the four closed forms this course expects, each valid for n ≥ 1.

SumClosed formCheck at n = 5
1 + 2 + … + nn(n + 1) / 25 × 6 / 2 = 15
12 + 22 + … + n2n(n + 1)(2n + 1) / 65 × 6 × 11 / 6 = 55
13 + 23 + … + n3(n(n + 1) / 2)2152 = 225
1 + r + r2 + … + rn(rn+1 − 1) / (r − 1)at r = 2: 26 − 1 = 63
Where ∑ is the summation sign: the letter below it is the index, the value below it is where the index starts, the value above it is where it stops, and the expression after it is what to add. n is the last index, so these sums have n terms when they start at 1 and n + 1 terms when they start at 0. The geometric row starts at r0 = 1, which is why its exponent is n + 1. r is the common ratio as above, and r ≠ 1.

The third one is the square of the first, which is a memorable accident worth using: the sum of the first n cubes equals the square of the sum of the first n numbers.

Two rules that let you take a sum apart, and they are used constantly:

∑ (xk + yk) = ∑ xk + ∑ yk
∑ c xk = c ∑ xk, for a constant c

Memory hook: squares over six, cubes are the square of the first sum. And every one of these four can be proved by induction, which is section 9.2 and a fair exam question.

Worked exampleMethod · evaluating a sum
Given
The sum of k2 for k running from 1 to 10.
Find
Its value, and the value of the sum of (3k + 2) over the same range.
Formula
∑ k2 = n(n + 1)(2n + 1) / 6 and ∑ k = n(n + 1) / 2, with the two splitting rules above.

The squares, at n = 10:

10 × 11 × 21 / 6 = 2310 / 6 = 385

The linear one. Split it first, which is where the rules earn their place:

∑ (3k + 2) = 3 ∑ k + ∑ 2
= 3 × (10 × 11 / 2) + 10 × 2
= 3 × 55 + 20
= 165 + 20 = 185

Note the second term. Summing the constant 2 ten times gives 20, not 2. Forgetting that a constant inside a sum still gets added once per index is the standard slip here.

Recall and check

1. Define a sequence, and say what a term is.

2. What distinguishes an arithmetic progression from a geometric one? Give one example of each.

3. Write the n-th term of an arithmetic progression and say what every letter means.

4. Write the sum of the first n terms of a geometric progression, and state its condition.

5. Find the rule behind 4, 8, 16, 32 and give its 10th term.

6. Evaluate the sum of the first 5 cubes.

Answers

1. A function from a subset of the integers to a set; a term an is the image of the index n, that is the number in position n.
2. Arithmetic adds a constant difference d, geometric multiplies by a constant ratio r. For example 7, 12, 17, 22 with d = 5, and 4, 8, 16, 32 with r = 2.
3. an = a + (n − 1)d: a is the first term, d the common difference, n the position, and n − 1 the number of steps taken.
4. Sn = a(rn − 1) / (r − 1), valid for r ≠ 1; at r = 1 the sum is na.
5. Geometric, a = 4, r = 2, so an = 4 × 2n−1 = 2n+1, and a10 = 2048.
6. (5 × 6 / 2)2 = 152 = 225.
