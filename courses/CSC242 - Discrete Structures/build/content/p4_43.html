Part Four · 4.3

Composition and Inverse Functions

Feeding one function's output into another is composition, and the exam asks for the same worked pair on two different papers.

By the end of this section you will be able to compose two functions in either order, explain why order matters, state when an inverse exists, and answer the conditions question on commuting linear functions.

Composition

Must memoriseComposition

For f : B → C and g : A → B, the composition f ∘ g is the function from A to C given by

(f ∘ g)(x) = f(g(x))

g runs first, on x. f runs second, on whatever g produced. ∘ is read "composed with", or "after".

Memory hook: read it right to left. In f ∘ g the letter nearest the x is the one that goes first. Say it as "f after g" and the order stops being confusing.

TrapThe order is not decoration

f ∘ g and g ∘ f are usually different functions, and the exam asks for both precisely to see whether you noticed.

Everyday version: putting on socks then shoes is not the same as shoes then socks. Composition, like getting dressed, is not commutative.

So compute each one separately, from its own definition. Never compute one and assume the other.

Asked

Trap
Expanding (x + 2)² as x² + 4. It is x² + 4x + 4. That single slip loses both the answer and the comparison.
Worked examplePQ 23/24 Q3(c) · PQ 24/25 Q2 b(iii)
Given
f(x) = x² + 1, g(x) = x + 2, both ℝ to ℝ.
Find
f ∘ g, g ∘ f, and whether they are equal.
Rule
(f ∘ g)(x) = f(g(x)): g first, then f.

f ∘ g

Apply g first, then feed the result into f.

(f ∘ g)(x) = f(g(x))
= f(x + 2)       [g has run]
= (x + 2)² + 1       [put x + 2 wherever f has x]
= x² + 4x + 4 + 1
= x² + 4x + 5

g ∘ f

Now the other order: f first, then g.

(g ∘ f)(x) = g(f(x))
= g(x² + 1)       [f has run]
= (x² + 1) + 2       [g adds 2 to whatever it is given]
= x² + 3

Are they equal?

No. x² + 4x + 5 and x² + 3 are different functions.

Saying so is enough for the mark, but naming a witness is better and costs one line. At x = 0:

(f ∘ g)(0) = 0 + 0 + 5 = 5,     (g ∘ f)(0) = 0 + 3 = 3.

Since 5 ≠ 3, the two compositions differ, so f ∘ g ≠ g ∘ f.

They agree only where x² + 4x + 5 = x² + 3, that is 4x = −2, so at the single point x = −½. Agreeing at one point is not being the same function.

Now redo it: compose the same f with h(x) = 3x. You should get (f ∘ h)(x) = 9x² + 1 and (h ∘ f)(x) = 3x² + 3.

When do two functions commute?

As printed2024/2025 · Q2 b(i)

bi.     Let f(x) = ax + b and g(x) = cx + d, where a, b, c and d are constants. Determine necessary and sufficient conditions on the constants a, b, c and d so that f ∘ g = g ∘ f. 2 marks

Note on the paper
The label is printed "bi.", welding part b to its first roman numeral. The phrase "necessary and sufficient" is section F.2's vocabulary: it means find the condition that holds exactly when the two compositions agree, so the argument must run both ways, not just one.
Worked examplePQ 24/25 Q2 b(i)
Given
f(x) = ax + b, g(x) = cx + d, with a, b, c, d constant.
Find
The condition on a, b, c, d that holds exactly when f ∘ g = g ∘ f.
Rule
Compose both ways, then compare coefficients.

Step 1. Compose both ways.

(f ∘ g)(x) = f(cx + d) = a(cx + d) + b = acx + ad + b
(g ∘ f)(x) = g(ax + b) = c(ax + b) + d = acx + cb + d

Step 2. Compare. Both have the same coefficient of x, namely ac, so the x terms always agree whatever the constants are. The two functions are equal exactly when the constant terms agree:

ad + b = cb + d

Step 3. Say why this is both necessary and sufficient. If ad + b = cb + d then the two expressions are identical, so the compositions agree everywhere: the condition is sufficient. Conversely, if the compositions agree everywhere then they agree at x = 0, where they take the values ad + b and cb + d, so those must be equal: the condition is necessary. Hence it is exactly the right condition.

A tidier form, worth a line: rearranging gives ad − d = cb − b, that is d(a − 1) = b(c − 1). In that shape it is easy to read off the familiar special cases: if a = c = 1 both sides are 0, so any two translations commute; and if b = d = 0 both sides are 0, so any two functions through the origin commute.

Now redo it: check the earlier example. There f(x) = x² + 1 is not linear, so this condition does not apply; but for f(x) = 2x + 3 and g(x) = 4x + 1, is d(a−1) = b(c−1)? Here 1 × 1 = 1 and 3 × 3 = 9, so no, and the two do not commute.

As printed2024/2025 · Q2 b(ii)

ii.     If f and f ∘ g are one-to-one, does it follow that g is one-to-one? Justify your answer. 2 marks

Worked examplePQ 24/25 Q2 b(ii)

Answer: yes, g must be one-to-one.

Proof. Suppose g(a) = g(b) for some a and b in the domain of g. Applying f to both sides gives f(g(a)) = f(g(b)), that is (f ∘ g)(a) = (f ∘ g)(b). But f ∘ g is one-to-one, so a = b. Since g(a) = g(b) forced a = b, g is one-to-one.

Notice what was not needed. The hypothesis that f is one-to-one was never used. Only the injectivity of the composition mattered. Saying that shows the marker you followed the logic rather than pattern-matching, and it is true: f ∘ g one-to-one alone forces g one-to-one.

The converse fails, which is worth one more line. If g is one-to-one, f ∘ g need not be: take g(x) = x on {1, 2} and f sending both 1 and 2 to the same value. Then g is one-to-one and f ∘ g is not.

Inverse functions

Must memoriseInverse

A function f : A → B has an inverse f−1 : B → A exactly when f is a bijection, that is, one-to-one and onto.

The inverse undoes f: f−1(f(a)) = a for every a in A, and f(f−1(b)) = b for every b in B.

Why both conditions are needed. If f is not one-to-one, two inputs share an output and the inverse would not know which to return, so it would not be single-valued. If f is not onto, some b has no pre-image and the inverse would be undefined there, so it would not be total. Those are exactly the two conditions of section 4.1.

Memory hook: only a perfect pairing can be run backwards. Collisions break single-valuedness, gaps break totality.

Worked exampleMethod

Find the inverse of f : ℝ → ℝ, f(x) = 2x + 1.

Section 4.2 showed this f is a bijection, so an inverse exists.

Write y = 2x + 1 and solve for x:

y = 2x + 1   ⇒   y − 1 = 2x   ⇒   x = (y − 1)/2

So f−1(y) = (y − 1)/2, usually rewritten with x as the variable: f−1(x) = (x − 1)/2.

Check it, always. f−1(f(x)) = ((2x + 1) − 1)/2 = 2x/2 = x. Correct.

By contrast f(x) = x² on the reals has no inverse: it is neither one-to-one nor onto, and "the square root" cannot decide between 2 and −2.

Recall and check

1. In f ∘ g, which function acts first?

2. With f(x) = x + 1 and g(x) = 3x, find both compositions.

3. What must be true of f for f−1 to exist?

4. Is composition commutative?

Answers

1. g, the one written nearest x.
2. (f ∘ g)(x) = 3x + 1 and (g ∘ f)(x) = 3(x + 1) = 3x + 3.
3. f must be a bijection: one-to-one and onto.
4. No. f ∘ g and g ∘ f generally differ.
