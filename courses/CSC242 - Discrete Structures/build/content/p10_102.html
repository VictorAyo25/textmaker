Discrete Probability

Probability is Part Five with a division at the end. Count the outcomes you want, count all the outcomes there are, divide. Everything else in this section is a rule for handling two events at once, and every one of those rules is a set identity from Part Two wearing a P.

By the end of this section you will be able to define a random experiment, sample space and event; distinguish independent, dependent, mutually exclusive and equally likely events; state the axioms; apply the complement, addition, multiplication and conditional rules; use Bayes' theorem; and recognise which counting rule of Part Five a probability question is really asking for.

In the course text, never yet examined
Discrete probability is a module of the course text and is properly written there, unlike the statistics module. No paper in the five available sessions has asked a probability question. It is taught here in full anyway, and two errors printed in the source module are flagged where they occur, because a reader who memorises them would answer confidently and wrongly.

Event Ea subset of the sample space"an even number" = {2, 4, 6}

A sample space is a set and an event is a subset of it. That one sentence imports the whole of Part Two: the union of two events is the event that at least one happens, the intersection is the event that both happen, and the complement is the event that it does not happen. Nothing new has to be learned about combining events, only about counting them.

For an experiment whose outcomes are all equally likely,

P(E) = n(E) / n(S)

Where P(E) is the probability of the event E, a number between 0 and 1 inclusive. n(E) is the number of favourable outcomes, the cardinality of the event, in the notation of section 2.1. n(S) is the total number of outcomes, the size of the sample space. equally likely is a condition, not decoration: the formula is wrong the moment some outcomes are more probable than others, and a loaded die is the standard counterexample.

Memory hook: favourable over total, and only when every outcome carries the same weight.

Mutually exclusive in set language is A ∩ B = ∅, which is precisely the disjoint sets of section 2.1. That is why the word disjoint is used for the same idea.

"Without replacement" is the phrase that signals dependence. Take a card and put it back, and the second draw faces the same deck; keep it, and the deck has changed. Exam questions turn on that phrase, and it is worth underlining it when you see it.

TrapMutually exclusive is not independent

The official course text writes, under its probability axioms, "if the occurrence of one event is not influenced by another event, they are called mutually exclusive or disjoint". That sentence defines independence and attaches the wrong name to it. The two ideas are not merely different; on events that can happen at all they are opposites.

Mutually exclusiveIndependent
Meansthey cannot both happenone happening tells you nothing about the other
In symbolsP(A ∩ B) = 0P(A ∩ B) = P(A) × P(B)
Knowing A happenedtells you B did nottells you nothing at all

Why they are opposites. If A and B are mutually exclusive and both have non-zero probability, then learning that A happened tells you B certainly did not: that is the strongest possible influence, so they cannot be independent. Formally, P(A ∩ B) = 0 while P(A) × P(B) > 0, so the independence equation fails.

The same module prints a second error, in its properties list: "for two non-disjoint events A and B, the probability of the union of two events P(A ∪ B) = P(A) + P(B)". That formula is the one for disjoint events. For non-disjoint events the overlap has been counted twice and must come off, exactly as in section 5.3:

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

The module's own formula list gives this correct version three paragraphs later, so the two statements contradict each other. Use the one with the subtraction; it is inclusion and exclusion, and it is right.

The axioms and the rules

Must memoriseThe axioms and the five rules

The axioms, which every probability obeys:

  • 0 ≤ P(E) ≤ 1 for every event E
  • P(∅) = 0 for the impossible event, and P(S) = 1 for the certain event
  • if E1, E2, …, En are pairwise mutually exclusive, then P(E1 ∪ … ∪ En) = P(E1) + … + P(En)

The rules, which are the axioms put to work:

RuleFormulaWhen
ComplementP(A′) = 1 − P(A)always
AdditionP(A ∪ B) = P(A) + P(B) − P(A ∩ B)always
Addition, disjointP(A ∪ B) = P(A) + P(B)only when A ∩ B = ∅
MultiplicationP(A ∩ B) = P(A) × P(B)only when A and B are independent
ConditionalP(B | A) = P(A ∩ B) / P(A)always, provided P(A) > 0
Where A′ is the complement of A, the event that A does not happen, written with the same prime as the set complement of section 2.2. A ∪ B is the event that at least one of A, B happens, and A ∩ B is the event that both happen. P(B | A) is the conditional probability of B given A: the probability of B once you already know A has happened. The bar is read "given" and is not division. P(A) > 0 is required because the formula divides by it, and conditioning on something impossible is meaningless.

The general multiplication rule, which works whether or not the events are independent and is just the conditional rule rearranged:

P(A ∩ B) = P(A) × P(B | A)

and independence is exactly the case where P(B | A) = P(B), which collapses it to the simple form.

Memory hook: or adds, and multiplies, not subtracts the overlap, given divides.

Worked, from the simplest upward

Worked exampleMethod · coins, dice and cards
Given
A fair coin, a fair die, and a standard deck of 52 cards.
Find
Several basic probabilities, each by counting the sample space first.
Formula
P(E) = n(E) / n(S), the outcomes being equally likely in each case.

One coin. S = {H, T}, so n(S) = 2 and P(heads) = 1 / 2.

One die. S = {1, 2, 3, 4, 5, 6}, so n(S) = 6.

P(any given face) = 1/6
P(even) = n({2, 4, 6}) / 6 = 3 / 6 = 1/2
P(odd) = 3 / 6 = 1/2

One card from 52.

P(ace) = 4 / 52 = 1/13
P(diamond) = 13 / 52 = 1/4
P(red queen) = 2 / 52 = 1/26

Three coin tosses, exactly two heads. The sample space is every sequence of three results, so by the product rule of section 5.1 it has 23 = 8 outcomes:

HHH, HHT, HTH, HTT, THH, THT, TTH, TTT

Exactly two heads occurs in HHT, HTH and THH, which is 3 outcomes, so

P(exactly two heads) = 3/8

The counting shortcut, for when there are too many outcomes to list: choosing which 2 of the 3 positions hold the heads is C(3, 2) = 3, by section 5.2. The same 3, obtained without writing out the sample space, which is the move you need when there are ten tosses rather than three.

The addition rule in action. One card, P(ace or diamond). The events overlap in the ace of diamonds, so

P(ace ∪ diamond) = 4/52 + 13/52 − 1/52 = 16/52 = 4/13

Adding without subtracting would give 17/52 and would count the ace of diamonds twice.

Worked exampleMethod · the complement, and "at least one"
Given
(a) A jar of 7 red, 3 green and 4 blue marbles, one drawn at random. (b) A committee of 4 chosen from 6 boys and 4 girls.
Find
(a) P(the marble is not blue). (b) P(the committee contains at least one boy).
Formula
P(A′) = 1 − P(A), and C(n, r) from section 5.2 for the counting.

(a) The marbles

The total is 7 + 3 + 4 = 14 marbles.

Directly: non-blue means red or green, which is 7 + 3 = 10 marbles, so

P(not blue) = 10 / 14 = 5/7

By the complement, which is the same answer by a shorter route:

P(blue) = 4 / 14 = 2/7, so P(not blue) = 1 − 2/7 = 5/7

(b) At least one boy

"At least one" is the standard signal to use the complement, because the opposite of "at least one boy" is the single simple case "no boys at all". Section 5.2 answered the counting version of this exact question from the 2025/2026 paper; here it is as a probability.

total committees = C(10, 4) = 210
committees with no boy = C(4, 4) = 1
committees with at least one boy = 210 − 1 = 209

so

P(at least one boy) = 209 / 210

Read the answer back. That is about 0.995, which is worth saying: with six boys among ten candidates, a committee of four with no boy at all is nearly impossible, and there is in fact exactly one such committee, the four girls. A probability that close to 1 should agree with your intuition, and if it does not, recheck the counting.

Worked exampleMethod · conditional and dependent events
Given
(a) Half of all teenagers own a cycle, and 30 per cent own both a bike and a cycle. (b) Six good and three defective laptops are mixed up and tested one at a time at random, without replacement.
Find
(a) The probability that a teenager owns a bike given that the teenager owns a cycle. (b) The probability that the first two tested are both defective.
Formula
P(B | A) = P(A ∩ B) / P(A), and the general multiplication rule P(A ∩ B) = P(A) × P(B | A).

(a) The conditional probability

Let A be "owns a cycle" and B be "owns a bike". We are given P(A) = 0.5 and P(A ∩ B) = 0.3.

P(B | A) = P(A ∩ B) / P(A) = 0.3 / 0.5 = 0.6

So 60 per cent of cycle owners also own a bike.

What conditioning did. The 30 per cent was measured against all teenagers; the answer 60 per cent is measured against cycle owners only. Conditioning shrinks the sample space from S to A, and dividing by P(A) is exactly that shrinking. Say that sentence and the formula stops being something to memorise.

(b) Two defectives in a row

There are 6 + 3 = 9 laptops, of which 3 are defective. Let A be "the first is defective" and B be "the second is defective".

P(A) = 3 / 9

Now the pool has changed, because the first laptop was not replaced: 8 remain and 2 of them are defective. So

P(B | A) = 2 / 8

and therefore

P(A ∩ B) = P(A) × P(B | A) = (3/9) × (2/8) = 6 / 72 = 1/12

The trap this question sets is using P(A) × P(B) = (3/9) × (3/9) = 1/9, which treats the draws as independent. They are not, because the first laptop is not put back, and the phrase "tested one by one" is what tells you so.

Cross-check by counting, in the manner of section 5.2: the number of ways to choose 2 defectives from 3 is C(3, 2) = 3, and the number of ways to choose any 2 from 9 is C(9, 2) = 36, giving 3 / 36 = 1/12. The two methods agree.

Bayes' theorem

Must memoriseBayes' theorem

Conditional probability runs one way; Bayes' theorem turns it round.

P(A | B) = P(B | A) × P(A) / P(B)

Where P(A) is the probability of A before the evidence, sometimes called the prior. P(B | A) is how likely the evidence B is when A holds. P(B) is how likely the evidence is overall, and it is usually the part you must compute rather than the part you are given. P(A | B) is the probability of A after the evidence, which is what the question wants.

Computing P(B) is the real work. If A and A′ are the only two possibilities, then B happens either with A or with A′, and those two cases are mutually exclusive, so

P(B) = P(B | A) × P(A) + P(B | A′) × P(A′)

which is the axiom of adding disjoint cases, applied to a split of the sample space.

Memory hook: Bayes reverses the bar. You are given "evidence given cause" and you want "cause given evidence".

Worked exampleMethod · Bayes on a server farm
Given
60 per cent of a data centre's machines come from supplier A and 40 per cent from supplier B. In the first year 2 per cent of A's machines fail and 5 per cent of B's do. A machine is found to have failed.
Find
The probability that it came from supplier B.
Formula
P(B | F) = P(F | B) × P(B) / P(F), with P(F) = P(F | A)P(A) + P(F | B)P(B).

Name everything first, which is where these questions are won or lost:

P(A) = 0.6,   P(B) = 0.4
P(F | A) = 0.02,   P(F | B) = 0.05

Step 1. The overall failure rate.

P(F) = 0.02 × 0.6 + 0.05 × 0.4
      = 0.012 + 0.020
      = 0.032

Step 2. Reverse the bar.

P(B | F) = P(F | B) × P(B) / P(F) = 0.05 × 0.4 / 0.032 = 0.020 / 0.032 = 0.625

Answer: 62.5 per cent.

Why the answer is interesting. Supplier B provides only 40 per cent of the machines but accounts for 62.5 per cent of the failures, because its failure rate is two and a half times higher. The evidence has moved the probability from 0.4 to 0.625, and that movement is exactly what Bayes' theorem measures.

Check with the complement. P(A | F) should be 0.012 / 0.032 = 0.375, and 0.625 + 0.375 = 1. Given that the machine failed, it came from one supplier or the other, so the two conditional probabilities must add to 1. That check costs one line and catches an arithmetic slip immediately.

Now redo it: if the split were 50 per cent each with the same failure rates, P(F) = 0.02 × 0.5 + 0.05 × 0.5 = 0.035 and P(B | F) = 0.025 / 0.035, which is about 0.714.

TeachRandom variables, in one box

A random variable assigns a number to each outcome of an experiment. It is a function on the sample space, in the sense of section 4.1, and not a variable in the algebraic sense at all.

Discrete is the one this course is about, which is what the word discrete in the course title means: countable, separated values rather than a smooth range. Every structure in this book, from a set to a graph to a tree, is discrete in exactly that sense.

Answers

1. The sample space S is the set of all possible outcomes; an event is a subset of S.
2. P(E) = n(E) / n(S), valid only when every outcome is equally likely.
3. Mutually exclusive means they cannot both occur, P(A ∩ B) = 0. Independent means one gives no information about the other, P(A ∩ B) = P(A)P(B). For events of non-zero probability the two are opposites.
4. P(A ∪ B) = P(A) + P(B) − P(A ∩ B); the last term may be dropped only when the events are disjoint, since it is then zero.
5. P(B | A) = P(A ∩ B) / P(A); the bar is read "given" and restricts the sample space to A.
6. 1/13, 1/4 and 4/13.
7. (3/9) × (2/8) = 1/12.
