a. (p ∧ q) ∨ (p ∧ ¬q) ≡ p, by the laws (4 marks)

Three steps, and each one is a mark. The instruction "without using a truth table" means the table earns nothing here even if it is correct.

Say what it means, which costs a sentence and shows the manipulation was understood: whether q holds or not is irrelevant to the compound, because the two disjuncts between them cover both cases and each requires p. This is the propositional twin of the Boolean simplification AB + AB′ = A.

The argument in two lines, which is the better answer if the question does not insist on a table. Suppose both premises hold. Either p is true, in which case p → q gives q, so q ∨ r holds; or p is false, in which case ¬p is true and ¬p → r gives r, so q ∨ r holds again. There is no third case, so the conclusion cannot fail while the premises hold. That is a proof by cases, and it explains why the table came out as it did.

Rows 4 and 8 are the ones to look at. In both, q ∨ r is false, so if the whole thing is to be a tautology the premise must be false there, and it is. An implication with a false hypothesis is true whatever its conclusion does, which is exactly the vacuous case that makes so many people distrust the truth table for →.

c. Symbolising and negating (4 marks)

Declare the domains and the predicate before writing a quantifier. Let x range over the students in the class, let y range over the problems set, and let S(x, y) mean "student x has solved problem y". Then

∀x ∃y S(x, y)

The negation, pushed inward one quantifier at a time. Each step flips one quantifier and moves the negation past it:

¬∀x ∃y S(x, y)
≡ ∃x ¬∃y S(x, y)
≡ ∃x ∀y ¬S(x, y)

In plain words: there is a student in the class who has solved no problem at all.

The two traps. First, the order of the quantifiers matters: ∃y ∀x S(x, y) would say there is one single problem that every student has solved, which is a much stronger claim than the original. Second, the negation is not "no student has solved any problem"; that would be ∀x ∀y ¬S(x, y). Denying that everyone succeeded requires only one failure.

d. The validity of the syllogism (4.5 marks)

Let C(x) mean x is a computer scientist, L(x) that x is logical and M(x) that x is a musician.

Premise 1: ∀x (C(x) → L(x))
Premise 2: ∃x (L(x) ∧ M(x))
Conclusion: ∃x (C(x) ∧ M(x))

The argument is invalid, and the way to prove an argument invalid is to exhibit one situation in which every premise is true and the conclusion is false. Take a universe of just two individuals, 1 and 2, and set

C = {1},   L = {1, 2},   M = {2}

Premise 1 holds: the only computer scientist is 1, and 1 is logical.
Premise 2 holds: 2 is both logical and a musician.
The conclusion fails: the only computer scientist is 1, and 1 is not a musician, so no individual satisfies C(x) ∧ M(x).

Premises true and conclusion false in the same situation, so the argument is not valid.

Where the reasoning goes wrong. Being logical is the middle term, and the two premises attach to different parts of it: the first says the computer scientists sit somewhere inside the logical people, the second says some logical people are musicians, and nothing forces those two regions of the logical people to overlap. Drawing three circles makes this visible at once, and a Venn diagram is a perfectly acceptable way to present this answer provided the counter-example is named.

AnswerMock Three Q2 · 17.5 marks

a. a − b divisible by 5, on the integers (6 marks)

Use the definition of "divides" explicitly, because every one of the three checks is an application of it: 5 divides m means m = 5k for some integer k.

Reflexive. For any integer a, a − a = 0 = 5 × 0, and 0 is an integer, so 5 divides a − a and a R a. This holds for every a, so R is reflexive.

Symmetric. Suppose a R b, so a − b = 5k for some integer k. Then

b − a = −(a − b) = 5(−k)

and −k is an integer, so 5 divides b − a and b R a.

Transitive. Suppose a R b and b R c, so a − b = 5k and b − c = 5m for integers k and m. Adding,

a − c = (a − b) + (b − c) = 5k + 5m = 5(k + m)

and k + m is an integer, so a R c.

R is reflexive, symmetric and transitive, so it is an equivalence relation.

The classes. Two integers are related exactly when they leave the same remainder on division by 5, since if a = 5q + r and b = 5q′ + r then a − b = 5(q − q′), and conversely. There are five possible remainders, so there are exactly five classes:

[0] = {…, −10, −5, 0, 5, 10, …}
[1] = {…, −9, −4, 1, 6, 11, …}
[2] = {…, −8, −3, 2, 7, 12, …}
[3] = {…, −7, −2, 3, 8, 13, …}
[4] = {…, −6, −1, 4, 9, 14, …}

Every integer lies in exactly one of them, which is the partition the relation induces and the sentence that finishes the answer. Note that the classes are infinite while there are only finitely many of them: a partition does not have to cut a set into small pieces, only into pieces that do not overlap and leave nothing out.

b. f(n) = 2n + 1 from the integers to the integers (4 marks)

Injective, yes. Suppose f(n1) = f(n2). Then 2n1 + 1 = 2n2 + 1, so 2n1 = 2n2, so n1 = n2.

Surjective, no. Every value of f is odd, because 2n is even for every integer n and one more than an even number is odd. So no even integer is an image. A single witness settles it: if f(n) = 2 then 2n + 1 = 2, so n = 1/2, which is not an integer, and therefore 2 has no preimage.

Making it a bijection. f is injective but not surjective, so the codomain is too large. Shrink it to exactly the set of values f actually takes:

f from the integers to { 2k + 1 : k is an integer }, the set of odd integers

This is now surjective by construction, since any odd integer can be written 2k + 1 and is then f(k), and it is still injective because shrinking the codomain cannot make two inputs collide. So it is a bijection.

The general principle worth stating: any injective function becomes a bijection onto its range. It is surjectivity that a codomain can be blamed for; injectivity is a property of the rule itself.

d. The composition of two injections (3.5 marks)

Set it up first. Let f be a function from A to B and g a function from B to C, both injective, so that g ∘ f is a function from A to C.

Proof. Suppose (g ∘ f)(x1) = (g ∘ f)(x2) for some x1 and x2 in A. By the definition of composition this says

g(f(x1)) = g(f(x2))

Now f(x1) and f(x2) are elements of B, and g is injective, so equal images force equal inputs:

f(x1) = f(x2)

And f is injective, so by the same reasoning

x1 = x2

Since x1 and x2 were arbitrary, g ∘ f sends no two different inputs to the same output, and is therefore injective. ∎

Notice the order in which the two hypotheses are used: g first, then f, which is the reverse of the order in which the functions are applied. That is not a coincidence, and saying so is worth half a mark: the proof runs backwards along the chain x → f(x) → g(f(x)), peeling off the outermost function first.

AnswerMock Three Q3 · 17.5 marks

a. Divisible by 3 or 5 but not by 15 (5 marks)

Count each family with a division. The number of integers from 1 to 1000 that a given d divides is the whole-number part of 1000 / d.

divisible by 3: 1000 / 3 = 333.33…, so 333
divisible by 5: 1000 / 5 = 200
divisible by 15: 1000 / 15 = 66.66…, so 66

Why 15 and not something else. An integer is divisible by both 3 and 5 exactly when it is divisible by 15, because 3 and 5 have no common factor above 1. This is the step to state: writing 3 × 5 = 15 without saying why the two conditions combine that way is the part examiners probe.

Divisible by 3 or by 5, by inclusion and exclusion:

333 + 200 − 66 = 467

Now remove the multiples of 15. Every multiple of 15 is divisible by 3, so all 66 of them are inside that 467 and must come out:

467 − 66 = 401

Check by regions. Divisible by 3 only: 333 − 66 = 267. Divisible by 5 only: 200 − 66 = 134. Their sum is 267 + 134 = 401, computed a different way. The phrase "or but not both" would have meant the same thing here, which is worth noticing: "divisible by 15" and "divisible by both" are the same set.

b. MISSISSIPPI (5 marks)

Count the letters first. MISSISSIPPI has 11 letters: M once, I four times, S four times, P twice. Check: 1 + 4 + 4 + 2 = 11.

11! / (4! × 4! × 2!) = 39916800 / (24 × 24 × 2) = 39916800 / 1152 = 34650

All four S's together. Glue them into a single block. The block then behaves as one letter, so the objects to arrange are

[SSSS], M, I, I, I, I, P, P   that is 8 objects, with the four I's alike and the two P's alike

8! / (4! × 2!) = 40320 / 48 = 840

Why the block is not itself rearranged. Ordinarily a block of k items would be permuted internally in k! ways, but the four S's are identical, so their 4! internal orders all give the same word. Multiplying by 4! here is the standard error and gives 20160.

A sanity check on the size: 840 out of 34650 is about one arrangement in 41, which is plausible, since insisting that four particular letters be adjacent is a severe restriction. An answer larger than 34650 would be impossible on its face.

c. Eight characters with at least one digit (4 marks)

The alphabet has 26 + 26 + 10 = 62 characters. "At least one" is the signal for the complement: count all passwords and remove those with no digit at all.

all passwords: 628 = 218340105584896
with no digit, only the 52 letters: 528 = 53459728531456
at least one digit = 628 − 528 = 164880377053440

Leaving the answer as 628 − 528 is acceptable and is what most of the marks are for. If you do evaluate it, note that the answer is about 75.5% of all passwords, which is the kind of remark that shows the number was understood rather than copied off a calculator.

Why not count directly. "Exactly one digit, exactly two digits, and so on up to eight" is eight terms, each a product of a binomial coefficient and two powers. It gives the same answer and takes ten times as long.

d. Two pigeonhole arguments (3.5 marks)

The first. Name the objects and the boxes, which is where the marks are. The objects are the 13 people; the boxes are the 12 months of the year; each person goes into the box of their birth month, and every person has exactly one birth month, so every object goes into some box. Since 13 > 12, the pigeonhole principle says some box holds at least two people, that is, two people share a birth month.

The second needs the generalised form: N objects in k boxes force some box to hold at least ⌈N / k⌉. Three in one box is guaranteed as soon as

⌈N / 12⌉ ≥ 3, that is N > 24, so the least such N is 25

Why 24 is not enough, and this sentence is worth a mark of its own: with 24 people it is possible for exactly two to be born in each of the twelve months, and then no month holds three. The principle guarantees a crowded box only from the twenty-fifth person onward, and exhibiting the arrangement that defeats 24 is what proves the answer is least.

AnswerMock Three Q4 · 17.5 marks

a. The number of odd-degree vertices is even (4 marks)

Split the sum, which is the whole idea. Let V be the vertex set and divide it into the vertices of even degree and the vertices of odd degree. By the handshaking theorem

∑even deg(v) + ∑odd deg(v) = ∑V deg(v) = 2|E|

Two of those three quantities are visibly even. The total 2|E| is even, being twice a whole number. The first sum is even, being a sum of even numbers. Therefore

∑odd deg(v) = 2|E| − ∑even deg(v) = even − even = even

Finish with the parity argument. That last sum consists entirely of odd numbers. A sum of odd numbers is odd when there is an odd count of them and even when there is an even count. Since the sum is even, the count must be even. So the number of vertices of odd degree is even. ∎

The consequence worth naming: no graph has exactly one odd-degree vertex, or three, or five. This is the corollary that answers "can such a graph exist" questions in one line, and part (b) of Mock Two Question Four used it.

b. The tree with degrees 4, 4, 3, 3, 3 and the rest 1 (5 marks)

Two facts about the tree, then equate them. Let n be the total number of vertices. A tree on n vertices has exactly n − 1 edges, so by the handshaking theorem

∑ deg(v) = 2(n − 1) = 2n − 2

Now add the degrees up from the description. There are two vertices of degree 4, three of degree 3, and the remaining n − 5 vertices have degree 1:

∑ deg(v) = 2 × 4 + 3 × 3 + (n − 5) × 1 = 8 + 9 + n − 5 = n + 12

Equating the two expressions gives one equation in one unknown:

n + 12 = 2n − 2, so n = 14

Check every figure. The tree has 14 vertices and 13 edges. Its leaves number 14 − 5 = 9, and the degrees total 8 + 9 + 9 = 26, which is 2 × 13 as the theorem requires. A tree with 9 leaves and 5 branch vertices is entirely believable, so nothing here is out of proportion.

The step that is easy to miss is that "the rest" have degree 1 and there are n − 5 of them, not some fixed number. Writing the unknown into the degree sum is what makes the equation solvable.

c. No simple graph has degree sequence (5, 5, 4, 3, 2, 1) (3.5 marks)

The parity test does not settle it, and saying so first shows you tried the cheap test: the degrees sum to 5 + 5 + 4 + 3 + 2 + 1 = 20, which is even, so the handshaking theorem is satisfied with 10 edges. Something else must do the work.

The argument. The sequence has six terms, so the graph has six vertices, and it contains two vertices of degree 5. In a simple graph with six vertices, a vertex of degree 5 is joined to all five of the others, since it has no loops and no repeated edges available to it. So call the two of them u and w.

Every other vertex is joined to u, and every other vertex is joined to w. Hence every vertex apart from u and w has degree at least 2. But the sequence contains a vertex of degree 1, which would have to be joined to both u and w and so have degree at least 2. That is a contradiction, so no such simple graph exists. ∎

Where "simple" is doing the work. Without it a vertex could reach degree 5 through loops or parallel edges and would not need to touch all five other vertices, and the argument collapses. Whenever a degree-sequence question is set, look first at whether the largest degree forces adjacency to everything.

d. Every simple connected planar graph has a vertex of degree at most 5 (5 marks)

By contradiction. Suppose G is simple, connected and planar with v ≥ 3 vertices, and suppose every vertex has degree at least 6.

The lower bound from the assumption. By the handshaking theorem,

2e = ∑ deg(v) ≥ 6v, so e ≥ 3v

The upper bound from planarity. Euler's formula v − e + f = 2, together with the fact that every face of a simple graph is bounded by at least three edges and every edge borders at most two faces, gives the standard bound

e ≤ 3v − 6

The two bounds cannot both hold. They would give

3v ≤ e ≤ 3v − 6, so 3v ≤ 3v − 6, so 0 ≤ −6

which is false. The assumption is therefore untenable, and some vertex has degree at most 5. ∎

Read the result back. This is the reason five colours are always enough for a planar map by an easy argument, and it is also why K5, in which every vertex has degree 4, is not ruled out by this test and needs the edge-count argument instead. A theorem that excludes a shape is only as useful as the shapes it fails to exclude.

a. Simplifying A′BC + AB′C + ABC′ + ABC (5 marks)

The trick is to use ABC three times. In Boolean algebra X + X = X, so a term may be duplicated as often as it is useful without changing the expression. That is the idempotent law, and it is the step that makes this question tractable.

Check by counting the 1's. The original F is 1 in exactly four rows: 011, 101, 110 and 111. The simplified AB + BC + AC is 1 exactly when some two of the inputs are 1, which is those same four rows. Four product terms have become three, and each has shrunk from three literals to two.

b. The circuit, and what it computes (3 marks)

It is the majority function of three inputs: the output is 1 exactly when at least two of A, B and C are 1. It is the circuit behind any two-out-of-three voting arrangement, such as three sensors on a machine or three copies of a computation compared against one another.

Six taps, three rails. Each input is used by exactly two of the three AND gates, which the drawing shows directly; the version of this circuit that draws six separate input wires is not wrong, but it hides the fact that there are only three signals.

d. The majority function as a program (5 marks)

The Boolean product and sum of part (a) are written with the bitwise operators & and |, which act on 0 and 1 exactly as · and + do in Boolean algebra. That correspondence is the point of the program, so make it visible in a comment.

majority.cpp
// Mock Three Question Five (d): the majority of three 0/1 inputs.
#include <iostream>
using namespace std;

// F = AB + BC + AC, with & for the Boolean product and | for the sum.
int majority(int a, int b, int c) {
    return (a & b) | (b & c) | (a & c);
}

int main() {
    int a, b, c;
    cout << "Enter A, B and C as 0 or 1: ";   // i. prompt
    cin >> a >> b >> c;

    if (a > 1 || b > 1 || c > 1) {           // ii. reject anything else
        cout << "Each input must be 0 or 1." << endl;
        return 0;
    }

    cout << "F = " << majority(a, b, c) << endl;  // iii. report
    return 0;
}
What it printed for the input 1 0 1
Enter A, B and C as 0 or 1: F = 1

So the program prints F = 1, which agrees with the truth table: with A = 1, B = 0 and C = 1, the term AC is 1 and that is enough.

Two remarks worth a mark each on paper. First, & and | here are the bitwise operators, not the logical && and ||; on inputs restricted to 0 and 1 the two pairs agree, but && and || also stop evaluating as soon as the answer is settled, which is a difference that matters as soon as the operands do anything besides hold a value. Second, the guard rejecting inputs above 1 is not decoration: with a = 2 the expression a & b would compute a bit pattern rather than a truth value, and the program would print something that is not 0 or 1.

AnswerMock Three Q6 · 17.5 marks

a. Every integer n ≥ 2 is a product of primes (5 marks)

Say at the outset that a single prime counts as a product of one prime. Without that convention the basis case fails and the whole proof stalls on a technicality.

Basis. n = 2 is prime, so it is a product of primes, namely of the one prime 2.

Strong inductive hypothesis. Let k ≥ 2 and assume that every integer m with 2 ≤ m < k is a product of primes.

Inductive step. Consider k. There are two cases and they are exhaustive.

Case 1, k is prime. Then k is a product of one prime and there is nothing to do.
Case 2, k is composite. Then by the definition of composite, k = a × b for some integers a and b with 2 ≤ a < k and 2 ≤ b < k. Both a and b fall in the range covered by the hypothesis, so each is a product of primes. Multiplying those two products together expresses k as a product of primes.

In both cases k is a product of primes, so the hypothesis for all values below k yields the claim at k. By the principle of strong induction, every integer n ≥ 2 is a product of primes. ∎

Why ordinary induction will not do here, and this is what the word "strong" in the question is testing. Ordinary induction would let you assume the claim only for k − 1, and knowing that k − 1 factorises tells you nothing whatever about k. What the proof actually needs is the claim at a and at b, two numbers that may lie anywhere below k. Strong induction is exactly the form that makes the whole range below k available.

b. Solving an = 2an−1 + 3 (4.5 marks)

This is not homogeneous, because of the constant 3, so the characteristic equation does not apply directly. The standard move is to absorb the constant by shifting the sequence.

The shift to use. For an = c·an−1 + b with c ≠ 1, add b / (c − 1) to both sides. Here c = 2 and b = 3, so the amount to add is 3 / (2 − 1) = 3. Put bn = an + 3. Then

bn = an + 3 = 2an−1 + 3 + 3 = 2an−1 + 6 = 2(an−1 + 3) = 2bn−1

which is a plain geometric progression. Its first term is b0 = a0 + 3 = 1 + 3 = 4, so

bn = 4 · 2n = 2n+2

Undo the shift to get back to the sequence that was asked for:

an = 2n+2 − 3 = 4 · 2n − 3

Check the first three terms against the recurrence, which is the only check that tests both the formula and the starting value:

nfrom the recurrencefrom the formula
0given as 14 × 1 − 3 = 1
12 × 1 + 3 = 54 × 2 − 3 = 5
22 × 5 + 3 = 134 × 4 − 3 = 13
32 × 13 + 3 = 294 × 8 − 3 = 29

Iterating instead is a legitimate route and gets the same answer: an = 2na0 + 3(2n−1 + … + 2 + 1) = 2n + 3(2n − 1) = 4 · 2n − 3, using the sum of a geometric progression. Whichever route you take, state which one you are taking in the first line.

c. Three balls of the same colour (4 marks)

The bag holds 4 + 5 + 6 = 15 balls, and three are taken together, so order does not matter and every part of this is a combination.

all selections of three: C(15, 3) = (15 × 14 × 13) / (3 × 2 × 1) = 2730 / 6 = 455

The favourable selections, one colour at a time. The three colours are alternatives, only one of which can happen, so they are added rather than multiplied:

all three white: C(4, 3) = 4
all three black: C(5, 3) = 10
all three green: C(6, 3) = 20
favourable in all: 4 + 10 + 20 = 34

P(all the same colour) = 34 / 455, about 0.075

The fraction will not reduce: 455 = 5 × 7 × 13 and 34 = 2 × 17, so they share no factor. Saying so saves you from hunting for a cancellation that is not there.

A check on plausibility. About one selection in thirteen is monochrome, which is believable: the largest colour class has only 6 of the 15 balls, so three matching is a genuine coincidence rather than a near-certainty. Any answer above about 0.2 should have prompted a recount.

d. There is no largest prime (4 marks)

Proof by contradiction, so begin by assuming the opposite, and say that you are doing so.

Suppose there is a largest prime. Then the primes can be listed completely and finitely:

p1 = 2, p2 = 3, p3 = 5, …, pk, the largest

Construct a number the list cannot account for. Let

N = (p1 × p2 × … × pk) + 1

Then N > 1, so by part (a) of this question N has at least one prime divisor; call it q.

Now trap q. Suppose q were one of the primes on the list. Then q divides the product p1 × … × pk, and q divides N by choice, so q divides their difference:

N − (p1 × … × pk) = 1

But no prime divides 1, since every prime is at least 2. So q is a prime that is not on the list, contradicting the assumption that the list contained every prime.

The assumption is therefore false, and there is no largest prime. ∎

The point that is worth stating and is usually got wrong: N itself need not be prime. The argument does not claim it is. It claims only that some prime divides N and that no prime on the list can. For instance 2 × 3 × 5 × 7 × 11 × 13 + 1 = 30031, which is 59 × 509 and so not prime at all; but 59 is a prime that was missing from the list, which is exactly what the proof promised.

Notice this answer used part (a). The step "N has a prime divisor" is precisely the theorem proved by strong induction earlier in this question, and pointing that out is free.
