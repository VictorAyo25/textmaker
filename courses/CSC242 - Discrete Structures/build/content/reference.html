TeachThe laws, in all three notations

One table, because they are one set of laws. Learn a row once and you have it in Part One, Part Two and Part Eight.

LawLogicSetsBoolean
Identityp ∧ T ≡ pA ∩ U = AA · 1 = A
Dominationp ∨ T ≡ TA ∪ U = UA + 1 = 1
Idempotentp ∨ p ≡ pA ∪ A = AA + A = A
Double negation¬(¬p) ≡ p(A′)′ = A(A′)′ = A
Commutativep ∧ q ≡ q ∧ pA ∩ B = B ∩ AA · B = B · A
Associative(p ∨ q) ∨ r ≡ p ∨ (q ∨ r)(A ∪ B) ∪ C = A ∪ (B ∪ C)(A + B) + C = A + (B + C)
Distributivep ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)A · (B + C) = A · B + A · C
De Morgan¬(p ∧ q) ≡ ¬p ∨ ¬q(A ∩ B)′ = A′ ∪ B′(A · B)′ = A′ + B′
Absorptionp ∨ (p ∧ q) ≡ pA ∪ (A ∩ B) = AA + A · B = A
Negationp ∨ ¬p ≡ TA ∪ A′ = UA + A′ = 1

Each law has a dual, obtained by swapping ∧ with ∨, ∩ with ∪, · with +, and T with F, U with ∅, 1 with 0. Learn one half of the pair and derive the other (section 8.1).
