Numbers, Symbols and Notation

Discrete mathematics has a small vocabulary. Learn it once here and nothing later in this book will look like a foreign language.

By the end of this section you will know what "discrete" means, be able to name and write the standard number sets, read and write the membership and subset symbols out loud, and use factorial and summation notation without hesitating.

What "discrete" means, and why the course exists

TeachThe one word in the title

Discrete means separated, made of individual pieces you can count, with nothing in between. Its opposite is continuous, which flows without gaps.

The whole numbers 1, 2, 3 are discrete: between 2 and 3 there is no other whole number. Temperature is continuous: between 20 degrees and 21 there are infinitely many values, and you can always find another.

A computer is a discrete machine. It stores whole bits, executes whole instructions, and holds finitely many values. That is the whole reason this course exists: the mathematics of computing is the mathematics of things you can count and separate, not the mathematics of smooth curves.

Worked examplePQ 25/26 Q2(a)

Five justifications, each a claim with a concrete example attached.

  1. Computers are discrete machines, so discrete mathematics is their native mathematics. A machine stores whole bits and executes whole instructions; it has no smooth quantities. Continuous mathematics describes a falling stone, but nothing inside a processor. Example: an integer overflow is a fact about a finite set of representable values, and only discrete reasoning predicts it.
  2. It supplies the language in which algorithms are specified and their cost measured. Counting techniques give the running time of a procedure before it is ever run. Example: knowing that comparing every pair of n records takes n(n − 1)/2 comparisons tells you the method will not scale, without writing a line of code.
  3. It is the basis of correctness, not merely of testing. Logic and proof by induction establish that a program works for every input, where testing only covers the cases you thought of. Example: proving a loop invariant holds shows a sorting routine is right for all inputs, including the ones nobody tried.
  4. Its structures are the data structures of the subject. Sets, relations, functions, graphs and trees are not analogies for computing objects; they are those objects. Example: a relational database is built directly on relations, and a file system is a tree.
  5. It underpins the applied areas the degree leads to. Networking, cryptography, compilers and artificial intelligence all rest on it. Example: routing traffic is a shortest-path problem on a graph, and public-key cryptography rests on number theory over the integers.

How to write it under time pressure: number them 1 to 5, give each a bold opening claim and one sentence of example. Five short numbered paragraphs read as five justifications; one long paragraph reads as one.

The number sets

TeachNames for collections of numbers

A set is any collection of distinct objects, gathered together and treated as one thing. Part Two studies sets properly; for now you only need the five standard ones, because every question in this course lives in one of them.

They are written with a special doubled letter so nobody confuses the set of all integers with a variable called Z.

Must memoriseThe five number sets
SymbolNameWhat is in it
ℕthe natural numbers0, 1, 2, 3, ... the counting numbers
ℤthe integers... −2, −1, 0, 1, 2, ... whole numbers, positive and negative
ℚthe rational numbersanything writable as a fraction of two integers, such as 3/4 or −7
ℝthe real numbersevery point on the number line, including π and the square root of 2
ℂthe complex numbersreals extended with the square root of −1 (not examined here)

Memory hook: Natural, Zahlen (German for numbers, which is where ℤ comes from), Quotient, Real, Complex. Each doubled stroke says "this is a whole universe of numbers, not a variable".

TrapDoes ℕ contain 0?

Textbooks disagree. Some start the natural numbers at 0, some at 1. In computing, 0 is almost always included, and this manual includes it.

What matters in an exam: say which convention you are using. One short sentence ("taking ℕ to include 0") protects you completely, and a marker cannot penalise a stated convention. What loses marks is leaving it ambiguous and then relying on it.

Membership: the two symbols you will use most

Teach∈ and ∉

To say that an object is in a set we write ∈. The statement 3 ∈ ℤ is read "3 is an element of the integers", or more casually "3 is in Z". The symbol is a stylised Greek epsilon, for the Greek word meaning "is".

To say an object is not in a set, strike it through: ∉. So ½ ∉ ℤ reads "one half is not an element of the integers", which is true, because one half is not a whole number.

The left side is always an object and the right side is always a set. That direction never changes, and it is the single most common slip in first attempts.

Two ways to describe a set

The 2025/2026 paper asks for exactly this, in two marks, so learn both names.

Must memoriseRoster and set-builder

1. The roster method, also called listing or the tabular method. Write the members out between braces, separated by commas.

A = {2, 4, 6, 8}

2. Set-builder notation, also called the rule method. State the property that decides membership.

A = {x | x is an even number and 0 < x < 10}

The vertical bar is read "such that". Some books use a colon instead, which means the same thing. The whole line is read: "A is the set of all x such that x is even and x is between 0 and 10".

Memory hook: the roster method names the members, the way a class register does. Set-builder gives the entry rule, the way a door policy does.

Worked exampleMethod

Write each set both ways.

(a) The odd numbers under 10.
Roster: {1, 3, 5, 7, 9}.
Set-builder: {x | x ∈ ℕ, x is odd, x < 10}.

(b) The days of the week starting with T.
Roster: {Tuesday, Thursday}.
Set-builder: {d | d is a day of the week and d begins with T}.

(c) The integers whose square is 4.
Set-builder: {x | x ∈ ℤ and x² = 4}.
Roster: {−2, 2}. Notice the roster form does the work of solving the equation for you, which is exactly why an examiner asks for it.

Now redo it: write "the prime numbers below 12" both ways, then check: {2, 3, 5, 7, 11}.

TrapSets do not repeat and do not care about order

{1, 2, 2, 3} is the same set as {1, 2, 3}. Writing an element twice adds nothing, because a set records only whether a thing is in.

{3, 1, 2} is also the same set as {1, 2, 3}. Order carries no information either.

This matters later. When order does matter you are no longer dealing with a set but with an ordered pair or a sequence, and the brackets change from braces to parentheses: (1, 2) is not (2, 1). Part Three is built entirely on that distinction.

Factorial

Must memorisen factorial

For a whole number n, n! (said "n factorial") means multiply every whole number from n down to 1.

n! = n × (n − 1) × (n − 2) × ... × 2 × 1

n a whole number, 0 or more. n! the product of every whole number from n down to 1. By definition 0! = 1.

The first few, which you should know on sight:

n01234567
n!1126241207205040

Memory hook: 0! = 1 looks wrong but is forced: there is exactly one way to arrange nothing, namely do nothing. Every counting formula in Part Five breaks if you set it to 0.

TeachWhy factorials grow so fast

10! is already 3 628 800, and 20! is bigger than a billion billion. This is not a curiosity: it is the reason some problems are hopeless to solve by trying every possibility. The travelling-salesman question in Part Six turns on exactly this.

Useful cancelling trick, used constantly in Part Five:

10! / 8! = (10 × 9 × 8!) / 8! = 10 × 9 = 90

Never expand both factorials and divide. Cancel first. It turns an impossible arithmetic problem into a two-second one.

Summation

Must memoriseSigma notation

The Greek capital sigma, ∑, is shorthand for "add up". It is read "the sum of".

∑i=1n ai = a1 + a2 + ... + an

i the index, a counter. i=1 below the sigma, where the counter starts. n above the sigma, where it stops. ai the thing being added, written in terms of i.

So ∑i=14 i² means 1² + 2² + 3² + 4² = 1 + 4 + 9 + 16 = 30.

Memory hook: sigma is the Greek S, for Sum. Read it left to right as a sentence: "sum, from i equals 1, up to n, of a-sub-i".

Recall and check

1. Say out loud what 7 ∉ ℚ would mean, and say whether it is true.

2. What is 6! / 4!?

3. Write {x | x ∈ ℤ and −2 ≤ x ≤ 2} by the roster method.

4. Evaluate ∑i=13 (2i + 1).

Answers

1. "7 is not an element of the rationals". It is false: 7 = 7/1, so 7 is rational.
2. 6!/4! = 6 × 5 = 30. Cancel, do not expand.
3. {−2, −1, 0, 1, 2}.
4. (2+1) + (4+1) + (6+1) = 3 + 5 + 7 = 15.
