Part Four · 4.2

The Five Correspondence Types

Ten marks on two separate papers, for one diagram you can learn in ten minutes. This is the best value in the whole course.

By the end of this section you will be able to define one-to-one and onto, draw all five correspondence types from memory, and say which is which from a diagram.

The two properties

Must memoriseOne-to-one and onto

Let f : A → B.

One-to-one (also injective): different inputs always give different outputs. Formally, f(a1) = f(a2) forces a1 = a2. No output is hit twice.

Onto (also surjective): every element of B is hit by something. Formally, for every b ∈ B there is an a ∈ A with f(a) = b. Equivalently, the range equals the codomain.

Bijective: both one-to-one and onto. A perfect pairing, with every element of A matched to exactly one of B and nothing left over on either side.

Memory hook: one-to-one is about collisions in B (there are none). Onto is about coverage of B (it is complete). One looks for doubles, the other looks for gaps.

TeachCounting tells you what is possible

Compare the sizes of A and B and some cases become impossible, which is a fast sanity check on any answer.

Break it down

Five named correspondence types.
Asked

Marks say
10 marks over five items is 2 each, so one diagram plus one or two sentences per item. This is the highest marks-per-minute question in the whole set: it is pure recall and needs no calculation.

This section, 4.2, and 4.1 for what a function is.

Item (v) is not a correspondence type at all, it is the failure case. Its diagram must break the function rule, on the left circle, and not merely be an odd pattern of arrows on the right.
Worked examplePQ 21/22 Q2(c) · PQ 20/21 Q4(b)

Open with the two definitions, because every item below refers to them and stating them once earns the understanding marks.

One-to-one (injective): different inputs give different outputs, so no element of B receives two arrows.
Onto (surjective): every element of B receives at least one arrow, so the range equals the codomain.

(i) One-to-one, not onto. Every element of B receives at most one arrow, but at least one receives none. Take A = {1, 2}, B = {a, b, c} with f(1) = a, f(2) = b. Nothing maps to c. This needs n(A) < n(B).

(ii) Onto, not one-to-one. Every element of B is reached, but at least one is reached twice. Take A = {1, 2, 3}, B = {a, b} with f(1) = a, f(2) = a, f(3) = b. Both targets are covered, and a is hit twice. This needs n(A) > n(B).

(iii) One-to-one and onto (bijective). Every element of B receives exactly one arrow. Take A = {1, 2, 3}, B = {a, b, c} with f(1) = a, f(2) = b, f(3) = c. This is a perfect pairing and requires n(A) = n(B). Only a bijection has an inverse, which is section 4.3.

(iv) Neither one-to-one nor onto. Some element of B is hit twice and some other is missed. Take A = {1, 2, 3}, B = {a, b, c} with f(1) = a, f(2) = a, f(3) = b. Here a is hit twice and c is never reached.

(v) Not a function. The mapping breaks the definition in 4.1, so the fault is on the input side. Either some element of A has two arrows leaving it, or some element of A has none. Take A = {1, 2, 3}, B = {a, b, c} with 1 sent to both a and b, and 3 sent nowhere. Both faults are present, and either alone is enough.

Draw the five pictures exactly as above, label the circles A and B, and write the one-line reason under each. Keep the reason on the right circle for (i) to (iv) and on the left circle for (v).

Worked exampleMethod · deciding from a formula

The exam sometimes gives a formula instead of a picture. The test is the same, done algebraically.

f : ℝ → ℝ, f(x) = 2x + 1.
One-to-one? Suppose f(a) = f(b). Then 2a + 1 = 2b + 1, so 2a = 2b and a = b. Yes.
Onto? Given any y, solve y = 2x + 1 for x = (y − 1)/2, which is a real number. Yes. So f is a bijection.

f : ℝ → ℝ, f(x) = x².
One-to-one? f(2) = 4 = f(−2) with 2 ≠ −2. No.
Onto? There is no real x with x² = −1. No. So it is type (iv), neither.

Notice how each "no" is settled by a single explicit counterexample, and each "yes" by a general argument. That asymmetry is section 1.4's rule about quantifiers, showing up again.

Recall and check

1. Define one-to-one and onto in one sentence each.

2. If n(A) = 5 and n(B) = 3, can f : A → B be one-to-one?

3. What must be true of the range for f to be onto?

4. In a diagram, what tells you it is not a function?

Answers

1. One-to-one: different inputs always give different outputs. Onto: every element of the codomain is an output of something.
2. No. With more inputs than outputs two inputs must share a target.
3. The range equals the codomain.
4. An element of A with two arrows leaving it, or with none.
