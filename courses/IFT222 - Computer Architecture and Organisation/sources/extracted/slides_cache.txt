- Number of Cache Lines

----- SLIDE 5 -----
- DIRECT CACHE MAPPING
- Find the number of Tag Bits
- 	tag bit = total no. of m/m bits – ( index + offset)
- 	Tag = 16 − 6 − 4 
- 	Tag = 6 bits
- Address Format for cache 
- 	Tag	   Index	Offset
- 	6 bits   6 bits	4 bits	
- from cpu      000010 000011 1001 ( 2 , 3, 9)

- 5. Determine the Tag Directory Size
- 	Tag Directory Size = Total cache lines  x  Tag Bits
- 				64 × 6 = 384 bits 
- 					  = 48 bytes (384/8)

- Offset = 4 bits
- Index = 6 bits
- Tag = 6 bits
