SLIDE 4
Course Description
This course introduces the fundamental principles and structure of modern computer systems.
It covers the relationship between hardware and software, the organization of the CPU, memory hierarchy, input/output mechanisms, instruction execution, and performance measurement.
Students will learn how computers are designed, how they execute programs, and how architectural choices affect system performance.

============================================================
SLIDE 5
Course Objectives
By the end of this course, students should be able to:
Explain the internal structure of modern computer systems and how components interact to execute programs.
Analyze performance of computer systems using metrics like CPI, MIPS, and benchmarks.
Design simple assembly-level programs and understand instruction set architecture.
Understand memory hierarchy concepts, including cache, main memory, and virtual memory.
Describe processor design techniques including pipelining and basic parallelism.
Recognize I/O organization and fundamentals of storage and communication within computing systems.

============================================================
SLIDE 6
Course Learning Outcomes
By the end of this course, students will be able to:
Describe the fundamental components of a computer system and their roles.
Explain instruction set architecture and data representation techniques.
Analyze CPU performance using standard metrics.
Explain memory hierarchy and address translation mechanisms.
Describe processor implementation including pipelining and hazards.
Discuss I/O systems and peripheral communication techniques.
Apply assembly programming concepts to simple coding problems.
Evaluate architectural trade-offs for performance and cost.

SLIDE 18
Computer Architecture
Computer architecture refers simply to the attributes of a computer visible to a programmer.
That is, it refers to those attributes that have direct impact on the logical execution of a computer program.
For example, it is an architectural design issue whether a computer will have a multiply instruction.  (MULTIPLICATION UNIT)
But It is an organizational issue whether that instruction will be implemented by a special multiply unit or by a mechanism that makes repeated use of the add unit of the system

============================================================
SLIDE 19
Computer Architecture
Thus, computer architecture refers to the functional design and logical structure of a computer system. It describes the following aspects of a computer:
  Instruction set
  Data types
  Addressing modes
  Register organization

============================================================
SLIDE 20
Computer Architecture
Computer Architecture also answers the question: “What does the computer do?”.
It therefore serves as a blueprint for system design.
Examples of architectural attributes include the instruction set, the number of bits used to represent various data types (e.g., numbers, characters), I/O mechanisms, and techniques for addressing memory.

SLIDE 23
Computer Organization
Computer organization refers to the operational units and their interconnections that realize the architectural specifications.
Organizational attributes include those hardware details transparent to the programmer, such as control signals; interfaces between the computer and peripherals; and the memory technology used.
Computer organization refers to the physical implementation of the system, including:
  Hardware components
  Interconnections
  Control signals
  Memory structure

============================================================
SLIDE 24
Computer Organization
Thus, Computer Organization answers the question: “How does the computer do it?. It ensures the architecture is translated into working hardware.
Computer architecture can be likened to a building design while computer organization may be likened to the actual construction or implementation of the building.

SLIDE 30
Components of Computer Architecture - 1
Instruction Set Architecture (ISA)
The Instruction Set Architecture (ISA) is the core of computer architecture.
It acts as the interface between hardware and software and defines the following:
The set of instructions a processor can execute
  Instruction formats (e.g., ADD, LOAD, STORE)
  Data types (integer, floating point)
  Registers available
  Addressing modes

============================================================
SLIDE 31
Components of Computer Architecture - 1
Real-Life Applications
Software Compatibility
Applications compiled for a specific ISA (e.g., x86 or ARM) will only run on processors supporting that ISA. Example: Mobile apps are built for ARM-based processors in smartphones.
Operating SystemsAn OS is designed for a specific ISA.
Example: Windows OS is optimized for x86 architecture systems.
Different organizations (hardware implementations) can support the same ISA but vary in performance.

SLIDE 40
Components of Computer Architecture - 5
Von Neumann Architecture: Shared memory for data and instructions
This processor configuration consists of a control unit, an arithmetic logic unit, a register set, and a memory region containing program instructions and data.
The key feature distinguishing the von Neumann architecture from the Harvard architecture is the use of a single area of memory for program instructions and the data acted upon by those Instructions.

============================================================
SLIDE 41
[images: 1]
Components of Computer Architecture - 5
It is conceptually straightforward for programmers, and relatively easier for circuit designers, to locate all of the code and data a program requires in a single memory region.  Figure 1 shows the elements of Von Neumann architecture.

============================================================
SLIDE 42
Components of Computer Architecture - 5
Harvard Architecture: Separate memory for data and instructions
A strict Harvard architecture uses one address space and memory bus for program instructions and a separate address space and memory bus for data.
This configuration has the immediate benefit of enabling simultaneous access to instructions and data, thereby implementing a form of parallelism.
This enhancement comes at the expense of essentially duplicating the number of address lines, data lines, and control signals that must be implemented by the processor to access both of the memory regions.
