Introduction
Instruction Set Architecture (ISA) is one of the most fundamental concepts in Computer Architecture and Organization. 
It defines the interface between hardware and software, acting as a bridge that allows software programs to communicate with the processor.
In simple terms, ISA specifies:
What operations a processor can perform (instruction set)
How instructions are represented (instruction format)
How data is accessed and manipulated (addressing modes)

Types of Instructions - Load/Store Instructions
One of the universal characteristics of instruction execution is that the source does not get changed, only the destination. 
Thus, in a load operation the processor copies data into a register, and in a store operation the processor copies data from a register into a memory location. 
Examples of load/store instructions in the MC68009 processor are LDA, STA, LDB, STB, LDD, STD, and so forth.
14

--- slide 15 ---
Types of Instructions - Load/Store Instructions
Examples of load/store instructions in the MC68000 processor are
MOVE (for either direction of data movement), 
MOVEM (for moving the content of several registers into or out of memory with a single instruction), and 
EXG (for exchanging register contents). 
These instructions and others like them must include information identifying the source and destination.

Arithmetic/logic operations provide the primary data-processing capabilities of the computer. 
The minimum arithmetic operations required are those of addition and subtraction.  5 – 3  = 5 + (-3)     101 + 011
All processors, implement the basic logic operations of AND, OR, and exclusive-OR on a bit-by-bit basis between two operands. 
With operations requiring two operands, smaller microprocessors usually require that one of the operands must be in a destination register initially, while the other may be in another register or in memory.

--- slide 19 ---
Test/branch operations provide the decision-making capabilities in computer programs. 
The test is often performed on the result of some prior arithmetic/logic operation. 
It determines whether the result was zero or non-zero, positive or negative, or some other binary choice involving bits in the condition code register. 
During the execution of a test/branch instruction, the processor examines the appropriate condition code bits to determine the result of the test.
19
Types of Instructions - Test/Branch Instructions

--- slide 20 ---
Depending upon the result, the processor may or may not branch to a remote location for the next instruction.  
Examples of test/branch instructions are BCC (branch if carry is cleared), BEQ (branch if equal to 0), BMI (branch if minus), and BRA (branch always).

Instruction Formats

--- slide 22 ---
An instruction is usually made up of a combination of an operation code and some way of specifying an operand, most commonly by its location or address in memory.
Instruction Format is the layout of bits in an instruction
11100011111110000001110000 = ADD R1,R2
An instruction is divided into Opcode (function), operand(s) (implicit or explicit) and addressing mode.
Instructions typically have 0,1,2 or 3 operands
There is usually more than one instruction format in an instruction set

Instruction Format Examples
Let’s attempt to study various instruction formats using the following program. 
The program in assembly language that evaluates 
	X = (A + B) * (C + D)
We shall use this to understand 3,2,1, and 0  instruction formats
33

--- slide 34 ---
Three Address - Instruction FormatX = (A + B) * (C + D)   X =A +B + C
ADD R1, A, B  R1 ← M[A] + M[B]   ADD R1,A,B
ADD R2, C, D  R2 ← M[C] + M[D]  ADD X, R1,C
MUL  X, R1, R2  M[X] ← R1 * R2 
It is assumed that the computer has two processor registers, R1 and R2. The symbol M[A] denotes the operand at memory address symbolized by A.
The advantage of the three-address format is that it results in short programs when evaluating arithmetic expressions.
The disadvantage is that the binary-coded instructions require too many bits to specify three addresses.

--- slide 35 ---
Two Address - Instruction Format
Two-address instructions are the most common in commercial computers. Here again each address field can specify either a processor register or a memory word. The program to evaluate X = (A + B) * (C + D) is as follows:
MOV R1, A   R1 ← M[A]
ADD R1, B   R1 ← R1 + M[B]
MOV R2, C   R2 ← M[C]
ADD R2, D   R2 ← R2 + M[D]
MOL R1, R2  R1 ← R1 * R2
MOV X, R1   M[X] ← R1

Two Address - Instruction Format
The MOV instruction moves or transfers the operands to and from memory and processor registers.
The first symbol listed in an instruction is assumed to be both a source and the destination where the result of the operation is transferred.

One-address instructions use an implied accumulator (AC) register for all data manipulation. 
For multiplication and division there is a need for a second register. 
However, here we will neglect the second register and assume that the AC contains the result of all operations.
 The program to evaluate X = (A + B) * (C + D) is

One Address - Instruction Format
LOAD A  AC ← M[AJ
ADD B   AC ← AC + M[B]
STORE T M[T] ← AC
LOAD C AC ← M[C]
ADD  D   AC ← AC + M[D]
MOL  T   AC ← AC*M[T]

All operations are done between the AC register and a memory operand. T is the address of a temporary memory location required for storing the intermediate result.

Immediate Addressing
47
Immediate addressing is one of the simplest and fastest addressing modes in Instruction Set Architecture (ISA). 
In this mode, the actual operand (data value) is directly embedded inside the instruction itself, rather than being stored in a register or memory location.

Indirect Addressing  Mode
51
An addressing technique in which the address field of the instruction contains the address of another memory location that stores the effective address of the operand.
Basic Format
|Opcode|Address|
Interpretation
Address field → does not contain actual operand location
It contains → pointer to the operand’s address

--- slide 52 ---
Indirect Addressing  Mode
52
How It Works (Step-by-Step)
CPU fetches the instruction 
Reads the address field (say A) 
Goes to memory location A 
Retrieves the effective address (EA) stored there 
Accesses operand using EA
Example 1
LOAD R1, (200)
Explanation
Instruction contains 200 
Memory[200] contains 500 
Memory[500] contains actual data 
Final operation:R1 = Memory[500]

Relative Addressing  Mode
54
Relative Addressing Mode is defined as:
An addressing technique in which the effective address (EA) is obtained by adding a displacement (offset) to the current value of the Program Counter (PC).
Formula:
Effective Address (EA) = PC + Offset

--- slide 55 ---
Relative Addressing  Mode
55
How It Works (Step-by-Step)
CPU fetches the instruction 
PC already points to the next instruction 
Offset is extracted from instruction 
Offset is added to PC 
Result gives target address (EA)
