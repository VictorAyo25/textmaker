The Machine

Instruction Sets and Formats

What a machine instruction is, the kinds there are, and the four "address" formats the paper asks you to write a program in. Plus the counting question the objective test likes.

TeachParts and types of an instruction

An instruction has an opcode (which operation to do) and zero or more operands (what to do it to), with an addressing mode saying where each operand is. The instruction format is just the layout of these bit fields. The whole collection of instructions a processor understands is its instruction set. The main types:

  • Data transfer (LOAD, STORE, MOVE): move data between registers and memory. LOAD reads from memory.
  • Arithmetic and logic (ADD, SUB, AND, OR): the ALU's work, mostly on registers.
  • Control transfer (JUMP, BRANCH, CALL): change the order instructions run in, usually after a compare.
  • Input/output: talk to devices.
TeachThe four address formats

How many operand addresses each instruction names:

  • Three-address: names both sources and the destination, e.g. ADD X, A, B (X = A + B). Fewest instructions for an expression.
  • Two-address: the destination is also a source, e.g. ADD A, B (A = A + B).
  • One-address: works through a single register, the accumulator: LOAD a value in, operate, STORE it out.
  • Zero-address: a stack machine. Operands sit on top of the stack, so operations name no address at all: PUSH values, then ADD takes the top two. Most instructions here, but each is tiny.

The trade-off: fewer addresses means shorter instructions but more of them. Three-address gives the shortest program; zero-address the longest.

Worked examplewrite X = (A + B) × (C + D)

The same expression in each format. Watch the instruction count climb as the number of addresses drops.

Three-address (shortest, 3 instructions):

ADD  T, A, B      ; T = A + B
ADD  X, C, D      ; X = C + D
MUL  X, T, X      ; X = T * X

Two-address (destination is also a source):

MOV  T, A
ADD  T, B         ; T = A + B
MOV  X, C
ADD  X, D         ; X = C + D
MUL  X, T         ; X = X * T

One-address (one accumulator, AC):

LOAD  A
ADD   B           ; AC = A + B
STORE T
LOAD  C
ADD   D           ; AC = C + D
MUL   T           ; AC = AC * T
STORE X

Zero-address (stack, most instructions but each is tiny):

PUSH A   PUSH B   ADD      ; A + B on the stack
PUSH C   PUSH D   ADD      ; C + D on the stack
MUL                       ; (A+B) * (C+D)
POP  X

The bigger version, X = ((A×B) + C/D) / (F×G + J×K), is Question 4b on the 2025/2026 paper and is in your final mock at the back.

TeachCounting bytes, and fixed vs variable length

To size a program, count each instruction's bytes and add up:

bytes per instruction = opcode bytes + (number of addresses × bytes per address)

An instruction's total length is just its fields added: an 8-bit opcode, a 6-bit register field and an 18-bit address field make an 8 + 6 + 18 = 32-bit instruction. Fixed-length instructions (all the same size) are faster to decode and are used by RISC (reduced instruction set computers); variable-length instructions are used by CISC (complex instruction set computers). To fit more opcodes in the same length, give the opcode more bits and the operands fewer. (Both philosophies are covered in Part C.)

Your turnMCQ, instructions

(1) Which format is used by stack machines? (2) Which instruction category changes the program's execution sequence? (3) An instruction has an 8-bit opcode, a 6-bit register field and an 18-bit address field: total length? (4) Which is NOT defined by the ISA: addressing modes, instruction formats, internal ALU implementation, or visible registers?

Answer

(1) zero-address (operands on the stack top). (2) control transfer (branch/jump/call). (3) 8 + 6 + 18 = 32 bits. (4) internal ALU implementation (that is organization, not the programmer-visible ISA).

Trap

"Zero-address" goes with the stack and operands on top of the stack; do not mix it up with three-address (the shortest program). And the ISA defines what the programmer sees (formats, modes, registers), never how the ALU is wired inside.
