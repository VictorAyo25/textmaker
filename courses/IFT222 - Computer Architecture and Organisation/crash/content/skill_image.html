Image and Memory Sizing

A small, reliable question: how much memory a picture needs. One formula and a couple of unit facts, and the marks are yours. We build it as a programme of tiny steps, worked through one at a time, so cover the page and check yourself as you go.

Work it frame by framecover, work, then slide down to check

Cover the page just below the first line with a card or your hand. Read a frame, do the small task, then slide the card down to the next line to check your answer. One step at a time, and do not skip.

A bitmap image (also called raster) is a grid of tiny squares, and each square stores its own colour as a few bits. So a bitmap picture is built out of what?

pixels. A vector image is different: it stores the shapes as maths (lines and curves), so it can be scaled to any size with no loss of quality. A logo that must be blown up to billboard size with no blur, bitmap or vector?

vector (the maths redraws it crisply at any size). A photograph, with its continuous shades, is stored as a bitmap. Read on.

Now colour depth, the number of bits each pixel uses. Monochrome (black or white only) needs 1 bit per pixel; greyscale is often 8 bits; full colour is 24 bits. How many bits per pixel does a monochrome image use?

1 bit (only two states, black or white). Now the size formula. The number of bits in a bitmap is width in pixels × height in pixels × bits per pixel. Picture a small 100 by 50 pixel monochrome image. Work out 100 × 50 × 1.

5000 bits. To turn bits into bytes, divide by 8. What is 5000 ÷ 8?

625 bytes. So the whole chain is pixels across × pixels down × bits per pixel, then ÷ 8 for bytes. Read on.

Often the size is given in inches at a certain dpi (dots per inch). Get the pixels first: pixels = inches × dpi, the same way for width and for height. Take 2 inches at 300 dpi. How many pixels is 2 × 300?

600 pixels. Do that for the width and the height, then feed the two pixel counts into the size formula as before. Read on.

One last caution. A megabyte can mean 1024 × 1024 bytes or a plain one million bytes, and the two give slightly different answers, so always say which you used. That is the whole skill. Now work the example below with the answer covered.

Worked examplethe method, vertically

An image is 17.12 inches by 9.45 inches at 250 dpi, 1 bit per pixel. Find its memory in megabytes. The exam sets exactly this; sit it verbatim in the final mock.

Given 17.12 in × 9.45 in · 250 dpi · 1 bit per pixel
Formula pixels = inches × dpi (both ways) · bytes = pixels × bits / 8 · MB = bytes / 1024 / 1024
pixels across = 17.12 x 250 = 4280
pixels down   =  9.45 x 250 = 2362.5
total pixels  = 4280 x 2362.5 = 10 111 500
bytes = 10 111 500 / 8 = 1 263 937.5
MB    = 1 263 937.5 / 1024 / 1024 = 1.21 MB
10 111 500 pixels × 1 bit = 1 263 937.5 bytes ≈ 1.21 MB. Say which megabyte you used (1024 twice gives 1.21; a million gives about 1.26).

Now redo it: pixels first, times the bits per pixel, divide by 8, then by 1024 twice.

Your turnMCQ, images

(1) How many bits per pixel for a monochrome bitmap? (2) A logo must be enlarged to billboard size without losing quality: bitmap or vector? (3) Photographs are best represented as?

Answer

(1) 1 bit (two states). (2) vector (scales with no quality loss). (3) bitmap (a photo is a grid of continuous-tone pixels).
