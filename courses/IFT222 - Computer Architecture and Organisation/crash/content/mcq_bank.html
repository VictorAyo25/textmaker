Architecture versus Organization

  1. An engineer describes computer architecture as the "blueprint" of a system. Which analogy best represents computer organization?   (a) The owner of the building   (b) The cost estimate   (c) The construction process implementing the design   (d) The building design
  2. Which of the following is NOT an example of a computer architecture component?   (a) Memory technology used   (b) Addressing modes   (c) Register organization   (d) Instruction set
  3. A cloud computing provider improves application response time by introducing multiple levels of cache memory. This improvement is mainly related to:   (a) Data representation   (b) Character encoding   (c) ISA design   (d) Memory organization
  4. A laptop and a desktop both use x86 processors. The desktop performs significantly better due to more CPU cores and larger caches. This performance difference arises mainly from:   (a) Organizational differences   (b) Different programming languages   (c) Different operating systems   (d) Architectural incompatibility
  5. A bank upgrades its servers to processors with larger caches and faster RAM while retaining the same x86 instruction set. What has primarily changed?   (a) Architecture only   (b) Organization only   (c) Both architecture and organization   (d) Neither architecture nor organization
  6. A computer scientist states that architecture and organization must be studied together because:   (a) Organization alone determines functionality.   (b) Architecture alone determines performance.   (c) Both concepts refer to the same thing.   (d) Architecture defines capabilities, while organization determines efficiency and performance.
  7. A national supercomputing center is evaluating two competing processor designs. Processor X achieves higher benchmark performance but consumes significantly more power. Processor Y delivers slightly lower performance while offering substantially better energy efficiency and scalability. Considering contemporary computer architecture principles for high-performance computing, which evaluation is the most appropriate?   (a) Processor Y may represent the superior architectural choice because modern processor evaluation considers performance/scalability, power efficiency, thermal constraints, and total cost of ownership rather than peak speed alone.   (b) Both processors are architecturally equivalent.   (c) Processor X is always preferable because peak performance is the sole design objective.   (d) Energy efficiency has no relevance in processor architecture.
  8. A research laboratory designs a custom processor specifically optimized for matrix multiplication in artificial intelligence workloads. This design illustrates which architectural principle?   (a) General-purpose optimization always outperforms specialization.   (b) Matrix operations require no architectural optimization.   (c) Specialized architectures eliminate software dependence.   (d) Domain-specific architectures can significantly improve efficiency for targeted applications.
  9. Which statement best characterizes the distinction between computer architecture and computer engineering?   (a) Computer engineering excludes hardware design.   (b) Both disciplines are identical.   (c) Computer architecture concerns only software.   (d) Computer architecture focuses primarily on the conceptual design and operational behavior of computing systems, whereas computer engineering encompasses the broader design, implementation, and integration of hardware systems.
  10. Two processors implement exactly the same Instruction Set Architecture but exhibit significantly different execution times when running identical benchmark applications. Which explanation best accounts for this observation?   (a) Different ISAs always produce identical performance.   (b) The compiler determines all performance differences regardless of hardware.   (c) Identical ISAs require identical transistor layouts.   (d) Variations in clock frequency, cache hierarchy, execution units, and pipeline organization influence performance despite identical ISAs.
  11. Which statement most accurately reflects the role of abstraction in computer architecture?   (a) Abstraction eliminates hardware complexity entirely.   (b) Abstraction reduces processor speed.   (c) Abstraction only applies to programming languages.   (d) Abstraction enables designers to separate concerns across different layers, allowing software developers and hardware engineers to work independently while maintaining compatibility.
  12. A processor supports backward compatibility with software written twenty years ago despite significant improvements in hardware implementation. Which architectural philosophy is primarily responsible for this capability?   (a) Eliminating compiler optimizations.   (b) Maintaining a stable ISA while evolving the underlying organization and microarchitecture.   (c) Replacing the ISA every processor generation.   (d) Increasing clock frequency only.
Answers

Answers

1. c architecture is the blueprint, organization is the construction that implements it.   2. a memory technology is an organization detail, not architecture.   3. d adding cache levels is a memory organization choice.   4. a same ISA, so the gap is organizational.   5. b the ISA is unchanged, only the organization improved.   6. d architecture sets capabilities, organization sets efficiency and performance.   7. a modern evaluation weighs power, thermal limits, scalability and cost, not peak speed alone.   8. d domain-specific architectures improve efficiency for targeted workloads.   9. d architecture is conceptual and operational design, engineering is the broader hardware build.   10. d clock, cache, execution units and pipeline vary despite an identical ISA.   11. d abstraction separates concerns across layers so hardware and software teams work independently.   12. b a stable ISA with an evolving organization preserves backward compatibility.

  12. Which of the following is NOT defined by an Instruction Set Architecture?   (a) Internal ALU implementation   (b) Addressing modes   (c) Instruction formats   (d) Programmer-visible registers

Answers

Answers

1. c addressing modes give the compiler efficient memory access.   2. d instruction formats are part of the programmer-visible ISA.   3. d supported instructions are defined by the architecture, the ISA.   4. a register-register arithmetic works straight from registers.   5. c the ISA is the programmer-visible interface.   6. b a conditional branch acts on the compare result.   7. b data transfer instructions move data between registers and memory.   8. b LOAD reads an operand from main memory.   9. d SIMD accelerates data-parallel computations.   10. a a shared Instruction Set Architecture runs the same binary.   11. b control transfer instructions redirect program flow.   12. a the internal ALU implementation is microarchitecture, not ISA.   13. a together they form the instruction set.

  3. An embedded processor minimizes silicon area and power consumption by reducing instruction complexity and relying heavily on compiler optimization. This design reflects:   (a) SIMD architecture   (b) RISC philosophy   (c) VLIW architecture   (d) CISC philosophy
  4. A computer architect wants to reduce compiler complexity by designing instructions that closely resemble high-level programming constructs. Which ISA philosophy best supports this objective?   (a) Stack-based ISA   (b) Harvard Architecture   (c) RISC   (d) CISC
Answers

Answers

1. b they reduce pipeline stalls from control hazards.   2. a variable-length instructions are a CISC trait.   3. b simple instructions plus heavy compiler reliance is the RISC philosophy.   4. d instructions resembling high-level constructs are CISC.

Von Neumann and Harvard, and the Rest

  1. For a monochrome bitmap image, each pixel requires:   (a) 2 bits   (b) 8 bits   (c) 1 bit   (d) 4 bits
  2. Photographs are generally better represented using:   (a) Vector graphics   (b) ASCII encoding   (c) Excess-3 encoding   (d) Bitmap graphics
  3. A processor fetches an instruction while simultaneously reading data from memory. Which architecture makes this possible?   (a) Stack Architecture   (b) CISC Architecture   (c) Von Neumann Architecture   (d) Harvard Architecture
  4. An embedded system uses separate memory modules for instructions and data to improve throughput. Which architectural design is being used?   (a) Von Neumann Architecture   (b) Stack Architecture   (c) Pipeline Architecture   (d) Harvard Architecture
  5. Which characteristic is a major advantage of the Harvard Architecture?   (a) Single memory space for all data   (b) Simpler hardware implementation   (c) Simultaneous access to instructions and data   (d) Reduced memory requirements
Answers

Answers

1. c a monochrome pixel is one bit.   2. d photographs suit bitmap graphics.   3. d Harvard has separate instruction and data memories, allowing simultaneous access.   4. d separate instruction and data memories is the Harvard design.   5. c Harvard allows simultaneous access to instructions and data.
