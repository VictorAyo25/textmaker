Foundations and Data

Number Systems and Conversions

Everything a computer holds is binary. This skill is turning numbers between binary, decimal and hexadecimal without thinking, plus the special decimal codes. It is easy marks and a big share of the objective questions.

TeachBases, and place value

A base is just how many symbols you count with before starting a new column. Decimal is base 10 (symbols 0 to 9). Computers use binary, base 2 (0 and 1), because a wire is either on or off. Binary gets long, so we write it in hexadecimal, base 16 (0 to 9 then A to F, where A = 10 up to F = 15). One binary digit is a bit; four bits are a nibble; eight bits are a byte.

In every base, a digit's value is the digit times the place value, and the places are powers of the base: reading right to left they are base0 = 1, then base, then base2, and so on. That one rule reads every base.

Must doThe three conversions, and powers of two
  • Any base to decimal: multiply each digit by its place value and add. In hex the places are 1, 16, 256, 4096.
  • Decimal to any base: divide repeatedly by the base, write down each remainder, then read the remainders bottom to top.
  • Binary to hex: group the bits into fours from the right, turn each group of four into one hex digit. Hex to binary is the reverse: each hex digit becomes four bits. This works because 16 = 24, so one hex digit is exactly four bits.

2n12481632641282565121024

Memory hook: know these powers of two cold; 210 = 1024 = "1 K", then 220 = 1 M, 230 = 1 G. Every cache and memory question needs them.

Worked examplehex to decimal

Convert the hex number 7D3A to decimal.

  1. Replace letters by values: 7, D = 13, 3, A = 10.
  2. Place values right to left: 1, 16, 256, 4096. So 7 is in the 4096 place, D in 256, 3 in 16, A in 1.
  3. Multiply and add: 7×4096 + 13×256 + 3×16 + 10×1 = 28 672 + 3328 + 48 + 10.
  4. Total = 32 058.
7D3A = 28 672 + 3328 + 48 + 10 = 32 058

Now redo it: the only hard part is remembering 4096, 256, 16, 1. Write those four first, then multiply.

Worked examplebinary to hex

Convert binary 11010110 to hex.

  1. Group in fours from the right: 1101  0110.
  2. Each group of four to one hex digit: 1101 = 8+4+1 = 13 = D; 0110 = 4+2 = 6.
  3. Write them in order: D6.
11010110 = 1101 0110 = D6 (check: both equal 214)

Now redo it: go backwards too. 2A7F to binary is 2=0010, A=1010, 7=0111, F=1111, giving 0010101001111111.

Your turnconvert three

(1) Write decimal 255 in hex. (2) How many hex digits does a 20-bit binary number need? (3) A hex value shifted right by one bit is the same as which operation?

Answer

(1) 255 = 15×16 + 15 = FF. (2) 20 ÷ 4 = 5 hex digits (one hex digit per four bits). (3) shifting right one bit is dividing by 2 (left one bit is times 2).

TeachDecimal codes: BCD, Excess-3, and characters

Sometimes we keep decimal digits as separate 4-bit codes rather than one binary number. The exam asks about three:

  • BCD (binary coded decimal), the 8421 code: write each decimal digit on its own as 4 bits. So 59 is 5 = 0101 and 9 = 1001, giving 0101 1001. It is a weighted code (the bits are worth 8, 4, 2, 1).
  • Excess-3: take the digit, add 3, then write that in 4 bits. So 9 becomes 9 + 3 = 12 = 1100. To read it back, subtract 3. It is non-weighted (the bits carry no fixed weights) and self-complementing: flipping all four bits gives the Excess-3 of the digit's 9's complement, which makes decimal subtraction easy.
  • Character codes: ASCII encodes English letters, digits and symbols in 7 or 8 bits; Unicode was introduced to cover the characters of all the world's languages. These are how text, not numbers, is stored.
Your turnMCQ, the codes

(1) The Excess-3 code for decimal 9 is? (2) The Excess-3 code 0110 is which decimal digit? (3) The 8421 BCD of decimal 59 is?

Answer

(1) 9 + 3 = 12 = 1100. (2) 0110 = 6, minus 3 = 3. (3) 5 = 0101, 9 = 1001, so 01011001. Remember: BCD is the digit itself in 4 bits; Excess-3 is the digit plus 3.

Trap

Group binary into fours from the right, never the left, and pad the leftmost group with leading zeros if it is short. And do not confuse the codes: BCD is weighted (8421) and is just the digit in binary; Excess-3 is non-weighted and is the digit plus 3. "BCD" stands for binary coded decimal, nothing else.
