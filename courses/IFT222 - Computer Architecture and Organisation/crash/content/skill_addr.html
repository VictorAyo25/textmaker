The Machine

Addressing Modes

An address field in an instruction does not always hold the operand directly. The addressing mode says how to turn that field into the real location, the effective address, and then the operand. Learn the six or seven modes as "how many hops through memory", and this is easy marks on both the paper and the objective test.

Here is the one idea behind every addressing mode. An instruction carries an address field, but that field does not always hold the operand you want. The mode is the rule for turning the field into the real place, and then the operand. What does the addressing mode tell you how to find?

the real location, then the operand. Two names to fix first. The real location of the operand is the effective address, or EA. And M[x] is shorthand for "the value stored at address x", so M[1200] is the value sitting at address 1200. In words, what does M[4500] mean?

the value stored at address 4500. We will grade every mode by one question: how many hops through memory does it take to reach the operand? We start with the fewest. Read on.

Immediate mode. The operand is a plain constant written inside the instruction itself, so you never touch memory to fetch it. How many memory hops does immediate mode need?

zero. Needing no memory access, immediate is the fastest way to supply a constant. Next, direct mode: the field is the address, so EA = the field and the operand = M[field], one hop into memory. Direct mode reads memory how many times?

once (one hop). Indirect mode adds one more hop. Now the field holds the address of the address: first EA = M[field], then the operand = M[ M[field] ]. That is two hops, a pointer to a pointer. How many hops does indirect mode take?

two. Because indirect follows an address that is itself stored in memory, it is exactly what you need to chase pointers, for example down a linked list. Read on.

Two modes lean on a register instead of memory. Register mode: the operand sits in a named register, so no memory hop at all. Register indirect: the register holds an address, so the operand is M[register], one hop. In register-indirect, is the operand in the register, or at the address the register holds?

at the address the register holds. Last group, the "add" modes; each adds something to the field to make the EA. Relative: EA = PC + field. Indexed: EA = index register + field. Base: EA = base register + displacement. What does relative mode add to the field?

the PC. Now put it to work on one running example. Take PC = 7000, R1 = 1500, address field = 1200, and memory holds M[1200] = 4500, M[4500] = 999, M[1500] = 6000. Keep these in view. First, direct (EA = field, operand = M[field]). Give the direct operand.

4500. (EA = 1200, operand = M[1200] = 4500.) Now indirect on the same field: first EA = M[1200], then operand = M[that]. Work both hops and give the indirect operand.

999. (EA = M[1200] = 4500, then operand = M[4500] = 999.) Now register indirect with R1 = 1500: the register holds the address, so operand = M[R1]. Give the register-indirect operand.

6000. (R1 = 1500, so operand = M[1500] = 6000.) Finally relative, an add-mode: EA = PC + field, with PC = 7000 and field = 1200. Give the relative EA.

8200. (7000 + 1200 = 8200. The table gives no M[8200], so you would report the EA and never invent a value.) Read on.

Now the whole thing on one card. Immediate = the operand is in the instruction (zero hops). Direct = one hop. Indirect = two hops. And the add-modes (relative, indexed, base) add a register or the PC to the field first, then read there. Order these by hops, fewest first: direct, immediate, indirect.

immediate (0), direct (1), indirect (2). That is every mode you need. Now study the worked example and recall below, which run this exact PC = 7000, R1 = 1500, field = 1200 example, and sit them with the answers covered.

Must doThe modes, as hops

The effective address (EA) is where the operand really is; M[x] means "the value stored at address x". Each mode is one more hop than the last:

Memory hook: immediate = in the instruction (zero hops, fewest memory accesses); direct = one hop; indirect = two hops (a pointer to a pointer). Register indirect uses a register as the pointer; relative, indexed and base all add something to the field.

Your turnMCQ, work the EA

(1) R1 = 2000, M[2000] = 500. Register-indirect operand? (2) Instruction address 500, displacement +30, PC-relative EA? (3) R2 = 300 (index), displacement 20, indexed EA? (4) Base register 4000, displacement 120, base EA? (5) Address 700, M[700] = 1500, M[1500] = 60. Indirect operand?

Answer

(1) M[2000] = 500. (2) 500 + 30 = 530. (3) 20 + 300 = 320. (4) 4000 + 120 = 4120. (5) M[700] = 1500, then M[1500] = 60.

Your turnMCQ, pick the mode

(1) A constant is embedded in the instruction: which mode? (2) Which mode needs the fewest memory accesses? (3) Which mode best suits following pointers in a linked list?

Answer

(1) immediate. (2) immediate (the operand is already in the instruction, no memory hop). (3) indirect (it dereferences a pointer, which is exactly what a linked list needs).

Trap

When a question gives you M[EA], read what it asks: the effective address is the location, the operand is the value there. For indexed, base and relative modes, you add the register or PC to the field to get the EA; the value stored at that EA is the operand, one further hop.
