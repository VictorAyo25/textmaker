As printed25/26 Q1(a)

the examiner's words, unedited

a. i) Computer Systems are designed using two closely related but distinct concepts which are Computer Architecture and Computer Organization. Differentiate between these concepts. 2mks ii) Compare Von Neumann Architecture and Harvard Architecture. Include a diagram for each. 3mks
In the hall25/26 Q1(a)

i) Architecture vs organization. Architecture is what the machine does as the programmer sees it (the instruction set, data types, addressing modes, registers), the "what". Organization is how it is built to do it (control signals, buses, memory technology, cache), the "how".

ii) Von Neumann vs Harvard. Von Neumann uses one memory and one bus for both instructions and data (simple, but the shared path is a bottleneck). Harvard uses separate memories and buses for instructions and data, so it can fetch an instruction and read data at the same time. Draw each: Von Neumann has CPU joined to a single Memory block; Harvard has CPU joined to a separate Instruction memory and Data memory.

b. A computer manufacturer is evaluating whether to replace a non-pipelined processor with a five-stage pipelined processor. In the hall25/26 Q1(b)
Given mix arithmetic 40%, memory 35%, branch 20%, floating point 5% ; five stage times 5, 4, 6, 5, 4 ns ; register overhead 1 ns ; non-pipelined clock 25 ns ; IC = 20 000 000 ; branch adds a 2-cycle penalty, floating point adds 4 extra cycles, a memory access misses 10% of the time adding 4 more.
Find pipelined clock, actual CPI, execution time, speedup, and why it is short of the max

       = 6 + 1 = 7 ns

CPI    = 1                (base, one per cycle)
       + 0.20 x 2         (branch)
       + 0.35 x 2.4       (memory: 2 + 0.10x4)
       + 0.05 x 4         (floating point)

Formula ideal = (k + n − 1) cycles, then add every stall: 1 per load-use, and (EX cycles − 1) per multi-cycle execute

Hazards

c. i) State Amdahl's law' 2mks ii) Assume in hypothetical system cache is 10 times faster than main memory and CPU accesses the cache 85% of the time. Using Amdahl's law, calculate the overall speed up of the system. 2mks
In the hall25/26 Q3(c)
Given cache 10 times faster than memory ; used 85% of the time
Find state Amdahl's law, then the overall speedup
Formula S = 1 / ((1−f) + f/s), with f the sped-up fraction and s its speedup

Amdahl's law: the overall speedup from improving part of a task is limited by the fraction of the time that part takes; as the improved part gets infinitely fast the speedup can never beat 1/(1−f).

f = 0.85 (cache hits), s = 10
S = 1 / ((1 - 0.85) + 0.85/10)
  = 1 / (0.15 + 0.085)
  = 1 / 0.235
  = 4.26
S = 4.26, far below 10, because the 15% of slow accesses dominate.

c. Explain the following terms 3mks i. Locality of reference ii. Temporal locality
In the hall25/26 Q5(c)

i) Locality of reference: the tendency of a program to reuse a small set of memory locations over a short time, which is why a small fast cache satisfies most accesses.

ii) Temporal locality: a location used now is likely to be used again soon (reusing the same instruction or variable). (Its partner, spatial locality, is about nearby locations being used next.)
