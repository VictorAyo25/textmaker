Question Onecompulsory, 30 marks

a) Three IEEE-754 single-precision numbers: X = C1400000, Y = 42100000, Z = 41400000. Convert to decimal and test the claims (for example is Y − Z > 0, is Z = X + Y). b) A five-stage pipeline performance question with an instruction mix. c) Store −182, 487, −1023 in a 16-bit two's-complement machine (binary and hex) and add (−182) + 487. d) Average CPI from an addressing-mode mix, then optimise one row and give the percent improvement. e) Effective address and operand for six addressing modes from a memory table (PC = 7000, field 1200).

Answers

a) X = −1.5×23 = −12; Y = 1.125×25 = 36; Z = 1.5×23 = 12. So Y − Z = 24 > 0 is true; X + Z = 0 is true; Z = X + Y (12 = 24) is false. (Skill: Floating Point.) b) clock = slowest stage + overhead, actual CPI = 1 + weighted extra cycles, time = IC×CPI×T. (Skills: CPU Performance and Pipelining.) c) 487 = 01E7, −182 = FF4A, −1023 = FC01, sum = 305. (Skill: Signed Numbers.) d) CPI 1.70, then 1.50, improvement 11.76%. (Skill: CPU Performance.) e) Immediate 1200, Direct 4500, Indirect 999, Register 1500, Register indirect 6000, Relative EA 8200. (Skill: Addressing Modes.)

Question Two20 marks

a) 32-bit addresses, 16 words per block, direct-mapped cache of 256 blocks: which cache line (in decimal) do CA2DFC12, F24F25FF, 24BBABCD, C1D9EEF2 map to? b) A classic five-stage RISC pipeline runs LW, ADD, SUB, SW, BEQ, MUL with forwarding, a one-cycle load-use stall and a three-cycle multiply: identify the hazards and give the total cycles. c) 1 GB memory, 512 KB cache, 128-byte blocks, 4-way set associative: blocks, sets, address format, and AMAT at 96% hits, 2 ns cache, 80 ns memory.

Answers

a) offset 4 bits, index 8 bits: read the last hex digit off and take the next two. Lines: CA2DFC12 → 193, F24F25FF → 95, 24BBABCD → 188, C1D9EEF2 → 239. (Skill: Memory and Cache.) b) one load-use RAW stall plus two extra multiply cycles give 13 cycles. (Skill: Pipelining.) c) blocks = 512 KB / 128 B = 4096; sets = 4096 / 4 = 1024; address 30 bits = tag 13 / set 10 / offset 7; AMAT = 2 + 0.04×80 = 5.2 ns. (Skill: Memory and Cache.)

Question Three20 marks

a) 64 MB memory, 128 KB cache, 64-byte blocks: number of lines, and the direct and 4-way field splits. b) A five-stage pipeline where execute takes 1 cycle for ADD/SUB, 3 for MUL, 6 for DIV: schedule four instructions with and without operand forwarding and count cycles. c) State Amdahl's law and use it: a cache 10 times faster than memory, used 85% of the time.

Answers

a) lines = 128 KB / 64 B = 2048; address 26 bits; direct: index 11, tag 9, offset 6; 4-way: set 9, tag 11, offset 6. (Skill: Memory and Cache.) b) build the cycle diagram row by row; the long DIV fixes everything behind it. Total 15 cycles with forwarding, 17 cycles without. (Skill: Pipelining.) c) S = 1 / ((1−0.85) + 0.85/10) = 1 / 0.235 = 4.26. (Skill: CPU Performance.)

Question Four20 marks

a) The IEEE-754 conversions again (as Q1a). b) Write X = ((A×B) + C/D) / (F×G + J×K) in zero, one, two and three-address formats. c) Memory for an image 17.12 by 9.45 inches at 250 dpi, in megabytes.

Answers

a) as Question 1a. b) do the numerator and denominator first, then divide; the three-address version is 7 instructions ending DIV X, R1, R2 (numerator over denominator, not R2, R3). (Skill: Instruction Sets and Formats.) c) pixels = (17.12×250)×(9.45×250) = 10 111 500; at 1 bit = 1 263 937.5 bytes ≈ 1.21 MB. (Skill: Image and Memory Sizing.)

Question Five20 marks

a) Represent −1240.56 in single-precision IEEE-754. b) A pipeline of 4 phases 60, 50, 90, 80 ns with a 10 ns latch: cycle time, one-task time, speedup, and the times for 500 tasks.

Answers

a) sign 1; 1240.56 = 1.21...×210, so exponent field 10 + 127 = 137; fill the 23 mantissa bits and round. The pattern is C49B11EB truncated (C49B11EC if you round the last bit). State which you did. (Skill: Floating Point.) b) cycle 100 ns, one task 280 ns, speedup 2.8, 500 tasks pipelined 50 300 ns against sequential 140 000 ns. (Skill: Pipelining.)
