Part A, Foundations and Data

SkillRemember this
Number systemsPowers of the base, right to left; 4 bits = 1 hex digit. To decimal: digit × place, then add. To another base: divide, read remainders bottom to top.
Signed numbersFlip and add one, to write a negative and to read one. Add the patterns, drop the top carry. Range −2n−1 to 2n−1 − 1.
IEEE-754Sign, exponent, mantissa (1 + 8 + 23, bias 127). value = ± 1.M × 2(field − 127). Hide the leading 1.
Image sizingpixels = inches × dpi; bits = pixels × depth; bytes = bits ÷ 8; MB = ÷ 1024 twice.
Architecture vs organizationArchitecture = the blueprint (what, the ISA); organization = the construction (how). Von Neumann shares one memory, Harvard splits the two.

Part B, The Machine

SkillRemember this
InstructionsOpcode = what, operands = what to. Fewer addresses, shorter but more of them. bytes = opcode + (addresses × bytes each).
Addressing modesCount the hops: immediate 0, direct 1, indirect 2. EA is the place; operand is M[EA]. Indexed, base, relative add to the field.
CPU performanceTime = IC × CPI × T. CPI = Σ(fraction × cycles). Improvement = (old − new)/old. Amdahl S = 1/((1−f) + f/s), ceiling 1/(1−f).
PipeliningClock = slowest stage + latch. n tasks = (k + n − 1) cycles, speedup up to k. Hazards RAW/WAR/WAW by the register order.
Memory and cacheOffset, index, tag = byte, hook, block. offset = log2(block), lines = cache ÷ block, index = log2(lines), tag = the rest. AMAT = Tc + (1−h)×Tm.

Part C, Prove It

SkillRemember this
RISC vs CISCRISC: few, fixed, one-cycle, pipelines cleanly. CISC: many, complex, variable-length. A stable ISA gives backward compatibility; SIMD accelerates data-parallel work.
Sitting the paperQuestion One is compulsory (30 marks), then any two of Questions Two to Five (20 each). Every answer: the Given, the Formula, the working stacked vertically, then the answer. Never write a bare number without its formula above it. Go and pass.
