Module Three · Unit 2

Semiconductor Memory

The chips that make up main memory: read-write RAM and read-only ROM, and the two kinds of RAM the exam always compares, DRAM and SRAM.

By the end of this unit you can distinguish RAM from ROM and give four differences between DRAM and SRAM, the exact question that recurs on the paper.

TeachRAM and ROM

RAM (Random Access Memory) is read-write and volatile: it loses its contents when power is removed. It holds the running program and its data. ROM (Read Only Memory) is read-mostly and non-volatile: it keeps its contents without power, and holds firmware such as the boot code. Both are random access: any location takes the same time to reach.

TeachDRAM and SRAM

RAM comes in two technologies. Dynamic RAM (DRAM) stores each bit as a charge on a tiny capacitor, which leaks, so it must be refreshed thousands of times a second. Static RAM (SRAM) stores each bit in a latch of several transistors, which holds as long as power is on, so it needs no refresh. SRAM is faster and simpler to use but larger and dearer per bit, so it is used for cache; DRAM is denser and cheaper, so it is used for main memory.

Recall and check

Why is SRAM used for cache and DRAM for main memory?

Answer

SRAM is faster and needs no refresh, which suits the small, speed-critical cache; DRAM is denser and cheaper per bit, which suits large main memory where cost per bit matters more than raw speed.
