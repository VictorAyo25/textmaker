How to Attack an Objective Question

Thirty of these decide the first third of the paper, and they are answered under more time pressure than anything in the theory half. This part is where you practise them.

Teach

An objective question is not a smaller version of a theory question. It is a different task: you are not producing an answer, you are eliminating three wrong ones. That changes the method, and the method is worth marks on its own.

Every question below came from one of the two computer-based tests actually set on this course. Both are reproduced whole, 60 questions each, grouped by topic rather than by test so that a run of questions drills one skill at a time. The stems and options were read off the test screenshots by eye. That is a weaker guarantee than the four written papers in this book carry, since those are held character for character against a transcript by a gate, and it is said here rather than left for you to assume.

Key point

In a four-option question, three options are wrong for a statable reason. Finding the reason is faster and safer than recognising the right answer, because recognition is exactly what a well-written distractor attacks.

Blunt version: do not look for the right one. Kill the wrong ones.

Teach

The four moves, in order, on every question:

  1. Read the stem twice and underline the instruction word. NOT, BEST, MOST DIRECTLY, PRIMARILY and EXCEPT each flip or narrow the question, and each one appears on these tests. A question containing NOT wants the odd one out, and reading it as a normal question makes every wrong answer look right.
  2. Answer it before you read the options where you can. If you know that organization is the construction and architecture is the blueprint, decide that first. Then the options are a lookup, not a suggestion.
  3. Strike the impossible. Two of the four usually die immediately: an option that contradicts a definition, names the wrong layer, or is true but answers a different question. Cross them out physically.
  4. Choose between the last two on the exact wording. This is where the mark is won or lost, and it is nearly always one word: only, always, all, determines, eliminates. A distractor that says "eliminates hardware complexity entirely" is wrong because of "entirely", not because of hardware complexity.
Trap

The longest option is right more often than chance on these two tests, because a fully qualified statement takes more words than a slogan. Do not turn that into a rule. It is a tiebreaker for a question you cannot otherwise split, and nothing more. Several questions here punish it deliberately.

Trap

One question on Test 1 asks how a floating point number is stored and its marked answer is Sign, Mantissa, Exponent. The true IEEE 754 field order, the one Module One Unit 3 teaches and the one every other question in this book uses, is Sign, Exponent, Mantissa. Learn the true order, and know that this particular question was marked the other way. Both facts are worth carrying: one is correct, the other is what the marking scheme did.

How to use this part

Sit one topic at a time, timed at 45 seconds a question, with the answers covered. Then read the answer block for that topic in full, including the explanations for the questions you got right: on an objective paper, a right answer for a wrong reason is a mark you will not get twice.

Architecture versus Organization

12 questions. Taught in Module One, Unit 1. Cover the answers before you start.

  1. TEST 1 Q16 An engineer describes computer architecture as the "blueprint" of a system. Which analogy best represents computer organization?   (a) The owner of the building   (b) The cost estimate   (c) The construction process implementing the design   (d) The building design
  2. TEST 1 Q24 Which of the following is NOT an example of a computer architecture component?   (a) Memory technology used   (b) Addressing modes   (c) Register organization   (d) Instruction set
  3. TEST 1 Q33 A cloud computing provider improves application response time by introducing multiple levels of cache memory. This improvement is mainly related to:   (a) Data representation   (b) Character encoding   (c) ISA design   (d) Memory organization
  4. TEST 1 Q34 A laptop and a desktop both use x86 processors. The desktop performs significantly better due to more CPU cores and larger caches. This performance difference arises mainly from:   (a) Organizational differences   (b) Different programming languages   (c) Different operating systems   (d) Architectural incompatibility
  5. TEST 1 Q35 A bank upgrades its servers to processors with larger caches and faster RAM while retaining the same x86 instruction set. What has primarily changed?   (a) Architecture only   (b) Organization only   (c) Both architecture and organization   (d) Neither architecture nor organization
  6. TEST 1 Q41 A computer scientist states that architecture and organization must be studied together because:   (a) Organization alone determines functionality.   (b) Architecture alone determines performance.   (c) Both concepts refer to the same thing.   (d) Architecture defines capabilities, while organization determines efficiency and performance.
  7. TEST 2 Q26 A national supercomputing center is evaluating two competing processor designs. Processor X achieves higher benchmark performance but consumes significantly more power. Processor Y delivers slightly lower performance while offering substantially better energy efficiency and scalability. Considering contemporary computer architecture principles for high-performance computing, which evaluation is the most appropriate?   (a) Processor Y may represent the superior architectural choice because modern processor evaluation considers performance/scalability, power efficiency, thermal constraints, and total cost of ownership rather than peak speed alone.   (b) Both processors are architecturally equivalent.   (c) Processor X is always preferable because peak performance is the sole design objective.   (d) Energy efficiency has no relevance in processor architecture.
  8. TEST 2 Q27 A research laboratory designs a custom processor specifically optimized for matrix multiplication in artificial intelligence workloads. This design illustrates which architectural principle?   (a) General-purpose optimization always outperforms specialization.   (b) Matrix operations require no architectural optimization.   (c) Specialized architectures eliminate software dependence.   (d) Domain-specific architectures can significantly improve efficiency for targeted applications.
  9. TEST 2 Q31 Which statement best characterizes the distinction between computer architecture and computer engineering?   (a) Computer engineering excludes hardware design.   (b) Both disciplines are identical.   (c) Computer architecture concerns only software.   (d) Computer architecture focuses primarily on the conceptual design and operational behavior of computing systems, whereas computer engineering encompasses the broader design, implementation, and integration of hardware systems.
  10. TEST 2 Q38 Two processors implement exactly the same Instruction Set Architecture but exhibit significantly different execution times when running identical benchmark applications. Which explanation best accounts for this observation?   (a) Different ISAs always produce identical performance.   (b) The compiler determines all performance differences regardless of hardware.   (c) Identical ISAs require identical transistor layouts.   (d) Variations in clock frequency, cache hierarchy, execution units, and pipeline organization influence performance despite identical ISAs.
  11. TEST 2 Q46 Which statement most accurately reflects the role of abstraction in computer architecture?   (a) Abstraction eliminates hardware complexity entirely.   (b) Abstraction reduces processor speed.   (c) Abstraction only applies to programming languages.   (d) Abstraction enables designers to separate concerns across different layers, allowing software developers and hardware engineers to work independently while maintaining compatibility.
  12. TEST 2 Q54 A processor supports backward compatibility with software written twenty years ago despite significant improvements in hardware implementation. Which architectural philosophy is primarily responsible for this capability?   (a) Eliminating compiler optimizations.   (b) Maintaining a stable ISA while evolving the underlying organization and microarchitecture.   (c) Replacing the ISA every processor generation.   (d) Increasing clock frequency only.
Answers, and why every option is what it is

1. The answer is The construction process implementing the design. Architecture is what the machine looks like to the programmer, the blueprint. Organization is how that blueprint is actually built and wired up, the construction process.

  • The owner of the building. Wrong. The owner commissions the building. That is neither the design nor the act of building, so it maps to nothing in this pair.
  • The cost estimate. Wrong. A cost estimate is a budget. Organization is about how the design is realised in hardware, not what it costs.
  • The construction process implementing the design. Correct. Organization is the construction: the buses, the cache, the control paths that turn the blueprint into a working machine.
  • The building design. Wrong. The building design IS the blueprint, and the stem has already given the blueprint to architecture. Choosing the building design says architecture and organization are the same thing.

2. The answer is Memory technology used. Architecture is the programmer-visible contract: instruction set, addressing modes, registers. Which memory technology is fitted is an implementation choice, so it belongs to organization.

  • Memory technology used. Correct, and note the question asks which is NOT. Whether the machine uses SRAM, DRAM or flash cannot be seen from any program, so it is an organization decision.
  • Addressing modes. Wrong choice, because addressing modes ARE architecture. They are the ways an instruction may name its operand, written into the ISA.
  • Register organization. Wrong choice, because register organization IS architecture. The programmer-visible registers are named directly in instructions.
  • Instruction set. Wrong choice, because the instruction set IS the architecture, the very heart of it.

3. The answer is Memory organization. Adding cache levels changes nothing a programmer can see in the instruction set. It changes how memory is arranged behind the scenes.

  • Data representation. Wrong. Data representation is how numbers are encoded in bits. No number changed here.
  • Character encoding. Wrong. Character encoding is ASCII and Unicode, which have nothing to do with cache levels.
  • ISA design. Wrong. The instruction set is untouched. Programs run unmodified, they just run faster.
  • Memory organization. Correct. Levels of cache are an arrangement of memory, which is precisely what memory organization means.

4. The answer is Organizational differences. Both run the same x86 instruction set, so the architecture is identical. Cores and cache size are organization, and organization is where performance comes from.

  • Organizational differences. Correct. The stem names cores and caches, and both are organization.
  • Different programming languages. Wrong. No language is mentioned, and the same program is assumed on both machines.
  • Different operating systems. Wrong. No operating system is mentioned, and an OS would not account for a hardware gap of this kind.
  • Architectural incompatibility. Wrong, and impossible. Both are x86, so the architectures are identical, not incompatible.

5. The answer is Organization only. The instruction set is untouched, so the architecture is untouched. Bigger caches and faster RAM are pure organization. The giveaway phrase is "retaining the same instruction set".

  • Architecture only. Wrong, and backwards. The one thing explicitly UNCHANGED is the instruction set, which is the architecture.
  • Organization only. Correct. Cache size and RAM speed are implementation, so only the organization moved.
  • Both architecture and organization. Wrong. It would need the ISA to have changed too, and the stem rules that out.
  • Neither architecture nor organization. Wrong. Something did change: the caches and the memory. Only its category is in question.

6. The answer is Architecture defines capabilities, while organization determines efficiency and performance. The one-line rule for this whole topic: architecture says WHAT the machine can do, organization says HOW WELL it does it.

  • Organization alone determines functionality. Wrong, the two are swapped. Functionality, what the machine can do at all, comes from the architecture.
  • Architecture alone determines performance. Wrong, swapped the other way. Performance comes from the organization, which is why two x86 chips differ in speed.
  • Both concepts refer to the same thing. Wrong. If they were the same thing there would be nothing to study together, and the whole distinction would collapse.
  • Architecture defines capabilities, while organization determines efficiency and performance. Correct, and this is the sentence to memorise for every question in this topic.

7. The answer is Processor Y may represent the superior architectural choice because modern processor evaluation considers performance/scalability, power efficiency, thermal constraints, and total cost of ownership rather than peak speed alone. Modern evaluation weighs performance per watt, thermal limits, scalability and total cost of ownership, not peak speed alone. On this paper, any option containing an absolute such as "always", "sole" or "no relevance" is the wrong one.

  • Processor Y may represent the superior architectural choice because modern processor evaluation considers performance/scalability, power efficiency, thermal constraints, and total cost of ownership rather than peak speed alone. Correct, and note the hedged verb "may represent". It weighs several criteria instead of crowning one.
  • Both processors are architecturally equivalent. Wrong. The stem itself lists differences in performance, power and scalability, so they cannot be equivalent.
  • Processor X is always preferable because peak performance is the sole design objective. Wrong on two counts: "always" admits no trade-off, and peak performance is not the sole objective in a facility that must be powered and cooled.
  • Energy efficiency has no relevance in processor architecture. Wrong, and the strongest claim of the four. Power is a first-order constraint in high-performance computing, since a machine that cannot be cooled cannot be run.

8. The answer is Domain-specific architectures can significantly improve efficiency for targeted applications. Building the silicon around one workload is the definition of a domain-specific architecture, and the payoff is efficiency on that workload.

  • General-purpose optimization always outperforms specialization. Wrong, and contradicted by the stem. If general-purpose always won, nobody would build the custom chip described.
  • Matrix operations require no architectural optimization. Wrong. The entire scenario exists because matrix work rewards architectural optimisation.
  • Specialized architectures eliminate software dependence. Wrong. A specialised chip still needs drivers, libraries and compilers. Hardware never removes the software.
  • Domain-specific architectures can significantly improve efficiency for targeted applications. Correct. Narrow the workload, and you may spend the transistors where that workload actually needs them.

9. The answer is Computer architecture focuses primarily on the conceptual design and operational behavior of computing systems, whereas computer engineering encompasses the broader design, implementation, and integration of hardware systems. Architecture is the conceptual and operational design. Engineering is the wider job of designing, implementing and integrating real hardware.

  • Computer engineering excludes hardware design. Wrong, and the reverse of the truth. Hardware design is the core of computer engineering.
  • Both disciplines are identical. Wrong. Architecture is one concern inside the broader engineering discipline, not a synonym for it.
  • Computer architecture concerns only software. Wrong. Architecture is the interface BETWEEN hardware and software, so it can never be software only.
  • Computer architecture focuses primarily on the conceptual design and operational behavior of computing systems, whereas computer engineering encompasses the broader design, implementation, and integration of hardware systems. Correct. Conceptual and operational design on one side, the broader build and integration of hardware on the other.

10. The answer is Variations in clock frequency, cache hierarchy, execution units, and pipeline organization influence performance despite identical ISAs. A shared ISA guarantees the same instructions, never the same speed. Clock, cache, execution units and pipeline depth are microarchitecture, and they are free to differ.

  • Different ISAs always produce identical performance. Wrong, and it answers a question that was not asked. The stem says the ISAs are the SAME, and the claim itself is false anyway.
  • The compiler determines all performance differences regardless of hardware. Wrong. The benchmark is identical on both machines, so the compiler is a constant here, not a variable.
  • Identical ISAs require identical transistor layouts. Wrong, and it is the exact misconception being tested. An ISA fixes the interface, never the transistors under it.
  • Variations in clock frequency, cache hierarchy, execution units, and pipeline organization influence performance despite identical ISAs. Correct. This is the microarchitecture, and it is where identical-ISA machines diverge.

11. The answer is Abstraction enables designers to separate concerns across different layers, allowing software developers and hardware engineers to work independently while maintaining compatibility. Abstraction hides complexity behind a stable interface, it does not delete it. That separation of layers is what lets the two sides of the industry work independently and still interoperate.

  • Abstraction eliminates hardware complexity entirely. Wrong. The complexity is still there, it is merely hidden behind the interface. "Entirely" gives this away.
  • Abstraction reduces processor speed. Wrong. Abstraction is a design principle, not a runtime cost imposed on the processor.
  • Abstraction only applies to programming languages. Wrong. The layering runs from transistors up through logic, microarchitecture, ISA, operating system and applications.
  • Abstraction enables designers to separate concerns across different layers, allowing software developers and hardware engineers to work independently while maintaining compatibility. Correct. Separation of concerns across layers, with compatibility preserved at each interface.

12. The answer is Maintaining a stable ISA while evolving the underlying organization and microarchitecture. Old binaries keep running because the programmer-visible contract, the ISA, is frozen. Everything under it is free to be rebuilt generation after generation.

  • Eliminating compiler optimizations. Wrong. Twenty-year-old binaries were compiled long ago, so nothing the compiler does now affects whether they run.
  • Maintaining a stable ISA while evolving the underlying organization and microarchitecture. Correct. Freeze the interface, evolve the implementation. That is the whole trick of backward compatibility.
  • Replacing the ISA every processor generation. Wrong, and it is the opposite policy. A new ISA every generation would break every old program.
  • Increasing clock frequency only. Wrong. A faster clock makes old software run faster, it does not make it run at all.

Instruction Set Architecture and Microarchitecture

13 questions. Taught in Module One, Unit 4. Cover the answers before you start.

  1. TEST 1 Q22 A game console experiences improved frame rates because the compiler uses efficient memory-access techniques. Which architectural component is most directly involved?   (a) Control signals   (b) System buses   (c) Addressing modes   (d) Memory chips
  2. TEST 1 Q39 Which of the following would most likely be visible to a programmer?   (a) Memory chip technology   (b) Cache implementation details   (c) Control signal generation circuitry   (d) Instruction formats
  3. TEST 1 Q50 A programmer wants to know whether a processor supports floating-point instructions. This concern relates to:   (a) Control signals   (b) Memory hierarchy   (c) Bus organization   (d) Computer architecture
  4. TEST 2 Q5 A compiler attempts to minimize memory accesses by keeping frequently used variables inside processor registers. Which instruction category benefits the most?   (a) Register-register arithmetic   (b) Privileged instructions   (c) Input/output instructions   (d) Interrupt instructions
  5. TEST 2 Q6 Which statement best distinguishes ISA from microarchitecture?   (a) ISA specifies transistor layout.   (b) ISA determines cache replacement policies.   (c) ISA specifies the programmer-visible interface.   (d) ISA defines how instructions are executed internally.
  6. TEST 2 Q10 Which instruction is typically executed immediately after a successful comparison operation?   (a) Divide   (b) Conditional Branch   (c) STORE   (d) LOAD
  7. TEST 2 Q13 Which instruction category is responsible for moving data between CPU registers and memory?   (a) Floating-point instructions   (b) Data transfer instructions   (c) Control instructions   (d) Logical instructions
  8. TEST 2 Q14 Which instruction would most likely access the main memory?   (a) XOR   (b) LOAD   (c) SHIFT   (d) ADD
  9. TEST 2 Q16 Why are specialized instructions such as SIMD instructions introduced into modern processors?   (a) To increase instruction fetch time   (b) To simplify cache design   (c) To eliminate registers   (d) To accelerate data-parallel computations
  10. TEST 2 Q22 A software developer successfully runs the same compiled application on two processors from different manufacturers. This is possible because both processors implement the same:   (a) Instruction Set Architecture   (b) Microarchitecture   (c) Control unit design   (d) Cache hierarchy
  11. TEST 2 Q33 Which instruction category primarily changes the sequence of program execution?   (a) Arithmetic   (b) Control Transfer   (c) Data Transfer   (d) Logical
  12. TEST 2 Q40 Which of the following is NOT defined by an Instruction Set Architecture?   (a) Internal ALU implementation   (b) Addressing modes   (c) Instruction formats   (d) Programmer-visible registers
  13. TEST 2 Q55 A processor supports arithmetic, logical, branch, load/store, and input/output instructions. These collectively constitute its:   (a) Instruction set   (b) Address bus   (c) Register file   (d) Pipeline stages
Answers, and why every option is what it is

1. The answer is Addressing modes. Addressing modes are the ways an instruction may name its operand, and they are the part of the ISA a compiler actually chooses between when it optimises memory access.

  • Control signals. Wrong. Control signals are generated by the hardware itself. A compiler cannot select them.
  • System buses. Wrong. Buses are physical organization. The compiler cannot choose a different bus.
  • Addressing modes. Correct. The stem says the COMPILER did it, and addressing modes are the memory-access choice available to a compiler.
  • Memory chips. Wrong. Memory chips are hardware fitted to the board, invisible to and unselectable by the compiler.

2. The answer is Instruction formats. Instruction formats are part of the ISA, which is by definition the programmer-visible interface. Everything else listed sits below that line, in the organization.

  • Memory chip technology. Wrong. A program behaves the same whichever memory technology is fitted, so the technology is invisible to it.
  • Cache implementation details. Wrong. Cache is deliberately transparent: it changes timing, never results.
  • Control signal generation circuitry. Wrong. Control circuitry is deep microarchitecture, generated inside the processor and never named by a program.
  • Instruction formats. Correct. A programmer or compiler must know the exact bit layout to encode an instruction at all.

3. The answer is Computer architecture. Which instructions EXIST is an architecture question, settled by the ISA. How fast they run would be an organization question.

  • Control signals. Wrong. Control signals implement instructions that already exist, they do not decide which exist.
  • Memory hierarchy. Wrong. The memory hierarchy affects how quickly operands arrive, not whether an instruction is supported.
  • Bus organization. Wrong. Bus organization is about moving data between units, again a speed matter.
  • Computer architecture. Correct. The set of supported instructions is exactly what the architecture defines.

4. The answer is Register-register arithmetic. Register-register arithmetic takes both operands from registers and writes the result back to a register, so it never touches memory at all.

  • Register-register arithmetic. Correct. Operands already in registers is precisely the condition this category needs.
  • Privileged instructions. Wrong. Privileged instructions are about protection and operating-system mode, not operand location.
  • Input/output instructions. Wrong. Input/output instructions talk to devices, so keeping variables in registers does not help them.
  • Interrupt instructions. Wrong. Interrupt instructions handle external events. They are unaffected by where a variable lives.

5. The answer is ISA specifies the programmer-visible interface. The ISA is WHAT the machine does, the interface a programmer codes against. The microarchitecture is HOW it is done inside: transistors, caches, pipelines.

  • ISA specifies transistor layout. Wrong. Transistor layout is physical implementation, the far end of microarchitecture.
  • ISA determines cache replacement policies. Wrong. Cache replacement, whether LRU or random, is invisible to a program and is a microarchitecture policy.
  • ISA specifies the programmer-visible interface. Correct, and this is the definition to memorise.
  • ISA defines how instructions are executed internally. Wrong. "How instructions are executed internally" is the definition of MICROARCHITECTURE, offered here as the near miss.

6. The answer is Conditional Branch. A compare sets the condition flags. The instruction that reads those flags and decides where to go next is the conditional branch.

  • Divide. Wrong. Divide is arithmetic. It neither reads nor needs the condition flags.
  • Conditional Branch. Correct. Compare then branch is the standard pair, which is how an if statement is built.
  • STORE. Wrong. STORE writes a register to memory and ignores the flags.
  • LOAD. Wrong. LOAD reads memory into a register and also ignores the flags.

7. The answer is Data transfer instructions. Data transfer is the category that only moves values around: LOAD, STORE, MOVE. It changes location, never value.

  • Floating-point instructions. Wrong. Floating-point instructions compute on real numbers, they do not exist to move data.
  • Data transfer instructions. Correct. LOAD, STORE and MOVE are its members.
  • Control instructions. Wrong. Control instructions change which instruction runs next, not where data sits.
  • Logical instructions. Wrong. Logical instructions such as AND, OR and NOT compute on values already held.

8. The answer is LOAD. LOAD fetches an operand from main memory into a register. The others work on values already held in registers.

  • XOR. Wrong. XOR is a logical operation between register values.
  • LOAD. Correct. Reaching into memory for an operand is the entire job of a LOAD.
  • SHIFT. Wrong. SHIFT moves bits within a single register.
  • ADD. Wrong. ADD sums register values, which is why compilers work so hard to keep operands in registers.

9. The answer is To accelerate data-parallel computations. SIMD is Single Instruction, Multiple Data: one instruction applies the same operation to many values at once, which is exactly what graphics and matrix work need.

  • To increase instruction fetch time. Wrong, and nobody adds a feature to make fetching SLOWER.
  • To simplify cache design. Wrong. SIMD makes the datapath wider and the design more complex, not the cache simpler.
  • To eliminate registers. Wrong, and backwards. SIMD needs wide vector registers, so it adds register state rather than removing it.
  • To accelerate data-parallel computations. Correct. One instruction, many data elements, which is where the name comes from.

10. The answer is Instruction Set Architecture. A compiled binary is a stream of ISA instructions. Any processor implementing that ISA can execute it, whoever built it and however differently it is built inside.

  • Instruction Set Architecture. Correct. The ISA is the contract a binary is written against.
  • Microarchitecture. Wrong, and the point of the question is that the two microarchitectures are almost certainly different.
  • Control unit design. Wrong. Control unit design is internal and varies freely between manufacturers.
  • Cache hierarchy. Wrong. Cache sizes and levels differ between vendors and are invisible to the binary anyway.

11. The answer is Control Transfer. Control transfer instructions, the jumps, branches, calls and returns, write a new value into the program counter and so redirect the flow.

  • Arithmetic. Wrong. Arithmetic computes values, then execution simply falls through to the next instruction.
  • Control Transfer. Correct. Jump, branch, call and return are its members.
  • Data Transfer. Wrong. Data transfer moves values between registers and memory, leaving the flow untouched.
  • Logical. Wrong. Logical instructions compute a result. Only a following branch changes the sequence.

12. The answer is Internal ALU implementation. The ISA defines the instructions, their formats, their addressing modes and the registers you can name. How the ALU is built to carry out an ADD is microarchitecture.

  • Internal ALU implementation. Correct, and remember the question asks which is NOT. Two chips with the same ISA may use completely different adder designs, and no program can tell.
  • Addressing modes. Wrong choice. Addressing modes ARE in the ISA, since an instruction must state how it names its operand.
  • Instruction formats. Wrong choice. Instruction formats ARE in the ISA, since the bit layout must be fixed for code to be encoded.
  • Programmer-visible registers. Wrong choice. Programmer-visible registers ARE in the ISA, since instructions name them directly.

13. The answer is Instruction set. Every instruction a processor understands, taken together, is its instruction set. The five categories listed are the standard grouping of that set.

  • Instruction set. Correct. The word "collectively" is the clue: all the instructions together are the set.
  • Address bus. Wrong. The address bus is a set of wires carrying a location, not a collection of instructions.
  • Register file. Wrong. The register file is storage inside the CPU, not the operations it can perform.
  • Pipeline stages. Wrong. Pipeline stages are how one instruction is processed in steps, unrelated to how many instructions exist.

  15. TEST 1 Q57 Excess-3 code is:   (a) Non-weighted   (b) Weighted   (c) ASCII-based   (d) Floating-point
  16. TEST 1 Q59 The Excess-3 code 0110 corresponds to decimal:   (a) 6   (b) 9   (c) 12   (d) 3
Answers, and why every option is what it is

1. The answer is Binary Coded Decimal. Binary Coded Decimal. Each decimal digit is coded separately in four bits, which is why 59 becomes 0101 1001 rather than the pure binary 111011.

  • Binary Control Digit. Wrong. No such term. "Control" belongs to the control unit, not to a numeric code.
  • Base Conversion Decimal. Wrong. Base conversion is an operation you perform, not the name of a code.
  • Binary Coded Decimal. Correct. Binary Coded Decimal: decimal digits, each coded in binary.
  • Binary Character Decimal. Wrong. "Character" points at text codes such as ASCII, while BCD codes numbers.

2. The answer is FF. 255 = 15 x 16 + 15, and 15 is F, so the answer is FF. Worth memorising: 255 is FF, is 11111111, and is the largest value eight unsigned bits can hold.

  • FE. Wrong. FE is 15 x 16 + 14 = 254, one short.
  • FF. Correct. Both digits are F, that is 15 x 16 + 15 = 255.
  • AE. Wrong. AE is 10 x 16 + 14 = 174.
  • F0. Wrong. F0 is 15 x 16 + 0 = 240.

3. The answer is Its 1's complement represents the 9's complement of the original digit. Take 3, whose Excess-3 code is 0110. Invert every bit and you get 1001, the Excess-3 code for 6, and 6 is the 9's complement of 3. Inverting the bits performs the decimal 9's complement for free.

  • Its 1's complement represents the 9's complement of the original digit. Correct. Bit inversion in the code equals 9's complement in decimal, which is what self-complementing means.
  • It eliminates overflow. Wrong. No code eliminates overflow. Overflow is a range problem, not an encoding problem.

12. The answer is Excess-3. Excess-3 is a numeric code, built self-complementing so decimal subtraction can be done by complementing and adding.

  • ASCII. Wrong. ASCII is a character code for text.

Answers, and why every option is what it is

1. The answer is 0 to 1023. An n-bit unsigned range is 0 to 2 to the power n, minus 1. Here 2 to the power 10 is 1024, so the range is 0 to 1023.

  • -1023 to 1023. Wrong. UNSIGNED means no negative values at all, so the range cannot start below zero.
  • 0 to 1023. Correct. 1024 distinct patterns, counting from 0, so the top value is 1023.
  • -512 to 511. Wrong. That is the 10-bit TWO'S COMPLEMENT range, offered to catch a reader who skimmed past the word unsigned.
  • 0 to 1024. Wrong by one. There are 1024 patterns, but they run 0 to 1023, because 0 uses one of them.

2. The answer is -28. The leading bit is 1, so the value is negative. Invert every bit to recover the magnitude: 11100011 becomes 00011100, which is 16 + 8 + 4 = 28.

  • -29. Wrong, and the trap. -29 is what this pattern means in TWO'S complement, where you invert and add 1.
  • -28. Correct. Invert only, giving 28, and apply the negative sign for -28.
  • -31. Wrong. 31 would be 00011111 after inversion, so the original would have been 11100000.
  • -30. Wrong. 30 would be 00011110 after inversion, so the original would have been 11100001.

3. The answer is It has positive and negative zero. 00000000 is +0 and 11111111 is -0, so one's complement carries two zeros, just as sign-magnitude does. Only two's complement has a single zero.

  • It has one representation of zero. Wrong. A single zero is the TWO'S complement property, and it is one of the reasons two's complement won.
  • Overflow never occurs. Wrong. Overflow depends on the width of the word, not on the negation scheme, so it can occur in any of them.
  • It has positive and negative zero. Correct. 00000000 and 11111111 are both zero, which is the scheme's central weakness.
  • It has no negative numbers. Wrong. Representing negatives is the entire purpose of a complement scheme.

4. The answer is Flipping all bits. One's complement negation is a straight bit inversion, nothing more.

  • Shifting right. Wrong. Shifting right divides by 2, it does not change the sign.
  • Flipping all bits. Correct. Invert every bit and you have the additive inverse.
  • Adding 1. Wrong on its own, and this is the near miss. Invert AND add 1 gives the TWO'S complement. Adding 1 by itself simply counts up.
  • Shifting left. Wrong. Shifting left multiplies by 2.

5. The answer is 10000000. Sign-magnitude splits the word into a sign bit and a magnitude. Negative zero is sign bit 1 with a magnitude of zero.

  • 11111111. Wrong. 11111111 is negative zero in ONE'S complement, and in sign-magnitude it reads as -127.
  • 00000000. Wrong. That is POSITIVE zero, sign bit 0 with zero magnitude.
  • 01111111. Wrong. Sign bit 0 with magnitude 1111111 is +127.
  • 10000000. Correct. Sign bit 1, magnitude 0000000, so minus nothing.

6. The answer is 255. Eight ones is 2 to the power 8, minus 1, which is 255. The word UNSIGNED means there is no sign bit to set aside.

  • 127. Wrong. 127 is 01111111, the largest value in SEVEN bits, which is what you get if you wrongly reserve a sign bit.
  • 255. Correct. 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255.
  • 254. Wrong by one. 254 is 11111110.
  • 128. Wrong. 128 is 10000000, just the top bit.

7. The answer is -128. Two's complement is asymmetric: 8 bits run from -128 to +127, and 10000000 is that most negative value. Weight the sign bit negatively and you get -128 + 0 = -128.

  • -127. Wrong. -127 is 10000001. Invert and add 1 to check: 10000001 gives 01111111, which is 127.
  • +128. Wrong, and impossible. +128 does not fit in 8-bit two's complement, where the largest positive is +127.
  • -128. Correct. The one negative value with no positive partner.
  • 0. Wrong. Zero is 00000000, and two's complement has only that one zero. Reading this pattern as -0 is the sign-magnitude habit.

8. The answer is 2. There are always exactly two, +0 and -0, because the sign bit is free to be either value while the magnitude is zero.

  • 2. Correct. One sign bit, two settings, both with an all-zero magnitude.
  • Depends on word length. Wrong. A longer word adds more magnitude bits, but there is still only ever one sign bit, so the count stays at 2.
  • 1. Wrong. A single zero is the TWO'S complement property.
  • 4. Wrong. Four would need two sign bits, which no scheme uses.

9. The answer is 11010100. Two steps, in order. Invert 00101100 to get 11010011, then add 1 to get 11010100. Check it: the original is 44, and the answer should read as -44.

  • 10110100. Wrong. This matches neither step. Inverting gives 11010011, and adding 1 gives 11010100.
  • 11110011. Wrong. 11110011 is not the inversion of 00101100. Compare them bit by bit.
  • 11010011. Wrong, and the classic near miss. 11010011 is the ONE'S complement, the result of stopping before you add 1.
  • 11010100. Correct. Inverted, then incremented.

10. The answer is Result exceeds representable range. Overflow is a result too large for the word to hold.

  • Result exceeds representable range. Correct, and this is the definition. The word has a fixed width, and the answer did not fit.
  • Division by zero occurs. Wrong. Division by zero is a separate arithmetic exception with its own trap.
  • Sign changes unexpectedly. Wrong, but tempting: an unexpected sign flip is how you DETECT two's complement overflow. It is the symptom, not the definition.
  • Bits are shifted. Wrong. Shifting is a normal operation, though shifting bits out of the top can itself cause a loss of value.

11. The answer is One's Complement. In one's complement, a carry out of the most significant bit must be added back into the least significant bit.

  • Excess-3. Wrong. Excess-3 is a digit code, not a signed number scheme, so end-around carry does not arise.
  • Sign Magnitude. Wrong. Sign-magnitude addition compares magnitudes and decides the sign. There is no carry to wrap.
  • One's Complement. Correct. The carry out is fed back into the low end, and the fix exists because of the two zeros.
  • Two's Complement. Wrong. Two's complement simply DISCARDS the carry out, which is one of the reasons its hardware is simpler.

12. The answer is -42. Split off the sign bit: 1 means negative, and the remaining seven bits 0101010 are 32 + 8 + 2 = 42.

  • +170. Wrong twice. It reads all eight bits as the magnitude, giving 170, and then ignores the sign bit.
  • -170. Wrong once. The sign is right, but the magnitude wrongly includes the sign bit, giving 170 instead of 42.
  • +42. Wrong once. The magnitude is right, but the leading 1 was ignored, so the sign is lost.
  • -42. Correct. Negative, magnitude 42.

13. The answer is Faster and simpler hardware implementation. One adder handles both addition and subtraction, there is a single zero, and no end-around carry is needed.

  • Easier decimal conversion. Wrong. Converting a two's complement number to decimal by hand is arguably the fiddliest of the three schemes.
  • Eliminates overflow. Wrong, and false on its face. Overflow is a consequence of a fixed word width and no scheme removes it.
  • Greater storage efficiency. Wrong. All three schemes use exactly the same number of bits for the same width.
  • Faster and simpler hardware implementation. Correct. One adder for both operations, one zero, no carry to wrap around.

14. The answer is Slow and complex arithmetic circuitry. The circuit must inspect both sign bits, decide whether to add or subtract, compare magnitudes and work out the sign of the result. Two's complement just adds.

  • Inability to represent positive numbers. Wrong, and plainly false. Sign bit 0 gives every positive value.
  • Slow and complex arithmetic circuitry. Correct. Signs must be compared, magnitudes ordered and the result's sign derived, all in hardware.
  • Large memory usage. Wrong. An 8-bit sign-magnitude value occupies 8 bits, the same as any other scheme.
  • Limited range. Wrong. Its range, -127 to +127, is essentially the same as two's complement, losing only the extra negative value.

1. The answer is Using double precision arithmetic. Double precision widens the exponent from 8 bits to 11, which stretches the range from about 10 to the power plus or minus 38 out to about 10 to the power plus or minus 308.

  • Using ASCII. Wrong. ASCII is a character code and performs no arithmetic at all.
  • Using double precision arithmetic. Correct. More exponent bits means more range, so fewer results fall off either end.
  • Using fewer bits. Wrong, and exactly backwards. Fewer bits shrink the range and cause MORE overflow.
  • Using BCD. Wrong. BCD codes decimal digits and is less compact than binary, so it does not extend numeric range.

2. The answer is Floating-point representation. Accuracy is decided by how a number is REPRESENTED: how many mantissa bits hold the significant digits.

  • Floating-point representation. Correct. The mantissa width sets how many significant digits survive, which is precision itself.
  • Cache hierarchy. Wrong. Cache changes how quickly data arrives, never what the computed value is.
  • Control signals. Wrong. Control signals sequence the hardware. They do not alter numeric precision.
  • Bus width. Wrong. A wider bus moves more bits per transfer, a speed matter and not an accuracy one.

3. The answer is 10^±308. Double precision reaches roughly 10 to the power plus or minus 308. Learn it as a pair with single precision at roughly 10 to the power plus or minus 38, because this paper sets both.

  • 10^±38. Wrong. That is the SINGLE precision figure, the other half of the pair.
  • 10^±128. Wrong. 128 is close to the single precision exponent bias of 127, not a decimal range.
  • 10^±308. Correct. About 10 to the power plus or minus 308.
  • 10^±256. Wrong. 256 is a familiar power of two, put here to look plausible. It is not the figure.

4. The answer is 64 bits. Double precision is 64 bits: 1 sign, 11 exponent, 52 mantissa. Single precision is 32 bits: 1 sign, 8 exponent, 23 mantissa. Those two lines answer most floating-point questions on this paper.

  • 64 bits. Correct. 1 + 11 + 52 = 64.
  • 32 bits. Wrong. 32 bits is SINGLE precision, and the name double says twice that.
  • 48 bits. Wrong. 48 bits is not an IEEE 754 basic format.

  • Cache replacement policy. Wrong. A replacement policy affects hit rate and therefore speed, not the computed values.
  • Character encoding. Wrong. Character encoding is for text, and a simulation computes on numbers.
  • Control bus design. Wrong. The control bus carries command signals, which has no bearing on numerical accuracy.

  • 23. Wrong. 23 is the MANTISSA width of the same format.
  • 7. Wrong. 7 bits is the width of an ASCII character, not of this exponent.
  • 11. Wrong. 11 is the exponent width of DOUBLE precision.

  • 255. Wrong. 255 is the largest value in 8 bits, not a bias.

Answers, and why every option is what it is

1. The answer is Layout of bits within an instruction. A format is a map of the instruction word: which bits are the opcode, which name registers, which carry an address or a constant.

  • Layout of bits within an instruction. Correct. It is the bit layout, and the decoder reads the word according to it.
  • Cache organization. Wrong. Cache organization is about memory levels and mapping, not the shape of an instruction.
  • Internal processor wiring. Wrong. Internal wiring is microarchitecture, hidden below the format.
  • Operating system memory allocation. Wrong. Memory allocation is a software concern, handled by the operating system at run time.

2. The answer is Operation to perform. Opcode is short for operation code. It answers WHAT to do, while the operand fields answer WHAT TO DO IT TO.

  • Memory address. Wrong. An address lives in the ADDRESS field, a separate part of the word.
  • Operation to perform. Correct. ADD, LOAD, JUMP and the rest are named by the opcode.
  • Register contents. Wrong. Register CONTENTS are data held in the register file. The instruction can only name the register, never carry its contents.
  • Interrupt priority. Wrong. Interrupt priority is set by the interrupt controller, not encoded in every instruction.

3. The answer is Increase opcode bits while reducing operand bits. The instruction word is a fixed budget of bits. If the total length may not grow, the only way to widen one field is to narrow another. An extra opcode bit doubles the opcode count, since k bits give 2 to the power k of them.

  • Increase RAM capacity. Wrong. RAM capacity is outside the processor and has no effect on how an instruction word is divided.
  • Increase opcode bits while reducing operand bits. Correct. A fixed word, so one field grows only at another's expense.
  • Add pipeline stages. Wrong. Pipeline stages change how instructions are PROCESSED, not how many distinct ones can be encoded.
  • Increase cache size. Wrong. Cache size affects speed, not the encoding space of the instruction set.

4. The answer is Three-address. A three-address instruction names both sources and the destination, so a whole operation is done in one go. The shorter formats need extra loads, stores and pushes to move operands into place, and each of those is another access.

  • Two-address. Wrong. Two-address must overwrite one source, so a value that is needed again has to be copied first.
  • Three-address. Correct. Everything is named at once, so the expression completes in the fewest instructions.
  • Zero-address. Wrong, and the furthest from it. A stack machine must PUSH each operand and POP the result, which is the most traffic of the four.

  • Consecutive accesses must be separated by at least 90 ns. Correct. The next access can only begin after the full 90 ns cycle.
  • A new memory operation can begin every 60 ns. Wrong, and the trap. 60 ns is when the DATA ARRIVES, not when the next operation may start.

26. The answer is Spatial locality. NEIGHBOURING locations means space, so this is spatial locality. It is why cache fetches a whole block rather than a single word, and why array traversal is fast.

  • Virtual locality. Wrong. There is no such principle. It is invented to sound like virtual memory.
  • Random locality. Wrong. Random access is the ABSENCE of locality, which is the worst case for a cache.
  • Temporal locality. Wrong, and the near miss. Temporal locality is the same location reused over TIME, while this stem says neighbouring.
  • Spatial locality. Correct. Nearby addresses accessed next.

Performance, RISC and CISC

7 questions. Taught in Module Two Unit 2, and Module Four Unit 1. Cover the answers before you start.

  1. TEST 2 Q4 A computer architect argues that processor performance should no longer be evaluated solely by clock frequency. Which of the following provides the strongest justification for this argument?   (a) Modern processors execute exactly one instruction per clock cycle.   (b) Processor performance also depends on CPI (Cycles Per Instruction), Instruction-Level Parallelism (ILP), cache performance, branch prediction accuracy, and memory latency.   (c) Clock frequency completely determines instruction execution time.   (d) Higher clock frequency eliminates cache misses.
  2. TEST 2 Q11 A processor executes a benchmark requiring 12 billion instructions, operating at 4 GHz, with an average CPI of 1.5. What is the approximate execution time?   (a) 2.5 seconds   (b) 4.5 seconds   (c) 5.5 seconds   (d) 3.5 seconds
  3. TEST 2 Q43 Suppose Processor X executes fewer instructions than Processor Y for the same program, but Processor Y completes execution faster due to better pipelining. Which statement is most accurate?   (a) Processor X has a superior ISA.   (b) Microarchitecture significantly affects performance.   (c) ISA alone determines performance.   (d) Instruction count is irrelevant.
  4. TEST 2 Q2 A processor implements speculative execution and branch prediction. The primary objective of these techniques is to:   (a) Increase storage capacity.   (b) Reduce pipeline stalls caused by control hazards.   (c) Reduce transistor count.   (d) Replace cache memory.
  5. TEST 2 Q23 Variable-length instruction formats are commonly associated with:   (a) CISC architectures   (b) SIMD processors   (c) RISC architectures   (d) Harvard architecture
  6. TEST 2 Q36 An embedded processor minimizes silicon area and power consumption by reducing instruction complexity and relying heavily on compiler optimization. This design reflects:   (a) SIMD architecture   (b) RISC philosophy   (c) VLIW architecture   (d) CISC philosophy
  7. TEST 2 Q42 A computer architect wants to reduce compiler complexity by designing instructions that closely resemble high-level programming constructs. Which ISA philosophy best supports this objective?   (a) Stack-based ISA   (b) Harvard Architecture   (c) RISC   (d) CISC
Answers, and why every option is what it is

1. The answer is Processor performance also depends on CPI (Cycles Per Instruction), Instruction-Level Parallelism (ILP), cache performance, branch prediction accuracy, and memory latency. Execution time is instruction count times CPI divided by clock rate. Frequency is one term of three, and CPI itself depends on cache, branches and parallelism.

  • Modern processors execute exactly one instruction per clock cycle. Wrong. Superscalar processors issue several instructions per cycle, and stalls can push it below one. "Exactly one" is false.
  • Processor performance also depends on CPI (Cycles Per Instruction), Instruction-Level Parallelism (ILP), cache performance, branch prediction accuracy, and memory latency. Correct. It names the other terms in the performance equation and the factors that drive CPI.
  • Clock frequency completely determines instruction execution time. Wrong, and it argues the OPPOSITE of the architect's case.
  • Higher clock frequency eliminates cache misses. Wrong. A faster clock does not change how often data is found in cache. If anything a miss costs MORE cycles at a higher frequency.

2. The answer is 4.5 seconds. CPU time = (instruction count x CPI) / clock rate. Cycles needed = 12 x 10^9 x 1.5 = 18 x 10^9. Divide by 4 x 10^9 cycles per second to get 4.5 seconds.

  • 2.5 seconds. Wrong. No correct combination of the three figures gives 2.5.
  • 4.5 seconds. Correct. 18 billion cycles at 4 billion cycles per second is 4.5 seconds.
  • 5.5 seconds. Wrong. Too high. Recheck the division by 4, not by 3.
  • 3.5 seconds. Wrong. Note that dropping the CPI gives 12 / 4 = 3 seconds, which is not offered, so this option catches a half-remembered formula rather than that specific slip.

3. The answer is Microarchitecture significantly affects performance. Fewer instructions did not win, because Y's better pipelining cut its CPI. Instruction count and CPI trade against each other, and this is the classic RISC against CISC comparison.

  • Processor X has a superior ISA. Wrong. A superior ISA that finishes LAST is a strange claim, and instruction count alone does not make an ISA better.
  • Microarchitecture significantly affects performance. Correct. Pipelining is microarchitecture, and here it outweighed the instruction count advantage.
  • ISA alone determines performance. Wrong, and directly contradicted: the two differ in pipelining, which is not the ISA.
  • Instruction count is irrelevant. Wrong, too strong. Instruction count is a real term in the performance equation, it simply was not decisive here.

4. The answer is Reduce pipeline stalls caused by control hazards. A branch is a control hazard: the pipeline does not know which instruction follows until the branch resolves. Predicting and running ahead speculatively keeps the pipeline full.

  • Increase storage capacity. Wrong. Neither technique stores anything for the program. They are about timing, not capacity.
  • Reduce pipeline stalls caused by control hazards. Correct, and note the exact phrase CONTROL HAZARD, which is the hazard branches cause.
  • Reduce transistor count. Wrong, and backwards. Prediction tables and speculation logic ADD transistors.
  • Replace cache memory. Wrong. Cache addresses data delay, branch prediction addresses control delay. They are different problems.

5. The answer is CISC architectures. CISC packs many operations of differing complexity into one instruction set, so instructions vary in length. RISC fixes the length to make decoding and pipelining simple.

  • CISC architectures. Correct. Variable length is a defining CISC trait, and x86 is the standing example.
  • SIMD processors. Wrong. SIMD is about operating on many data elements at once, which is independent of instruction length.
  • RISC architectures. Wrong, and the direct opposite. RISC uses FIXED-length instructions.
  • Harvard architecture. Wrong. Harvard is about separate instruction and data memories, not about encoding.

6. The answer is RISC philosophy. Simple instructions, simple hardware, and complexity pushed into the compiler. That trade is the RISC philosophy in one sentence.

  • SIMD architecture. Wrong. SIMD adds wide vector units for data parallelism, which costs area rather than saving it.
  • RISC philosophy. Correct. Reduced instruction complexity plus compiler reliance is RISC by definition.
  • VLIW architecture. Wrong, though it is the closest decoy: VLIW also leans on the compiler, but it does so to issue several operations at once, not to minimise area and power.
  • CISC philosophy. Wrong, and the opposite. CISC puts the complexity in the HARDWARE to make the compiler's job easier.

7. The answer is CISC. Closing the semantic gap between high-level languages and machine instructions was the original CISC goal, so one instruction could do the work of a whole statement.

  • Stack-based ISA. Wrong. A stack ISA simplifies operand addressing, but it does not aim to mirror high-level constructs.
  • Harvard Architecture. Wrong. Harvard describes the memory organization, not the instruction philosophy.
  • RISC. Wrong, and the opposite. RISC deliberately keeps instructions simple and makes the COMPILER work harder.
  • CISC. Correct. Complex instructions resembling high-level constructs, which is where the semantic gap argument comes from.

Von Neumann, Harvard and Image Data

5 questions. Taught in Module One Unit 1, and Module One Unit 2. Cover the answers before you start.

  1. TEST 1 Q18 For a monochrome bitmap image, each pixel requires:   (a) 2 bits   (b) 8 bits   (c) 1 bit   (d) 4 bits
  2. TEST 1 Q31 Photographs are generally better represented using:   (a) Vector graphics   (b) ASCII encoding   (c) Excess-3 encoding   (d) Bitmap graphics
  3. TEST 1 Q37 A processor fetches an instruction while simultaneously reading data from memory. Which architecture makes this possible?   (a) Stack Architecture   (b) CISC Architecture   (c) Von Neumann Architecture   (d) Harvard Architecture
  4. TEST 1 Q44 An embedded system uses separate memory modules for instructions and data to improve throughput. Which architectural design is being used?   (a) Von Neumann Architecture   (b) Stack Architecture   (c) Pipeline Architecture   (d) Harvard Architecture
  5. TEST 1 Q46 Which characteristic is a major advantage of the Harvard Architecture?   (a) Single memory space for all data   (b) Simpler hardware implementation   (c) Simultaneous access to instructions and data   (d) Reduced memory requirements
Answers, and why every option is what it is

1. The answer is 1 bit. Monochrome means two states, black or white, and one bit gives exactly two states. The general rule is that k bits per pixel give 2 to the power k colours.

  • 2 bits. Wrong. 2 bits give 4 levels, which is a four-shade image rather than a monochrome one.
  • 8 bits. Wrong. 8 bits give 256 levels, the usual greyscale depth.
  • 1 bit. Correct. One bit, two states, so image size in bits equals the number of pixels.
  • 4 bits. Wrong. 4 bits give 16 levels, the old 16-colour standard.

2. The answer is Bitmap graphics. A photograph is continuous tone with no clean edges to describe as shapes, so it is stored as a grid of pixel values. Pair this with the logo question, where the answer was vector.

  • Vector graphics. Wrong. Vectors describe shapes with equations, which suits logos and diagrams, not the texture of a real scene.
  • ASCII encoding. Wrong. ASCII encodes text characters.
  • Excess-3 encoding. Wrong. Excess-3 encodes single decimal digits.
  • Bitmap graphics. Correct. A pixel grid captures continuous tone, which is what a photograph is.

3. The answer is Harvard Architecture. Harvard keeps instructions and data in separate memories with separate buses, so both can be read in the same cycle.

  • Stack Architecture. Wrong. Stack architecture describes how operands are addressed, not how memory is wired.
  • CISC Architecture. Wrong. CISC is an instruction set philosophy, unrelated to the number of memory paths.
  • Von Neumann Architecture. Wrong, and this is the contrast being tested. Von Neumann shares ONE memory and one bus for both, which forces the two accesses to take turns. That queue is the Von Neumann bottleneck.
  • Harvard Architecture. Correct. Separate paths mean genuinely simultaneous access.

4. The answer is Harvard Architecture. The phrase SEPARATE MEMORY for instructions and data is the definition of Harvard. It is common in embedded and signal processing designs for exactly the throughput reason given.

  • Von Neumann Architecture. Wrong. Von Neumann is the SINGLE shared memory design, the opposite of what the stem describes.
  • Stack Architecture. Wrong. Stack architecture is about operand addressing, not memory separation.
  • Pipeline Architecture. Wrong. Pipelining overlaps the stages of instruction processing. It is a technique, not a memory arrangement, though Harvard helps it along.
  • Harvard Architecture. Correct. Separate instruction and data memories.

5. The answer is Simultaneous access to instructions and data. Two memories with two buses means an instruction fetch and a data read can happen at once, which raises throughput and removes the Von Neumann bottleneck.

  • Single memory space for all data. Wrong, and it describes VON NEUMANN. Harvard deliberately splits the memory space in two.
  • Simpler hardware implementation. Wrong, and backwards. Two memory systems and two bus sets are MORE hardware, which is the price Harvard pays.
  • Simultaneous access to instructions and data. Correct. Both accesses in the same cycle.
  • Reduced memory requirements. Wrong. Splitting memory does not reduce how much is needed, and fixed separate pools can waste space when one fills before the other.
