Question Paper

Time: 2 hours. Answer Question One (compulsory, 30 marks) and any other two questions (20 marks each). Total 70 marks.

Question OneCompulsory · 30 marks

(a) (i) Differentiate computer architecture from computer organization. (2) (ii) Compare the Von Neumann and Harvard architectures, with a diagram for each. (3)

(b) A processor runs 2 million instructions with this mix and cycle cost: ALU 45% at 1 cycle, Load 25% at 4 cycles, Store 15% at 2 cycles, Branch 15% at 3 cycles. (i) Find the average CPI. (ii) Find the total clock cycles. (iii) If Load is optimised to 2 cycles, find the new CPI. (iv) Find the percentage performance improvement. (6)

(c) Using a 12-bit register, represent 150 and −95 in unsigned, sign-magnitude, one's complement and two's complement. (6)

(d) (i) Represent 39.5 in IEEE-754 single precision, giving the hex. (ii) Find the decimal value of 42480000H under IEEE-754. (9)

(e) A 32-bit machine has a direct-mapped cache of 1024 lines with 32-byte blocks. Give the number of tag, index and offset bits. (4)

Question Two20 marks

(a) A 5-stage pipeline has stage times 20, 15, 25, 20 and 10 ns with a 5 ns latch delay. For 1000 tasks find (i) the cycle time, (ii) the non-pipeline time for one task, (iii) the pipeline time for 1000 tasks, (iv) the sequential time for 1000 tasks, (v) the speedup. (10)

(b) Explain the three kinds of pipeline hazard, and say how forwarding and a single stall handle a load-use data hazard. (6)

(c) Why is the speedup of a real pipeline always less than the number of stages? (4)

Question Three20 marks

(a) A system has 256 MB main memory, a 64 KB cache with 32-byte blocks, using 4-way set associative mapping. Find (i) the number of cache blocks, (ii) the number of sets, (iii) the tag, set and offset field widths. (8)

(b) The cache hit ratio is 90%, cache access is 3 ns and main memory is 60 ns. Find the average memory access time for simultaneous and for hierarchical organisation. (6)

(c) Explain locality of reference, distinguishing temporal from spatial locality, and say how each shapes cache design. (6)

Question Four20 marks

(a) Write Y = (A + B) × (C − D) in the 3-address, 2-address, 1-address and 0-address instruction formats. (10)

(b) Given PC = 4000, R1 = 2500, an address field of 3200, and memory where M[1500] = 700, M[2500] = 900, M[3200] = 1500 and M[7200] = 350, give the effective address and operand for direct, indirect, register-indirect (R1) and relative addressing. (6)

(c) State four differences between RISC and CISC, with one example processor of each. (4)

Question Five20 marks

(a) State Amdahl's law. A program has 90% of its work parallelised to run 8 times faster. Find the overall speedup. (6)

(b) State four differences between DRAM and SRAM, and say which is used for cache and which for main memory, and why. (8)

(c) Describe the four memory access methods, with one example device each. (6)
