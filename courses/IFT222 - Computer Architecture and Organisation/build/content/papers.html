Hierarchical is 1 ns slower here because the cache time is paid on every access, hit or miss.

AnswerQuestion Two (20 marks)

Q2(a) A cache of 1 KB with 16-byte blocks backs a 64 KB main memory on a 16-bit address. Design the cache for direct, fully associative and 2-way set-associative mapping, and give an advantage and a disadvantage of each. (8 marks)

Given cache = 1 KB · block = 16 bytes · main memory = 64 KB · address = 16 bits
Find the address format under each of the three mappings, plus one advantage and one disadvantage each
Formula lines = cache / block · offset = log2(block) · sets = lines / k · tag = address − index (or set) − offset · tag directory = lines × tag bits
what each symbol means lines = 1 KB / 16 B = 64, the same under all three mappings · offset = log216 = 4 bits · k = the ways per set, 2 for the 2-way case · 64 KB = 216, which is why the address is 16 bits
MappingTagIndex / setOffsetTag directory
Direct66 (index, 64 lines)464 × 6 = 384 bits = 48 bytes
Fully associative12none464 × 12 = 768 bits = 96 bytes
2-way set assoc.75 (set, 32 sets)464 × 7 = 448 bits = 56 bytes
Direct: simplest and fastest lookup (one line to check, one comparator), but two blocks mapping to the same line evict each other, causing conflict misses. Fully associative: no conflict misses, any block may sit anywhere, but every line's tag must be compared at once, which is expensive and slow, and the tag directory doubles to 96 bytes. 2-way: the compromise, most conflict misses removed for only two comparators and a modest tag growth to 56 bytes.

Q2(b) (i) What is locality of reference, and distinguish temporal from spatial locality? (ii) What happens on a cache miss?  [see M3 U1]

(i) Locality of reference is the tendency of a program to access a small, predictable set of memory locations during any short period. Temporal: a location used now is likely to be used again soon, so cache keeps recently used items. Spatial: locations near one just used are likely to be used soon, so cache fetches a whole block of neighbours at once. (ii) On a miss the word is not in cache, so the address goes onto the system bus, main memory returns the whole block containing it, that block is loaded into a cache line (evicting one if necessary), and the required word is delivered to the CPU at the same time.

Q2(c) Write an assembly program to add two numbers and store the result. (4 marks)  [see M1 U4]

On a one-address (accumulator) machine:
LOAD A   ; accumulator = A
ADD  B   ; accumulator = A + B
STORE C  ; C = A + B
On a three-address machine it is the single instruction ADD C, A, B. Either scores full marks provided you state which machine you assume.
AnswerQuestion Three (20 marks)

Q3(a) State the Von Neumann concept (1), two significant aspects of it (2), and the Von Neumann bottleneck (2).  [see M1 U1]

The Von Neumann concept: a computer stores its program (instructions) and its data together in the same memory, and executes instructions one after another by fetching them from that memory. Two aspects: (a) a single shared memory holds both instructions and data; (b) instructions execute sequentially, one at a time, under the stored-program idea. The bottleneck: because one bus is shared between instructions and data, the CPU cannot fetch an instruction and access data at the same instant, so that single path limits overall speed however fast the CPU is.

AnswerQuestion Four (20 marks)

Q4(a)(i) Compare Von Neumann and Harvard architecture, with a diagram of each. (3)  (ii) State four differences between RISC and CISC and give two example processors of each. (4)  [see M1 U1, M4 U1]

(i) Von Neumann uses one memory and one bus for instructions and data, so it is simpler and cheaper but the shared bus carries only one at a time. Harvard uses separate memories and buses, so an instruction fetch and a data access happen simultaneously: faster, but more hardware and less flexible. Draw both diagrams; they carry marks of their own.

Examples: RISC, ARM and MIPS (also SPARC, RISC-V). CISC, Intel x86 and Motorola 68000 (also VAX).

Q4(b)(i) Use end-around carry in one's complement to compute 153 − 142 in a 10-bit register. (4)  (ii) Distinguish overflow from underflow, with one example each. (3)  [see M1 U2]

Given 153 − 142 · n = 10 bits · one's complement
Find the difference as a pattern and in decimal
Formula a − b = a + (−b) with −b the bitwise inversion; a carry out of the top is added back into the lowest bit
153 = 00 1001 1001; +142 = 00 1000 1110 so −142 = 11 0111 0001. Adding: 00 1001 1001 + 11 0111 0001 = 1 00 0000 1010, with a carry out. End-around: 00 0000 1010 + 1 = 00 0000 1011 = 11, and 153 − 142 = 11. Correct. (ii) Overflow is a result too large for the available bits (in 8-bit two's complement, 100 + 50 = 150 overflows the +127 limit). Underflow is a result too small to represent: for integers more negative than the smallest storable value (−100 − 50 = −150 below −128), and for floating point a value so close to zero it rounds away to nothing.

Q4(c) Find the decimal value of C4F2E000H in IEEE-754 single precision. (6 marks)  [see M1 U3]

C4F2E000 = 1100 0100 1111 0010 1110 0000 0000 0000. Sign 1, so negative. E = 1000 1001 = 137, so e = 137 − 127 = 10. Restoring the hidden 1 gives 1.11100101110 × 210 = 111100101112 = 1024+512+256+128+16+4+2+1 = 1943. So the value is −1943.
AnswerQuestion Five (20 marks)

Q5(a)(i) State the three categories of instructions with two examples each. (ii) Describe memory characteristics by access method, with an example each. (4)  [see M1 U4, M3 U1]

(i) Data transfer: LOAD, STORE (also MOVE, PUSH, POP). Arithmetic and logic: ADD, AND (also SUB, MUL, OR, NOT, shifts). Control (test and branch): JUMP, BEQ (also CALL, RETURN). (ii) Sequential: read in order from the start, access time depends on position, as in magnetic tape. Direct: jump near the item then search a small region, as on a disk. Random: every location takes the same time via its address, as in RAM. Associative: located by content rather than address, all locations compared at once, as in a cache tag search.

Q5(b) A pipeline has 4 phases of 60, 50, 90 and 80 ns with a 10 ns latch delay. Find the cycle time, the non-pipeline time for one task, the speedup, the pipeline and sequential times for 500 tasks, and the throughput. (6 marks)  [see M2 U3]

Given k = 4 stages · 60, 50, 90, 80 ns · latch = 10 ns · n = 500 tasks
Find cycle time, one-task non-pipelined time, speedup, 500-task pipelined and sequential times, throughput
Formula cycle = slowest + latch · pipelined = (k + n − 1) × cycle · sequential = n × Σstages · throughput = n / pipelined time
Cycle = 90 + 10 = 100 ns. Non-pipelined one task = 60+50+90+80 = 280 ns. Ideal speedup = 280/100 = 2.8. For 500 tasks: pipelined = (4 + 499) × 100 = 50 300 ns; sequential = 500 × 280 = 140 000 ns. Throughput = 500 / 50 300 ns, which in the steady state is one task per cycle, that is 1/100 ns = 10 million tasks per second.

AnswerQuestion One (compulsory, 30 marks)

Q1(a)(i) Differentiate computer architecture from computer organization. (2)  (ii) Compare Von Neumann and Harvard, with a diagram of each. (3)  [M1 U1]

(i) Architecture is the set of attributes visible to the programmer (instruction set, registers, addressing modes): it defines what the machine does. Organization is how those attributes are implemented in hardware (control signals, buses, memory technology): it defines how. Example: architecture says a MULTIPLY instruction exists; organization decides whether a dedicated multiplier or repeated addition performs it. (ii) Von Neumann: one memory, one bus, simpler and cheaper, bus is a bottleneck. Harvard: separate memories and buses, simultaneous fetch and data access, faster but costlier. Both diagrams are worth marks; draw them.

Q1(b) A 5-stage pipeline (IF 5, ID 4, EX 6, MEM 5, WB 4 ns) has 1 ns register overhead. Mix: arithmetic 40%, memory 35%, branch 20%, floating point 5%, over 20 million instructions; the non-pipelined clock is 25 ns. Find the pipelined clock, the actual CPI, the execution time and the speedup. (6)  [see M2 U2]

Given stages 5, 4, 6, 5, 4 ns · overhead 1 ns · IC = 20 000 000 · the mix above · non-pipelined clock 25 ns
Find clock period, actual CPI, execution time, speedup
Formula clock = slowest stage + overhead · actual CPI = ideal + Σ(fraction × penalty) · time = IC × CPI × T
Clock = 6 + 1 = 7 ns. Reading the stated penalties (ideal CPI 1; branch +2; memory +2 plus 4 more on a 10% miss, so 2.4 average; floating point +4): CPI = 1 + 0.20(2) + 0.35(2 + 0.10×4) + 0.05(4) = 2.44. Non-pipelined time = 20 000 000 × 25 ns = 0.5 s. The pipelined time is 20 000 000 × 2.44 × 7 ns = 0.3416 s, a speedup of about 1.46. It falls short of the ideal 5 because stalls raise CPI above 1 and the latch overhead lengthens every cycle.

AnswerQuestion Two (20 marks)

Q2(a) 32-bit addresses, 16 words per block, direct-mapped cache of 256 blocks. Which block does each of CA2DFC12, F24F25FF, 24BBABCD, C1D9EEF2 map to?  [see M3 U3]

Offset 4 bits, index 8 bits, tag 20 bits. Reading the hex: drop the last digit, take the next two. CA2DFC12 → C1 = 193; F24F25FF → 5F = 95; 24BBABCD → BC = 188; C1D9EEF2 → EF = 239.

Q2(b) A 5-stage RISC pipeline runs I1 LW, I2 ADD, I3 SUB, I4 SW, I5 BEQ, I6 MUL, with forwarding, one stall for load-use, and a 3-cycle EX for MUL. Identify the hazards, draw the timing diagram, give the total cycles, and suggest two hardware improvements.  [see M2 U3]

Hazards: a load-use data hazard between I1 and I2 (forwarding cannot fix it, so exactly one stall); data hazards I2 to I3 and I3 to I4, both covered by forwarding; a control hazard at I5, the branch resolved in EX; and a structural delay at I6, whose 3-cycle EX holds the stage for two extra cycles. Ideal (k + n − 1) = 5 + 6 − 1 = 10, plus 1 load-use stall and 2 for the long multiply, giving 13 cycles. Two improvements: add a dedicated multiplier so a long multiply does not block EX, and use separate instruction and data memories (or split caches) to remove structural stalls.

Q2(c) Main memory 1 GB, cache 512 KB, block 128 bytes, 4-way set associative. Find the blocks, the sets, the address format, and the AMAT at 96% hit, 2 ns cache and 80 ns memory.  [see M3 U3]

Blocks = 512 KB / 128 B = 4096. Sets = 4096 / 4 = 1024. Address = 30 bits, offset = log2128 = 7, set = log21024 = 10, tag = 30 − 10 − 7 = 13, so the format is tag 13 / set 10 / offset 7. AMAT (hierarchical) = 2 + 0.04(80) = 2 + 3.2 = 5.2 ns. Higher associativity cuts conflict misses but needs more comparators, so past a point it costs more than it saves.
AnswerQuestion Three (20 marks)

Q3(a) Main memory 64 MB, cache 128 KB, block 64 bytes. Find the number of lines, the direct-mapped fields, the 4-way fields, and say why fully associative removes conflict misses but adds a challenge.  [see M3 U3]

64 MB = 226, so 26-bit addresses. Lines = 128 KB / 64 B = 2048. Offset = log264 = 6. Direct: index = log22048 = 11, tag = 26 − 11 − 6 = 9. 4-way: sets = 2048/4 = 512, set bits = 9, tag = 26 − 9 − 6 = 11. Fully associative lets a block sit in any line, so no two blocks are forced to collide and conflict misses vanish; the challenge is that every line's tag must then be compared simultaneously, needing one comparator per line, which is expensive in area and power and slows the lookup.

Q3(b) A 5-stage pipeline (IF, ID, OF, EX, WB), one cycle per stage except EX which takes 1 for ADD/SUB, 3 for MUL and 6 for DIV, runs I1 MUL, I2 DIV, I3 ADD, I4 SUB. Give the total cycles with and without operand forwarding.  [see M2 U3]

Under the stated assumptions (one in-order execution unit, so an instruction enters EX only when EX is free; write-back one cycle after EX; forwarding delivers a result to the next instruction's EX in the following cycle), the schedule gives 15 cycles with forwarding and 17 cycles without. The full cycle diagram for both cases is worked in Module Two Unit 3. State your assumptions: this question is ambiguous without them, and the marks follow the reasoning.

Q3(c) A cache is 10 times faster than main memory and serves 85% of accesses. Find the overall speedup by Amdahl's law. (4)  [see M2 U2]

Given f = 0.85 · s = 10
Find the overall speedup
Formula speedup = 1 / ((1 − f) + f/s)
Speedup = 1 / (0.15 + 0.085) = 1 / 0.235 = 4.26. Note it is far short of 10: the 15% still going to main memory at full cost caps the gain, which is the point of Amdahl's law.

Q5(c) Explain locality of reference and temporal locality. (3)

Locality of reference is the tendency of a program to concentrate its accesses in a small, predictable set of locations over any short period. Temporal locality is the form where a location just accessed is likely to be accessed again soon, as a loop counter is, which is why a cache keeps recently used data rather than discarding it.
