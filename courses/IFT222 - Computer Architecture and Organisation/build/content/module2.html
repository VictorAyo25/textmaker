Processor Components

The parts inside the CPU that carry out the fetch, decode, execute cycle, and the buses that connect them to memory. A few of these carry number questions about address size and memory capacity.

By the end of this unit you can name the components of a CPU and say what each does, describe the three system buses, and calculate address space, memory capacity and address width.

What is inside the processor

TeachThe CPU's parts
  • Control Unit (CU): the conductor. It fetches each instruction, decodes it, and sends the control signals that make every other part act at the right moment.
  • Arithmetic and Logic Unit (ALU): the calculator. It performs arithmetic (add, subtract) and logic (AND, OR, NOT, compare, shift).
  • Registers: the CPU's own tiny, fastest memory. General-purpose registers hold working values; special ones are the PC, IR, MAR and MDR met in Module One, and the stack pointer (SP), which holds the address of the top of the stack.
  • Internal buses: the wires that carry data between the registers, the ALU and the control unit.
TeachThe three system buses

The system bus that joins CPU, memory and I/O is really three sets of wires:

  • Address bus: carries the address the CPU wants to read or write. Its width sets how many locations can be addressed: k address lines reach 2k locations. One direction only (CPU to memory).
  • Data bus: carries the actual data, both directions. Its width sets how many bits move per transfer.
  • Control bus: carries the signals that say read, write, or wait.
TeachInput/output and how the CPU handles it

The third partner on the system bus is input/output (I/O): the devices that move data between the computer and the outside world (keyboard, screen, disk, network). The CPU manages I/O in one of three ways:

  • Programmed I/O (polling): the CPU repeatedly checks whether a device is ready. Simple, but it wastes CPU time waiting.
  • Interrupt-driven I/O: the device raises an interrupt when it is ready and the CPU stops to service it, so it need not poll.
  • Direct memory access (DMA): a DMA controller moves a whole block between a device and memory without the CPU, interrupting it only once the transfer is done. Fastest for large transfers.
Must memoriseAddressing capacity

k address lines can address 2k locations. Turn it around: to address N locations you need k = log2N address lines. The total capacity is 2k × (bytes per location).

Memory hook: every extra address line doubles the number of locations you can reach.

Worked examplePQ 20/21 Q1a

A minicomputer uses 18 address lines. Find (i) the address space, (ii) the largest memory in bytes if each location holds one byte, (iii) the length of the program counter.

  1. Address space = 2number of lines = 218 = 262 144 locations. 218 = 210 × 28 = 1024 × 256.
  2. At one byte per location that is 262 144 bytes = 256 KB.
  3. The PC must hold any address, so it is as wide as the address bus: 18 bits.
(i) 218 = 262 144 locations. (ii) 262 144 bytes = 256 KB. (iii) PC length = 18 bits.

Now redo it: address space is always 2 to the power of the number of address lines, and the PC is always as wide as an address.

Worked examplePQ 20/21 Q5a

A computer has 4 GB of word-addressable memory with a word size of 2 bytes. How many bits are needed to address memory?

  1. 4 GB = 4 × 230 bytes = 232 bytes.
  2. Word-addressable means each address names a word, not a byte. Number of words = 232 bytes ÷ 2 bytes = 231 words.
  3. To address 231 words needs 31 bits (because 231 words need 31 address lines).
4 GB ÷ 2-byte word = 231 words, so 31 address bits are needed.

Now redo it: the trap is word-addressable versus byte- addressable. Divide the total bytes by the bytes per addressable unit first, then take the log base 2.

Recall and check

A machine has 20 address lines and a 1-byte cell. How much memory can it address?

Answer

220 = 1 048 576 locations = 1 MB. Every address line doubles the reach, and 220 is exactly one mega.
