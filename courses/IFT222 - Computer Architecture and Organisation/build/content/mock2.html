Question Paper

Time: 2 hours. Answer Question One (compulsory, 30 marks) and any other two questions (20 marks each). Total 70 marks.

These questions were written for this manual. They are not a real paper. Every number in them is new, so none of them carries an As printed bar: that bar is reserved for the examiner's own words, and nothing on this page is the examiner's. What this paper copies is the shape of questions that have actually been set, leaning to the 2023/24 and 2024/25 papers: signed representation tables, an IEEE-754 conversion each way, cache field widths and the instruction formats. When you want the real wording, go to the Past Papers part for 2024/25 in full, or to the unit that teaches each topic, where the 2023/24 questions are quoted where they are taught.

Question OneCompulsory · 30 marks

(a) (i) State the Von Neumann concept and two of its significant aspects. (3) (ii) What is the Von Neumann bottleneck, and give two ways to reduce it? (2)

(b) A 16-bit two's complement processor stores 300, −200 and −5000. (i) Give the representable range and confirm all three fit. (ii) Represent each in binary and hexadecimal. (iii) Compute 300 + (−200) in two's complement. (9)

(c) (i) Represent 85.75 in IEEE-754 single precision (hex). (ii) Find the decimal value of C2960000H under IEEE-754. (8)

(d) Write Z = (A + B) × (C + D) + E in the 3-address and 0-address formats, and count the bytes of each assuming 1 byte per opcode and 2 bytes per address. (8)

Question Two20 marks

(a) A 32-bit machine has a direct-mapped cache in which each block holds 8 words and there are 512 blocks. (i) Give the offset, index and tag field widths. (ii) In which cache block do the addresses ABCD1234H and 5678FEDCH fall? (10)

(b) Explain the three cache mapping functions (direct, fully associative, set associative), with one advantage and one disadvantage of each. (10)

Question Three20 marks

(a) Using a 10-bit register, complete the unsigned, sign-magnitude, one's complement and two's complement forms of 200 and −75. (8)

(b) Using end-around carry in one's complement, compute 200 − 75 in a 10-bit register. (6)

(c) Find the memory needed for a black-and-white image of 8 inches by 10 inches at 200 dpi. Give the answer in megabytes. (6)

Question Four20 marks

(a) Find the decimal value of 43A00000H under IEEE-754 single precision. (6)

(b) Name the three categories of instructions, with two examples of each. (6)

(c) Describe the immediate, direct, indirect and register-indirect addressing modes, saying where the operand is in each. (8)

Question Five20 marks

(a) A 4-stage pipeline has stage times 40, 30, 50 and 35 ns with a 5 ns latch. For 200 tasks, find the cycle time, the pipeline time, the sequential time and the speedup. (8)

(b) Draw and describe the memory hierarchy, from registers to secondary storage, saying how speed, size and cost change down it. (6)

(c) A cache has an 85% hit ratio, 4 ns cache access and 70 ns main memory access. Find the average memory access time for a hierarchical organisation. (6)
